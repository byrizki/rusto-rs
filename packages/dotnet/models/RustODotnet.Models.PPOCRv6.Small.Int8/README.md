# RustODotnet.Models.PPOCRv6.Small.Int8

Pre-converted PP-OCRv6 Small INT8 quantized model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.rten` / `det.onnx` (PP-OCRv6 Small Detection INT8 ~2.7 MB)
- `rec.rten` / `rec.onnx` (PP-OCRv6 Small Recognition INT8 ~13.5 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
