# RustODotnet.Models.UVDoc

Document Unwarping (UVDoc) for [RustO!](https://github.com/byrizki/rusto-rs).

## Description

UVDoc geometric unwarping model (~30 MB). Corrects page curvature and perspective distortion.

## Usage

```csharp
// Models are automatically copied to your output directory.
// Reference them by relative path:
var modelPath = Path.Combine(AppContext.BaseDirectory, "models", "uvdoc.rten");
```
