# RustODotnet.Models.PPOCRv6.Tiny

Pre-converted PP-OCRv6 Tiny model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.onnx` (PP-OCRv6 Tiny Detection ~1.7 MB)
- `rec.onnx` (PP-OCRv6 Tiny Recognition ~4.3 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
