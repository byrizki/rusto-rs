# RustODotnet.Models.PPOCRv6.Small

Pre-converted PP-OCRv6 Small MNN model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.mnn` (PP-OCRv6 Small Detection ~9.4 MB)
- `rec.mnn` (PP-OCRv6 Small Recognition ~21 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
