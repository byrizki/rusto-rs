# RustODotnet.Models.PPOCRv5.Server

Pre-converted PP-OCRv5 server high-accuracy model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.onnx` (PP-OCRv5 Server Detection ~86 MB)
- `rec.onnx` (PP-OCRv5 Chinese+English Server Recognition ~98 MB)
- `rec_en.onnx` (PP-OCRv5 English Server Recognition ~90 MB)
- `dict.txt` (Chinese dictionary)
- `dict_en.txt` (English dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
