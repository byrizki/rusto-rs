# RustODotnet.Models.Cls

Text-Line Classifier for [RustO!](https://github.com/byrizki/rusto-rs).

## Description

PP-OCRv4 text-line angle classifier (~585 KB). Detects inverted (180°) text lines before OCR.

## Usage

```csharp
// Models are automatically copied to your output directory.
// Reference them by relative path:
var modelPath = Path.Combine(AppContext.BaseDirectory, "models", "cls.rten");
```
