# RustODotnet.Models.PPOCRv6.Tiny.Int8

Pre-converted PP-OCRv6 Tiny INT8 quantized model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.rten` / `det.onnx` (PP-OCRv6 Tiny Detection INT8 ~0.7 MB)
- `rec.rten` / `rec.onnx` (PP-OCRv6 Tiny Recognition INT8 ~2.7 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
