# RustODotnet.Models.PPOCRv6.Medium.Int8

Pre-converted PP-OCRv6 Medium INT8 quantized model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.rten` / `det.onnx` (PP-OCRv6 Medium Detection INT8 ~15.3 MB)
- `rec.rten` / `rec.onnx` (PP-OCRv6 Medium Recognition INT8 ~60.4 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
