# RustODotnet.Models.Layout.S

Document Layout Detection Small for [RustO!](https://github.com/byrizki/rusto-rs).

## Description

PP-DocLayout-S document layout model (~4.7 MB). Detects text, title, figure, table, list regions.

## Usage

```csharp
// Models are automatically copied to your output directory.
// Reference them by relative path:
var modelPath = Path.Combine(AppContext.BaseDirectory, "models", "layout.s.rten");
```
