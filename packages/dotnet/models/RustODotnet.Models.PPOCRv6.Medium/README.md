# RustODotnet.Models.PPOCRv6.Medium

Pre-converted PP-OCRv6 Medium MNN model files for [RustODotnet](https://www.nuget.org/packages/RustODotnet).

## Included Models

- `det.mnn` (PP-OCRv6 Medium Detection ~60 MB)
- `rec.mnn` (PP-OCRv6 Medium Recognition ~74 MB)
- `dict.txt` (PP-OCRv6 50-language dictionary)

When referenced, models are automatically copied to your output `models/` directory at build time.
