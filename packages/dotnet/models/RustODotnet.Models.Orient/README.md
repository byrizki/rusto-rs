# RustODotnet.Models.Orient

Document Orientation Classifier for [RustO!](https://github.com/byrizki/rusto-rs).

## Description

PP-LCNet document orientation classifier (~6.4 MB). Detects 0°/90°/180°/270° page orientation.

## Usage

```csharp
// Models are automatically copied to your output directory.
// Reference them by relative path:
var modelPath = Path.Combine(AppContext.BaseDirectory, "models", "orient.rten");
```
