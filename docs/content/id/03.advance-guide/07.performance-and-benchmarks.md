> [!NOTE]
> **Lingkungan Pengujian Tolok Ukur**:
>

## 1. Evaluasi Komprehensif OmniDocBench

> [!NOTE]
> **Paritas Akurasi & Efisiensi Memori**: Dengan pengurutan spasial 1D yang identik, model Indra OCR pada Pure-Rust MNN dan RTen sama-sama meraih akurasi identik **45.97% (NED 0.5403)**, mengungguli PaddleOCR Tiny (45.33%) dan RapidOCR Tiny (44.84%). RustO dengan RTen hanya mengonsumsi **178.0 MB hingga 196.2 MB RAM**—jejak memori puncak terendah di antara seluruh runtime OCR yang dievaluasi (kurang dari separuh konsumsi RapidOCR sebesar 392.5 MB dan hampir 4x lebih rendah dari PaddleOCR sebesar 659.3 MB). Pure-Rust MNN beroperasi pada kisaran **253.1 MB hingga 285.9 MB RAM** dengan ukuran biner mandiri hanya **4.5 MB** tanpa dependensi runtime C++ eksternal. Pada PP-OCRv6 Small, jejak memori berhasil dipangkas menjadi **249.4 MB** (penurunan ~48%). Peningkatan model dari Tiny ke Small melipatgandakan bobot model 4x lipat (6.1 MB → 29.8 MB) dan menaikkan latensi ~3x tanpa peningkatan akurasi pada pengujian ini.

### Poin Utama Arsitektur & Tradeoff Mesin

1. **Pure-Rust MNN (`rusto-nn`, Bawaan v0.4.0)**:
   - Menggabungkan keandalan keamanan memori 100% Rust murni dan tanpa dependensi kompilasi C++ eksternal dengan eksekusi graf MNN dan kernel SIMD teroptimasi (AVX-512, AVX2+FMA, NEON, WebGPU).
   - Ukuran biner bawaan `rusto` kini dipangkas menjadi **4.5 MB** (pengurangan ~45% berkat pemisahan backend RTen dan MNN C++ ke dalam biner mandiri terpisah).
   - Menghilangkan latensi _cold-start_ dengan waktu muat model secepat **0.45 ms** hingga **1.01 ms** (**8x–31x lebih cepat** dibandingkan RTen dan hingga **38x lebih cepat** dibandingkan ONNX Runtime).
   - Secara konsisten menyamai atau mengungguli RTen dan mendekati kinerja MNN C++ asli di seluruh dokumen uji sembari mempertahankan **paritas akurasi transkripsi karakter 100% identik**.
2. **RTen (Backend Rust Murni)**:
   - Menyediakan eksekusi Rust murni untuk model berformat `.rten` dengan jejak RSS puncak terendah (**177.8 MB hingga 200.1 MB**).
   - Mengompilasi menjadi biner WebAssembly super ramping berukuran **238 KB** gzipped (646 KB tanpa kompresi pada `rusto-wasm`) untuk eksekusi browser langsung tanpa backend.
3. **ONNX Runtime Langsung (C++ ORT)**:
   - Menyediakan inferensi CPU yang cepat berkat optimasi thread pool dan kernel graf yang matang.
   - Memerlukan distribusi shared library dinamis (`libonnxruntime.so` / `.dylib` / `.dll`), menambah friksi packaging pada kontainer dan target aplikasi lintas platform.
4. **Alibaba MNN C++ Runtime**:
   - Eksekusi CPU mentah yang cepat berkat microkernel vektor tingkat assembly, namun memerlukan skrip build C++ kustom, konfigurasi linker, dan dynamic linking.
5. **PaddlePaddle (Framework PaddleOCR)**:
   - Implementasi resmi Python dengan fleksibilitas GPU tinggi, namun memiliki overhead memori yang sangat besar (mencapai 10.6 GB RSS saat analisis tata letak) serta dependensi deployment Python yang kompleks.

## 3. Ucapan Terima Kasih & Penghargaan

- **[DataLab](https://github.com/datalab-to)**: Penghargaan istimewa kepada DataLab atas perancangan dan pembukaan sumber arsitektur model **[Indra OCR](https://github.com/datalab-to/indra-ocr)** serta kurasi dataset evaluasi **[OmniDocBench](https://github.com/datalab-to/omnidocbench)**.

- **[RapidOCR](https://github.com/RapidAI/RapidOCR)**: Referensi arsitektur pipeline OCR dan baseline evaluasi komparatif.
- **[RTen](https://github.com/robertknight/rten)**: Mesin inferensi deep learning berbasis Rust murni untuk dukungan model RTen.
