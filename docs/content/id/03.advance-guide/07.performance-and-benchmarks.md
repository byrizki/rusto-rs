## 1. Evaluasi Komprehensif OmniDocBench

Dievaluasi terhadap dataset riil yang beragam **OmniDocBench** (dibuat oleh [DataLab](https://github.com/datalab-to), mencakup jurnal ilmiah, buku teks, surat kabar, majalah, slide presentasi, dan lembar ujian) yang membandingkan RustO asli (berbasis `rten 0.27.0` resmi) dengan PaddleOCR resmi Python dan RapidOCR (C++ ONNX Runtime), serta pipeline resmi Indra OCR dari DataLab.

## 2. Perbandingan Mesin Inferensi Asli (Head-to-Head)

Dievaluasi pada input berukuran tetap (Deteksi: 640×640, Pengenalan: 16 potongan) membandingkan mesin inferensi machine learning asli pada latensi eksekusi, jejak biner, dan dependensi runtime:

| Metrik / Dimensi                        |   RTen (Rust Murni `.rten`)    |   ONNX Langsung (C++ ORT)    |       MNN (C++ FFI Asli)        |       Tract (Rust Murni)       |
| :-------------------------------------- | :----------------------------: | :--------------------------: | :-----------------------------: | :----------------------------: |
| **Bahasa Inti & Arsitektur Mesin**      |         **Rust Murni**         |           C++ FFI            |             C++ FFI             |         **Rust Murni**         |
| **Format Serialisasi Model**            |    **FlatBuffers `.rten`**     |   Protocol Buffers `.onnx`   |       `.mnn` kepemilikan        |    Protocol Buffers `.onnx`    |
| **Dependensi Runtime & Linker**         | **Nihil (100% tautan statis)** |  Shared library C++ dinamis  | Shared library C++ terkompilasi | **Nihil (100% tautan statis)** |
| **Waktu Pemuatan Awal Model**           |          **17.53 ms**          |           38.80 ms           |           **5.20 ms**           |            45.10 ms            |
| **Deteksi (640×640)**                   |            51.17 ms            |           35.49 ms           |          **~24.5 ms**           |           191.04 ms            |
| **Latensi Pengenalan (Rata-rata/Crop)** |            3.26 ms             |           1.86 ms            |          **~0.95 ms**           |            8.19 ms             |
| **Total Pengenalan (16 potongan)**      |            52.19 ms            |           29.78 ms           |          **~15.2 ms**           |           130.99 ms            |
| **Total Latensi Inferensi Neural**      |         **103.36 ms**          |           65.27 ms           |          **~39.7 ms**           |           322.03 ms            |
| **Total Pipeline Ujung-ke-Ujung**       |         **678.08 ms**          |          447.83 ms           |            479.07 ms            |           ~1.100 ms            |
| **Ukuran Bundle WASM (gzipped)**        |           **517 KB**           |           ~3.78 MB           |   N/A (Memerlukan Emscripten)   |            1.99 MB             |
| **Portabilitas Lintas Platform**        |  **Universal (Native + Web)**  |   Biner spesifik platform    |      Mobile & Desktop C++       | Rust Murni (operator terbatas) |
| **Kemudahan Deployment**                | **Biner statis tanpa config**  | Setup library dinamis & path |  Toolchain kustom & FFI build   |    Biner statis Rust Murni     |

### Poin Utama Arsitektur & Tradeoff Mesin

1. **RTen (Bawaan Rust Murni RustO!)**:
   - Memberikan pengalaman pengembang terbaik dan portabilitas lintas platform universal.
   - Menghilangkan seluruh dependensi toolchain C/C++, terhubung secara mulus ke aplikasi native serta mengompilasi menjadi biner WebAssembly super ramping berukuran **517 KB** untuk eksekusi browser langsung.
   - Pemetaan memori FlatBuffers zero-copy memungkinkan inisialisasi awal model hanya dalam **17.53 ms**.
2. **ONNX Runtime Langsung (C++ ORT)**:
   - Menyediakan inferensi CPU yang cepat (65.27 ms total inferensi neural) berkat optimasi thread pool dan kernel graf yang matang.
   - Memerlukan distribusi shared library dinamis (`libonnxruntime.so` / `.dylib` / `.dll`), menambah friksi packaging pada kontainer dan target aplikasi lintas platform.
3. **Alibaba MNN**:
   - Eksekusi CPU mentah tercepat (~39.7 ms inferensi) berkat microkernel vektor tingkat assembly.
   - Memerlukan skrip build C++ kustom, konfigurasi linker, dan konversi model berpemilik.
4. **Tract**:
   - Eksekusi 100% Rust murni tanpa dependensi C++, namun latensi inferensi lebih tinggi (322.03 ms) pada jaringan konvolusional berdimensi dinamis.

## 3. Ucapan Terima Kasih & Penghargaan

- **[DataLab](https://github.com/datalab-to)**: Penghargaan istimewa kepada DataLab atas perancangan dan pembukaan sumber arsitektur model **[Indra OCR](https://github.com/datalab-to/indra-ocr)** serta kurasi dataset evaluasi **[OmniDocBench](https://github.com/datalab-to/omnidocbench)**.
- **[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)**: Untuk model-model pretrained seri PP-OCR (PP-OCRv6, PP-OCRv5, PP-OCRv4).
- **[RapidOCR](https://github.com/RapidAI/RapidOCR)**: Referensi arsitektur pipeline OCR dan baseline evaluasi komparatif.
- **[RTen](https://github.com/robertknight/rten)**: Mesin inferensi deep learning berbasis Rust murni yang mentenagai RustO! v0.3+.
