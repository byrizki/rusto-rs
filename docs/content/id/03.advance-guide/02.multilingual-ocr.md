RustO! menyediakan kapabilitas OCR untuk puluhan bahasa dan aksara. Untuk mempertahankan akurasi tinggi sekaligus menjaga ukuran berkas model tetap kecil, model dipisahkan menjadi **model dwibahasa inti (PP-OCRv6)** dan **paket bahasa regional khusus (PP-OCRv5 & PP-OCRv4)**.

---

## 1. Cakupan Bahasa PP-OCRv6 (Mandarin + Inggris / Latin)

Model bawaan **PP-OCRv6** dilatih terutama untuk **bahasa Mandarin dan Inggris**, dengan dukungan luas untuk bahasa-bahasa beraksara Latin umum:

| Varian / Tier | Jumlah Karakter Kamus | Cakupan Aksara & Karakter | Sangat Cocok Untuk |
| :--- | :--- | :--- | :--- |
| **PP-OCRv6 Tiny** (Bawaan) | **6.904 karakter** | Mandarin Sederhana, Inggris, alfabet Latin standar (Bahasa Indonesia, Spanyol, Prancis, Jerman), angka (0-9), tanda baca, serta simbol mata uang (`$`, `€`, `¥`, `£`, `Rp`). | Aplikasi mobile, struk belanja, faktur, dan dokumen umum berbahasa Indonesia, Inggris, atau Mandarin. |
| **PP-OCRv6 Small** & **Medium** | **18.708 karakter** | Seluruh karakter pada varian Tiny ditambah karakter Hanzi Tradisional, glif CJK langka, serta aksara Kana Jepang (Hiragana dan Katakana). | Pemindaian dokumen campuran Mandarin, Kana Jepang, dan aksara Latin. |

> **Penting**: Model PP-OCRv6 **tidak** mendukung Hangul Korea, Arab, Sirilik, Dewanagari (Hindi), Thai, Yunani, atau aksara India Selatan. Untuk aksara-aksara tersebut, gunakan paket model bahasa khusus di bawah ini.

## 3. Cara Mengganti Model Bahasa di Kode

Cukup pertahankan detektor batas teks universal (`det.rten`) dan arahkan konfigurasi pengenalan ke model bahasa regional yang telah Anda unduh:

### Pada Rust:
```rust
use rusto::{InitializeConfig, RustO};

// Inisialisasi dengan detektor universal + model pengenal bahasa Jepang
let config = InitializeConfig::ppv4(
    "models/det.rten",
    "models/japan_rec.rten",
    "models/japan_dict.txt",
);

let mut ocr = RustO::initialize(config)?;
let results = ocr.detect_text_file("struk_jepang.jpg")?;
```

### Pada Node.js:
```typescript
import { RustO } from '@rustors/node';

const ocr = new RustO({
  detModelPath: 'models/det.rten',
  recModelPath: 'models/arabic_rec.rten',
  dictPath: 'models/arabic_dict.txt',
});

const lines = await ocr.detectTextFile('faktur_arab.pdf');
```

### Pada Python:
```python
import rusto

engine = rusto.RustOEngine.from_config(
    '{"detection":{"model_path":"models/det.rten"},"recognition":{"model_path":"models/korean_rec.rten","dict_path":"models/korean_dict.txt"}}'
)

lines = engine.detect_text_file("dokumen_korea.png")
```

## 5. Bahasa Kanan-ke-Kiri (RTL)

Saat memproses bahasa seperti **Arab, Persia, atau Urdu**:
- Mesin pengenal membaca karakter sesuai arah visual potongan gambar dari kiri ke kanan.
- Titik koordinat poligon pada keluaran terstruktur merefleksikan posisi sebenarnya pada dokumen.
- Pada mode teks spasial (`OutputGranularity::Spatial`), perataan baris menyusun kata-kata berdasarkan posisi spasial aslinya.
