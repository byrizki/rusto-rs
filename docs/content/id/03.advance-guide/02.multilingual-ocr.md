RustO! menghadirkan kemampuan OCR multibahasa mutakhir yang mendukung beragam aksara, alfabet, dan tipografi di lebih dari 50 bahasa.

## 1. Model Terpadu 50 Bahasa PP-OCRv6 (Direkomendasikan)

PP-OCRv6 memperkenalkan jaringan pengenalan terpadu (`rec.mnn` + `ppocrv6_dict.txt`) yang mampu mengenali berbagai macam aksara sekaligus dalam satu dokumen campuran tanpa perlu mengganti model atau kamus:

| Rumpun Aksara     | Bahasa yang Didukung                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------- |
| **Latin**         | Bahasa Indonesia, Inggris, Spanyol, Prancis, Jerman, Portugis, Italia, Vietnam, Turki, Belanda, dll. |
| **Sirilik**       | Rusia, Ukraina, Belarusia, Bulgaria, Serbia, Makedonia, Kazakh, dll.                                 |
| **CJK**           | Mandarin Sederhana, Mandarin Tradisional, Jepang (Kanji/Hiragana/Katakana), Korea (Hangul).          |
| **Dewanagari**    | Hindi, Marathi, Sansekerta, Nepal, Bhojpuri, dll.                                                    |
| **Arab / Persia** | Arab, Persia (Farsi), Urdu, Uighur, Pashto.                                                          |
| **Asia Tenggara** | Thai, Lao, Khmer, Burma.                                                                             |
| **Lainnya**       | Yunani, Ibrani, Georgia, Armenia.                                                                    |

## 3. Memuat Model Bahasa Khusus dalam Kode

### Pada Rust:

```rust
use rusto::{InitializeConfig, RustO};

// Memuat model pengenalan bahasa Jepang
let config = InitializeConfig::ppv4(
    "models/det.mnn",
    "models/japan_rec.mnn",
    "models/japan_dict.txt",
);

let mut ocr = RustO::initialize(config)?;
```

### Pada .NET / C#:

```csharp
using RustODotnet;

var config = new InitializeConfig
{
    Template = "ppv5",
    Recognition = new RecognitionConfig
    {
        ModelPath = "models/arabic_rec.mnn",
        DictPath = "models/arabic_dict.txt"
    }
};

using var ocr = RustO.Initialize(config);
```
