Skenario kendala umum di berbagai platform beserta langkah-langkah solusinya.

## 1. Berkas & Aset Model Tidak Ditemukan

### Gejala

Muncul eksepsi saat inisialisasi: `Failed to initialize RustO with config`, `Model asset not found`, atau `FileNotFoundException`.

### Penyebab

Mesin tidak dapat menemukan file `det.mnn`, `rec.mnn`, atau `dict.txt` pada direktori kerja aktif atau bundel aplikasi.

### Solusi

- **Rust / CLI / C FFI**: Pastikan path relatif dihitung dari direktori kerja aktif saat ini, atau gunakan path absolut (contoh: `/usr/share/models/det.mnn`).
- **.NET / C#**: Pastikan Anda telah memasang paket model NuGet (misal `RustODotnet.Models.PPOCRv6.Tiny`) atau menyalin berkas model dengan opsi `<CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>` pada file `.csproj`.
- **iOS / Swift**: Pastikan Anda telah menambahkan `pod 'RustO-Models-PPOCRv6-Tiny'` pada `ios/Podfile` dan menjalankan `pod install`.
- **Android**: Pastikan paket `rusto-models-ppocrv6-tiny` dideklarasikan di `app/build.gradle` dan Anda meneruskan `Context` Android ke `RustO.initialize(context)`.

## 2. Android: UnsatisfiedLinkError atau Simbol JNI Tidak Ditemukan

### Gejala

`java.lang.UnsatisfiedLinkError: dlopen failed: library "librusto.so" not found`.

### Solusi

Pastikan konfigurasi `build.gradle` aplikasi Anda tidak memfilter ABI yang didukung. Tambahkan filter ABI standar pada `android.defaultConfig.ndk`:

```groovy
android {
    defaultConfig {
        ndk {
            abiFilters 'arm64-v8a', 'armeabi-v7a', 'x86_64', 'x86'
        }
    }
}
```

## 3. React Native: "The package 'react-native-rusto' doesn't seem to be linked"

### Gejala

Kesalahan saat memanggil `initialize()` atau `detectText()` pada React Native.

### Solusi

1. **Bare React Native**:
   - iOS: Jalankan `cd ios && pod install`, lalu kompilasi ulang dengan `npm run ios`.
   - Android: Bersihkan cache Gradle dengan `cd android && ./gradlew clean`, lalu kompilasi ulang.
2. **Expo**: Pustaka native C/Rust kustom tidak dapat dijalankan di Expo Go bawaan. Anda harus menggunakan _development build_:
   ```bash
   npx expo run:ios
   # atau
   npx expo run:android
   ```

## 4. Kehabisan Memori (OOM) pada Foto Kamera Resolusi Tinggi

### Gejala

Aplikasi mengalami _crash_ karena kehabisan memori RAM saat memindai foto kamera beresolusi sangat besar (48MP, 108MP).

### Solusi

Batasi dimensi maksimum gambar pada `OcrRunOptions` sebelum gambar diproses oleh jaringan inferensi:

```typescript
const safeOptions = {
  maxSideLen: 1600, // Menurunkan skala dimensi sebelum alokasi memori
  detection: {
    limitSideLen: 960,
    limitType: 'max',
  },
};
```

## 5. Teks Struk Termal Pudar atau Dot-Matrix Tidak Terdeteksi

### Gejala

Teks pada kertas termal atau struk dot-matrix terlewat atau terpotong-potong.

### Solusi

Aktifkan dilatasi morfologi 2x2 dan turunkan ambang binarisasi:

```typescript
const receiptOptions = {
  textScore: 0.45,
  postprocess: {
    useDilation: true, // Menyambungkan kembali karakter yang putus
    threshold: 0.25, // Menurunkan batas binarisasi piksel
    unclipRatio: 2.2, // Memperluas area batas poligon
  },
};
```
