RustO! menyediakan jalur pembaruan terstruktur antar rilis versi utama. Pelajari panduan migrasi yang relevan di bawah ini untuk memahami perubahan yang memutus kompatibilitas (breaking changes), transisi format model, dan API yang direkomendasikan.

---

## 🚀 Peningkatan dari v0.3 ke v0.4

RustO! **v0.4.0** menetapkan DataLab Indra OCR sebagai model unggulan bawaan (default flagship), mentransisikan mesin inferensi bawaan ke MNN berbasis Rust murni (`rusto-nn`) berdampingan dengan RTen, memisahkan seluruh bobot model ke dalam aset rilis mandiri yang dihosting di Hugging Face Hub (`byrizki/rusto-models`), memperkenalkan pemulihan urutan baca neural berbasis transformer, serta menambahkan pipeline penyempurnaan dokumen multi-tahap.

### ⚡ Ringkasan Peningkatan v0.3 ke v0.4

| Aspek                     | v0.3.x                                      | v0.4.0 (Terkini)                                                         |
| :------------------------ | :------------------------------------------ | :----------------------------------------------------------------------- |
| **Model Mesin Bawaan**    | `ppocrv6-tiny` (~6 MB)                      | **`indraocr`** (~5.5 MB, **45,98%** akurasi OmniDoc)                     |
| **Mesin Inferensi**       | RTen                                        | **Pure-Rust MNN (`rusto-nn`)** + backend RTen                            |
| **Distribusi Model**      | Paket platform & berkas terbundel           | **Berkas mandiri model** di Hugging Face Hub                             |
| **Unduh Otomatis Model**  | Penempatan manual atau jalur lokal          | **Pencarian 3 lapis deterministik & unduh otomatis** ke cache            |
| **Pembacaan Multi-Kolom** | Pemindaian horizontal naif / teks bercampur | **Transformer Urutan Baca Neural (`indra_order.rten`)**                  |
| **Deteksi Tata Letak**    | Model tata letak lawas                      | **PP-Structure v3 / Rapid Layout (`layout_cdla.rten`, `publaynet`)**     |
| **Dewarping Dokumen 3D**  | Tidak ada / perlu prapemrosesan eksternal   | **Jaringan unwarp 3D UVDoc terintegrasi (`uvdoc.rten`)**                 |
| **Orientasi Dokumen**     | Hanya sudut tetap                           | **Orientasi 4 arah dinamis (`indra_orient.rten` / `ppocr_orient.rten`)** |
| **CLI Pra-unduh Model**   | Skrip manual `curl` / `wget`                | **Subperintah khusus `rusto download`**                                  |

### 1. Model Bawaan Unggulan: Indra OCR (`indraocr`)

Model kanonikal bawaan yang dipilih oleh `RustO::initialize()` dan CLI kini adalah **`indraocr`** (DataLab, `datalab-to/indra-ocr`).

- **Akurasi & Latensi OmniDocBench**: Rata-rata latensi dokumen penuh adalah **1.780,2 ms** dengan akurasi karakter dasar **45,70%** (mencapai **63,90%** pada Full Pipeline dengan pengurutan urutan baca neural) dan puncak RAM **190.5 MB - 193.9 MB** RSS, mengungguli PaddleOCR dan RapidOCR.
- **Akurasi Dokumen Indonesia & Regional**: Dilatih khusus untuk kosakata vernakular Indonesia, KTP/SIM, formulir pajak, dan struk belanja lokal, dengan akurasi pengenalan teks Latin yang unggul.
- **Alternatif ultra-ringan**: Tentukan `model: "ppocrv6-tiny"` (~6 MB) secara eksplisit jika aplikasi Anda memiliki batasan ukuran unduhan yang ketat.

```typescript
// v0.4 default menyelesaikan ke indraocr dengan caching otomatis
const ocr = RustO.initialize();

// Atau minta secara eksplisit PP-OCRv6 Tiny jika dibutuhkan
const lightOcr = RustO.initialize({ model: 'ppocrv6-tiny' });
```

### 2. Pemisahan Model Mandiri & Hosting di Hugging Face Hub

Paket bobot model terpisah per platform (seperti `rusto-models-ppocrv6-tiny-*.aar`, `RustODotnet.Models.*`, `@rustors/model-*`) kini telah dihapus.

- **Biner aplikasi tetap ramping**: Ukuran paket inti tetap di bawah 10 MB tanpa bloat bobot model.
- **Unduh otomatis sesuai kebutuhan**: RustO! memeriksa jalur pengguna, lalu `~/.cache/rusto/models`, dan mengunduh berkas model yang dibutuhkan langsung dari Hugging Face Hub (`byrizki/rusto-models`).
- **Hapus dependensi model lama** dari `package.json`, `build.gradle`, atau `.csproj`.

```diff
  // package.json
  "dependencies": {
-   "@rustors/model-ppocrv6-tiny": "^0.3.0",
    "@rustors/node": "^0.4.0"
  }
```

### 3. Transformer Urutan Baca & Alur Tata Letak (`indra_order.rten`)

Dokumen multi-kolom tidak lagi mengalami masalah kalimat bercampur horizontal.

- **`indra_order.rten`** (~2.9 MB) dari Indra OCR bekerja selayaknya transformer penata urutan tata letak, menyusun alur baca alami antar kolom.
- Aktifkan melalui `enableReadingOrder: true` pada kode atau opsi `--reading-order` pada CLI.

```bash
rusto ocr two_column_paper.pdf --reading-order --format text-ordered
```

### 4. Pipeline Penyempurnaan Dokumen Opsional

Tahapan tambahan modular yang dapat dipasang ke pipeline OCR dasar:

- **Dewarping Geometris (`uvdoc.rten`, ~30 MB)**: Meratakan kelengkungan 3D (buku tebal, kuitansi kusut) sebelum deteksi DBNet.
- **Orientasi Dinamis (`orient.rten` / `indra_orient.rten`, ~6.4 MB)**: Mendeteksi rotasi 0°/90°/180°/270° dan memutar kanvas tegak lurus.
- **Deteksi Tata Letak (`layout_cdla.rten` / `layout_publaynet.rten`)**: Segmentasi semantik 10 kelas atau 5 kelas.
- **Pengklasifikasi Arah Baris (`cls.rten`, ~585 KB)**: Membalik baris teks yang terbalik 180° ke posisi tegak.

```typescript
const ocr = RustO.initialize({
  model: 'indraocr',
  enableReadingOrder: true,
  layoutVariant: 'cdla',
  unwarp: { enabled: true },
  orientation: { enabled: true, thresh: 0.85 },
});
```

### 5. CLI Pengunduh Model Khusus (`rusto download`)

Unduh model terlebih dahulu untuk sistem tanpa internet (offline), citra Docker, atau runner CI:

```bash
rusto download
rusto download --model ppocrv6-tiny
rusto download --all
```

### 6. API Fluent Builder Chaining & Opsi Pipeline 6 Fase

Pada v0.4.0, metode deteksi teks beralih ke API fluent builder chaining yang bersih dan selalu diakhiri dengan `.run()`, menggantikan objek konfigurasi yang rumit dan panggilan terpisah seperti `detect_layout` / `unwarp`:

- **Konsisten `.run()`**: Setiap rangkaian builder selalu dieksekusi dengan `.run()` di seluruh 11 binding platform.
- **Tata Letak & Unwarp Terintegrasi**: Diaktifkan langsung melalui `.withLayoutReading()` dan `.withAutoUnwarp()`.
- **6 Fase Eksekusi Terstruktur**: Dikelompokkan ke dalam `preDetection`, `detection`, `postDetection`, `preRecognition`, `recognition`, dan `postRecognition`.
- **4 Sakelar Pipeline Boolean**: `withAutoUnwarp()`, `withLayoutReading()`, `withOrientationDetection()`, dan `withLineClassification()`.

#### Perbandingan Kode (TypeScript / Node.js)

```typescript
// ❌ v0.3.x: Objek opsi konfigurasi bersarang yang rumit
const results = await engine.detectTextFile(
  'invoice.png',
  JSON.stringify({
    unwarp: true,
    layout: true,
    postprocess: { useDilation: true },
  })
);

// ✅ v0.4.0: Chaining fluent builder yang diakhiri dengan .run()
const results = engine
  .detectText('invoice.png')
  .withAutoUnwarp()
  .withLayoutReading()
  .withPostDetection({ useDilation: true })
  .asLines()
  .run();
```

#### Perbandingan Kode (Rust)

```rust
// ❌ v0.3.x: Struct monolitik dengan pemanggilan terpisah
let options = OcrRunOptions {
    unwarp: Some(true),
    layout: Some(true),
    postprocess: Some(PostprocessRunOptions { use_dilation: Some(true), ..Default::default() }),
    ..Default::default()
};
let result = ocr.detect_text(&image, &options)?;

// ✅ v0.4.0: Chaining fluent builder dengan tahapan pipeline terintegrasi
let result = ocr.detect_text_builder(image)
    .with_auto_unwarp(true)
    .with_layout_reading(true)
    .with_post_detection(PostDetectionOptions { use_dilation: Some(true), ..Default::default() })
    .asLines()
    .run()?;
```

## 📦 Peningkatan dari v0.2 ke v0.3

RustO! **v0.3.0** mentransisikan mesin inferensi ke pure Rust RTen, menghapus toolchain C++/CMake, serta memisahkan opsi ke `InitializeConfig` dan `OcrRunOptions`.

### ⚡ Ringkasan v0.2 ke v0.3

| Aspek                    | v0.2.x                               | v0.3.0                                                                           |
| :----------------------- | :----------------------------------- | :------------------------------------------------------------------------------- |
| **Mesin Inferensi Inti** | Alibaba MNN (memerlukan C++ / CMake) | **Pure Rust [RTen](https://github.com/robertknight/rten)** (tanpa toolchain C++) |
| **Format Model**         | Format `.mnn` proprietari            | FlatBuffers **`.rten`** atau standar **`.onnx`**                                 |
| **API Sesi Inferensi**   | `MnnSession`                         | **`EngineSession`** (mengimplementasikan `InferenceSession`)                     |
| **Model Konfigurasi**    | Blok `preprocessing` bersarang       | Pemisahan **`InitializeConfig`** & **`OcrRunOptions`**                           |
| **Nama Paket NPM**       | Mandiri (`react-rusto`, `rusto-web`) | Lingkup **`@rustors/*`** (`@rustors/react`, `@rustors/web`)                      |

### Format Model & API Sesi

Model format `.mnn` digantikan dengan FlatBuffers `.rten` atau `.onnx`. `MnnSession` digantikan oleh `EngineSession` generik:

```rust
use rusto::session::EngineSession;

let det_session = EngineSession::from_det_config(&config.det)?;
let rec_session = EngineSession::from_rec_config(&config.rec)?;
```

### Pemisahan Konfigurasi Statis & Opsi Runtime

Opsi dipisahkan menjadi inisialisasi statis satu kali (`InitializeConfig`) dan opsi per pemanggilan inferensi (`OcrRunOptions`):

```rust
use rusto::{InitializeConfig, OcrRunOptions, OutputGranularity, RustO};

// Inisialisasi statis (thread-safe, dimuat satu kali)
let mut ocr = RustO::initialize(InitializeConfig::from_json(r#"{"model":"indraocr"}"#)?)?;

// Opsi per permintaan inferensi (stateless, concurrent)
let mut options = OcrRunOptions::default();
options.detection.box_threshold = 0.6;
options.output_granularity = OutputGranularity::Lines;

let result = ocr.detect_text(&image, &options)?;
```

### Migrasi Namespace Paket (`@rustors/*`)

Seluruh paket npm dipindahkan ke lingkup resmi organisasi `@rustors`:

| Paket Lawas (v0.2)   | Paket Resmi (v0.3+)                                                            | Catatan                        |
| :------------------- | :----------------------------------------------------------------------------- | :----------------------------- |
| `react-native-rusto` | [`@rustors/react-native`](https://www.npmjs.com/package/@rustors/react-native) | Bridge native JNI/TurboModule  |
| `rusto-web`          | [`@rustors/web`](https://www.npmjs.com/package/@rustors/web)                   | Mesin browser WASM RTen        |
| `react-rusto`        | [`@rustors/react`](https://www.npmjs.com/package/@rustors/react)               | Provider konteks & hooks React |

### Daftar Periksa Migrasi

- [ ] **Langkah 1**: Gunakan bobot model yang dihosting di Hugging Face Hub (`byrizki/rusto-models`).
- [ ] **Langkah 2**: Perbarui dependensi ke rilis terbaru (menggunakan `@rustors/*` untuk npm).
- [ ] **Langkah 3**: Hapus dependensi paket model lawas (`rusto-models-*`, `@rustors/model-*`).
- [ ] **Langkah 4**: Pisahkan `InitializeConfig` statis dari `OcrRunOptions` per gambar.
- [ ] **Langkah 5**: Aktifkan `--reading-order` atau `enableReadingOrder: true` untuk dokumen multi-kolom.
- [ ] **Langkah 6**: Validasi keluaran teks OCR dan poligon pembatas pada gambar pengujian.
