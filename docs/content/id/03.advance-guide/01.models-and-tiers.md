Saat mengintegrasikan RustO! ke dalam aplikasi atau layanan Anda, salah satu keputusan arsitektural utama adalah **memilih tingkatan model yang tepat** dan **menentukan cara mendistribusikan bobot model** ke pengguna akhir.

RustO! memisahkan biner pustaka inti yang ringan dari berkas bobot model. Panduan ini dirancang dari sudut pandang pengembang untuk membantu Anda menentukan model yang paling sesuai dengan kebutuhan aplikasi serta memilih metode pengunduhan yang paling efisien.

---

## 1. Panduan Cepat Pengambilan Keputusan: Model Mana yang Harus Saya Pilih?

| Lingkungan Target / Kebutuhan Anda | Rekomendasi Model | Ukuran Arsip | Kecepatan Inferensi (CPU) | Alasan Memilih Varian Ini |
| :--- | :--- | :--- | :--- | :--- |
| **Aplikasi Mobile (iOS / Android / RN / Flutter)** | **PP-OCRv6 Tiny (FP32)** *(Bawaan Direkomendasikan)* | **~6.0 MB** | ⚡ 30–60 ms | Akurasi sangat tinggi dengan konsumsi baterai/CPU minimal dan startup instan. |
| **Memori Sangat Terbatas / Embedded (IoT, Low RAM)** | **PP-OCRv6 Tiny (INT8)** | **~2.8 MB** | ⚡ 20–40 ms | 50% lebih kecil, terkuantisasi integer 8-bit dengan perbedaan akurasi karakter <0.5%. |
| **Aplikasi Desktop & Server Edge Ringan** | **PP-OCRv6 Small (FP32)** | **~30 MB** | ⏱️ 80–150 ms | Arsitektur backbone lebih tangguh dengan daya tangkap tinggi untuk teks kecil, struk padat, dan teks miring. |
| **Cloud Server & Pengarsipan Dokumen Skala Besar** | **PP-OCRv6 Medium (FP32)** | **~134 MB** | ⏱️ 200–450 ms | Presisi terbaik untuk formulir rumit, laporan multi-kolom, dan hasil scan berkualitas rendah. |
| **Bahasa Jepang / Tradisional Tionghoa** | **PP-OCRv4 Japanese / TradChinese** | **~25 MB** | ⏱️ 60–120 ms | Dilengkapi kamus karakter khusus untuk Kanji, Kana, dan glif tradisional. |
| **Multibahasa (Arab, Sirilik, Korea, dll.)** | **PP-OCRv5 Language Packs** | **~28 MB** | ⏱️ 60–110 ms | Model pengenalan dan kamus khusus untuk aksara regional non-Latin. |

### Pendekatan B: Manajer Paket Bawaan (Tanpa Pengunduhan Manual)

Jika mengembangkan aplikasi untuk iOS, Android, atau .NET, Anda tidak perlu mengunduh file secara manual. Cukup cantumkan bundel model pada konfigurasi proyek:

#### 1. iOS (CocoaPods)
Pada file `Podfile`:
```ruby
pod 'RustO-Models-PPOCRv6-Tiny', '~> 0.2.4'
```
Pustaka secara otomatis menemukan model di dalam bundel pod saat Anda memanggil `try RustO.initialize()`.

#### 2. Android (Gradle)
Pada `android/app/build.gradle`:
```groovy
dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-models-ppocrv6-tiny:v0.2.4'
}
```
Model tersemat pada aset AAR dan diekstrak secara otomatis saat mesin pertama kali diinisialisasi.

#### 3. .NET (NuGet)
```bash
dotnet add package RustODotnet.Models.PPOCRv6.Tiny
```
MSBuild secara otomatis menyalin aset `.rten` dan `dict.txt` ke direktori keluaran aplikasi Anda.

### Pendekatan C: Skrip Pengunduh CLI (Pengembangan & CI)

Gunakan skrip shell bawaan untuk kemudahan proses pengembangan lokal maupun jalur otomatisasi CI/CD:

```bash
# 1. Unduh model bawaan default PP-OCRv6 Tiny FP32
bash scripts/download_models.sh --model ppocrv6 --tier tiny --output-dir models/PPOCR_v6_tiny

# 2. Unduh model kuantisasi PP-OCRv6 Tiny INT8 (~2.8 MB)
bash scripts/download_models.sh --model ppocrv6 --tier tiny --int8 --output-dir models/PPOCR_v6_tiny_int8

# 3. Unduh model PP-OCRv6 Small
bash scripts/download_models.sh --model ppocrv6 --tier small --output-dir models/PPOCR_v6_small

# 4. Unduh paket aksara Jepang
bash scripts/download_models.sh --model ppocrv4 --tier mobile --lang japan --output-dir models/PPOCR_v4_japan
```

## 4. Perbedaan Format Model: `.rten` vs `.onnx` vs `_int8`

- **`.rten` (Bawaan Direkomendasikan)**:
  - Dirancang khusus untuk pustaka inferensi Rust murni [RTen](https://github.com/robertknight/rten).
  - Mendukung pemetaan memori _zero-copy_ (`mmap`), sehingga sistem operasi dapat berbagi halaman memori model tanpa alokasi heap berlebih.
  - Bebas dependensi C/C++ maupun pustaka ONNX eksternal.
  - Terakselerasi SIMD pada prosesor modern (AVX2, AVX-512, dan ARM NEON).
- **`.onnx`**:
  - Digunakan jika Anda menghubungkannya dengan ONNX Runtime (`ort`) atau WebAssembly pada browser.
- **`_int8.rten` (Terkuantisasi)**:
  - Bobot diubah menjadi representasi integer 8-bit.
  - Mengurangi ukuran berkas dan penggunaan RAM hingga ~50–60%.
  - Hingga 2x lebih cepat dalam transfer memori perangkat mobile dengan perbedaan akurasi karakter <0.5%.

## 5. Memverifikasi Integritas Berkas Model

Setiap rilis menyertakan berkas manifes `SHA256SUMS`. Untuk memverifikasi integritas arsip yang Anda unduh:

```bash
# Di Linux / macOS
sha256sum -c SHA256SUMS --ignore-missing

# Atau verifikasi satu berkas arsip:
sha256sum RustO-Models-PPOCRv6-Tiny.zip
```
