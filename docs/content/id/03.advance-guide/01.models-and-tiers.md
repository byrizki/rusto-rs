RustO! memisahkan mesin runtime inti dari berkas bobot model agar biner rilis aplikasi Anda tetap ramping (di bawah 10 MB) dan bebas dari ketergantungan paket bawaan yang membengkak.

Jika Anda baru pertama kali mencoba dan bingung memilih model: **mulai dengan `ppocrv6-tiny` (bawaan, FP32, Apache 2.0)**. Berukuran ~5.9–6.1 MB, model ini mencatat akurasi dasar **46,53%** (**62,72%** dengan urutan baca heuristik Rust murni, **57,91%** pada pipeline penuh CDLA) di lebih dari 50 bahasa/aksara dengan lisensi permisif Apache 2.0. Untuk batasan memori atau penyimpanan perangkat edge/mobile yang lebih ketat, pilih **`ppocrv6-tiny-fp16`** (~3.1 MB pada `rusto-nn` / `rusto-webgpu`) atau **`ppocrv6-tiny-int8`** (~3.3–3.4 MB). DataLab **`indraocr`** (~5.4 MB) tetap tersedia sebagai opsi dengan akurasi **45,70%** dasar / **63,90%** full pipeline (catatan: bobot Indra OCR menggunakan lisensi OpenRAIL-M termodifikasi).

## 1. Model Dasar OCR Kanonikal

RustO! menyediakan model dasar kanonikal resmi yang dapat langsung ditentukan melalui nama (misalnya `model = "ppocrv6-tiny"`, `model = "ppocrv6-tiny-fp16"`, `model = "ppocrv6-tiny-int8"`, `model = "indraocr"`). Model dasar menggabungkan deteksi, rekognisi, dan kamus:

| Model Kanonikal               | Target Lingkungan / Kasus Penggunaan                                       |  Ukuran Dasar   |               Latensi Rata-Rata OmniDocBench                | Keunggulan Utama                                                                                                                                                                                             |
| :---------------------------- | :------------------------------------------------------------------------- | :-------------: | :---------------------------------------------------------: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ppocrv6-tiny`** _(Bawaan)_ | Aplikasi mobile (iOS, Android, React Native, Flutter), Web, & CLI          | **~5.9–6.1 MB** |  **1.127,7 ms** (`rusto-nn`) / **996,2 ms** (`rusto-rten`)  | Model bawaan FP32 berlisensi permisif Apache 2.0 dengan akurasi dasar **46,53%** (**62,72%** urutan baca heuristik) pada lebih dari 50 aksara.                                                               |
| **`ppocrv6-tiny-fp16`**       | CLI edge ringan, mobile, & Web/WebGPU (khusus `rusto-nn` / `rusto-webgpu`) |   **~3.1 MB**   |                 **1.142,8 ms** (`rusto-nn`)                 | Bobot half-precision `.mnn` / `.onnx` yang memangkas ukuran hampir 50% dengan akurasi **46,57%** (+0,04 pp vs FP32). Catatan: hanya didukung `rusto-nn` dan `rusto-webgpu` (tidak didukung di `rusto-rten`). |
| **`ppocrv6-tiny-int8`**       | Perangkat edge, IoT, dan mobile dengan sumber daya terbatas                | **~3.3–3.4 MB** | **1.113,5 ms** (`rusto-rten`) / **1.821,8 ms** (`rusto-nn`) | Bobot terkuantisasi 8-bit untuk efisiensi jejak memori pada `.mnn`, `.onnx`, dan `.rten` dengan akurasi **45,52%–46,74%**.                                                                                   |
| **`indraocr`**                | Dokumen Indonesia: KTP, SIM, struk lokal, formulir, Latin                  |   **~5.4 MB**   |         **582,9 ms** (dasar) / **599,9 ms** (full)          | Model opsional dari DataLab (`datalab-to/indra-ocr`). Kecepatan tinggi, akurasi kosakata, dan pengenalan tata letak regional (bobot berlisensi OpenRAIL-M termodifikasi).                                    |
| **`ppocrv6-small`**           | Aplikasi desktop, microservice backend, dokumen padat                      |  **~30.5 MB**   |                 2,971.0 ms (dokumen penuh)                  | Arsitektur lebih dalam untuk teks kecil, tabel padat, dan noise pindaian.                                                                                                                                    |
| **`ppocrv6-small-int8`**      | Layanan backend berthroughput tinggi dan server microservice               |  **~16.1 MB**   |                 **6.970,7 ms** (`rusto-nn`)                 | Model small terkuantisasi 8-bit berukuran ringkas dengan akurasi OmniDocBench **45,14%** (`rusto-nn` / `rusto-webgpu`).                                                                                      |
| **`ppocrv6-medium-int8`**     | Kluster pemrosesan dokumen batch presisi maksimal                          |  **~75.9 MB**   |                **21.914,1 ms** (`rusto-nn`)                 | Arsitektur berkapasitas besar terkuantisasi 8-bit (akurasi OmniDocBench **44,59%**; beban komputasi CPU tinggi di `rusto-nn`).                                                                               |
| **`ppocrv5-mobile`**          | Baseline multibahasa mobile (Latin, Sirilik, Arab, Korea)                  |   **~21 MB**    |                 Paket multibahasa baseline                  | Baseline multibahasa teruji dengan dukungan orientasi baris 180° terintegrasi.                                                                                                                               |
| **`ppocrv5-server`**          | Pemrosesan server multibahasa presisi tinggi                               |   **~54 MB**    |                    Paket server baseline                    | Arsitektur SVTR berkapasitas besar dengan kamus 18.385 karakter untuk akurasi maksimal.                                                                                                                      |
| **`ppocrv4-mobile`**          | Bahasa Jepang (Kanji/Kana) & Tionghoa Tradisional (CHT)                    |   **~21 MB**    |                     Paket CJK baseline                      | Cakupan kamus aksara CJK lengkap serta kompatibilitas regional Kannada.                                                                                                                                      |
| **`ppocrv4-server`**          | Pemrosesan dokumen batch & CJK kapasitas server                            |   **~65 MB**    |                      Paket server CJK                       | Deteksi dan rekognisi teks kapasitas tinggi untuk dokumen Asia padat dan pindaian noisy.                                                                                                                     |

> [!NOTE]
> Paket bahasa multibahasa dan tahap pemahaman dokumen tambahan **tidak** digabungkan ke dalam paket pipeline dasar. Seluruhnya didistribusikan sebagai aset `.mnn` dan `.rten` mandiri yang modular.
>
> **Catatan Lisensi Bobot Indra OCR**: Kode upstream [`datalab-to/indra-ocr`](https://github.com/datalab-to/indra-ocr) berlisensi Apache 2.0, sedangkan **bobot modelnya** (`indraocr` dan `indra_order`) menggunakan lisensi **OpenRAIL-M termodifikasi** (gratis untuk riset, penggunaan pribadi, dan startup/entitas di bawah \$20 juta pendanaan atau pendapatan; dilarang bersaing dengan layanan API Datalab; lisensi komersial tersedia di [datalab.to/pricing](https://www.datalab.to/pricing)). Karena itu, RustO! memakai **`ppocrv6-tiny` (FP32, Apache 2.0)** sebagai bawaan.

## 2. Arsitektur Pipeline Modular

RustO! memisahkan secara tegas antara **Pipeline Dasar OCR** dan **Tahap Tambahan Opsional**:

```mermaid
flowchart TD
    subgraph BASE["Pipeline Dasar OCR (Inti Modular)"]
        DET["Deteksi Teks<br/>(det.mnn / det.rten)"] --> REC["Pengenalan Teks<br/>(rec.mnn + dict.txt / meta.json)"]
    end

    subgraph EXTRAS["Tahap Opsional Mandiri (Aset Terpisah)"]
        UNWARP["1. Unwarp Dokumen<br/>(uvdoc.mnn / uvdoc.rten)"]
        ORIENT["2. Orientasi Halaman<br/>(indra_orient.mnn / ppocr_orient.mnn)"]
        LAYOUT["3. Analisis Tata Letak<br/>(layout_cdla.mnn / layout_publaynet.mnn)"]
        CLS["4. Klasifikasi Sudut Baris<br/>(ppocr_cls.mnn / ppocr_cls.rten)"]
        ORDER["5. Pemulihan Urutan Baca<br/>(indra_order.mnn / indra_order.rten)"]
    end

    UNWARP -.-> BASE
    ORIENT -.-> BASE
    LAYOUT -.-> BASE
    BASE -.-> CLS
    BASE -.-> ORDER
```

### Karakteristik Aset Model:

- **Bobot dasar terpisah**: Pipeline dasar (`det` + `rec` + `dict`/`meta.json`) dan tahap opsional (`cls`, `orient`, `unwarp`, `layout`, `reading-order`) disediakan sebagai berkas `.mnn` atau `.rten` mandiri yang dapat dipasang secara dinamis.
- **Model Tata Letak PP-Structure v3 & Indra Layout / Reading Order**:
  - **`layout_cdla.mnn` / `layout_cdla.rten`** (5.8 MB): Segmentasi 10 kelas tata letak dokumen (Teks, Judul, Gambar, Keterangan Gambar, Tabel, Keterangan Tabel, Header, Footer, Referensi, Persamaan).
  - **`layout_publaynet.mnn` / `layout_publaynet.rten`** (5.2 MB): Segmentasi 5 kelas tata letak dokumen (Teks, Judul, Daftar, Tabel, Gambar).
  - **`indra_order.mnn` / `indra_order.rten`** (2.9 MB): Model urutan baca dan tata letak dari DataLab Indra OCR. Berfungsi menyusun baris teks multi-kolom ke urutan baca alami manusia.
- **Pemulihan Urutan Baca Cerdas (Neural Reading Order)**: Menggunakan transformer pemulihan urutan baca yang diaktifkan melalui opsi `--reading-order` atau `enableReadingOrder`.

## 3. Alur Resolusi Model

RustO! menerapkan alur pencarian deterministik 3 tingkat pada seluruh bahasa pemrograman dan CLI:

```mermaid
flowchart LR
    A["1. Lokasi Spesifik Pengguna<br/>(--model-path / modelPath / overrides)"] -->|Ditemukan| RUN["Jalankan Inferensi"]
    A -->|Tidak Ditemukan| B["2. Direktori Cache Lokal<br/>(~/.cache/rusto/models)"]
    B -->|Ditemukan| RUN
    B -->|Tidak Ditemukan| C["3. Unduh Otomatis<br/>(Hugging Face Hub)"]
    C -->|Unduh & Simpan ke Cache| RUN
```

1. **Jalur Spesifik Pengguna**: Jika jalur folder model (`--model-path` / `modelPath`) atau override komponen spesifik (`--det-model`, `--rec-model`, `--dict`) diberikan, RustO! akan memeriksa lokasi tersebut terlebih dahulu.
2. **Direktori Cache Lokal**: Jika tidak ditemukan di lokasi pengguna, RustO! mencari di folder cache (`~/.cache/rusto/models` atau `--cache-dir`).
3. **Unduh Otomatis**: Jika berkas belum ada di cache, RustO! secara otomatis mengunduh berkas model dan kosakata dari Hugging Face Hub (`https://huggingface.co/byrizki/rusto-models`) ke direktori cache.

## 4. Mengunduh Model

### Menggunakan CLI (`rusto download`)

Unduh model sebelum menjalankan aplikasi untuk skenario offline atau kontainer:

```bash
# Unduh model default (ppocrv6-tiny) ke direktori cache
rusto download

# Unduh model kanonikal tertentu
rusto download --model ppocrv6-small
rusto download --model indraocr

# Unduh paket bahasa regional
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang japan

# Unduh seluruh model kanonikal sekaligus
rusto download --all

# Menggunakan direktori cache kustom
rusto download --model ppocrv6-tiny --cache-dir /opt/models/cache
```

### Unduhan Terprogram di Berbagai Bahasa Pemrograman

```typescript
// TypeScript / Node.js & Web
import { RustO, downloadModel, isReady, version } from '@rustors/node';

const paths = RustO.downloadModel('ppocrv6-tiny', 'latin');
console.log(`RustO v${version()} ready: ${isReady()}`);
```

```python
# Python
from rusto import RustO, download_model, is_ready, version

paths = download_model(model="ppocrv6-tiny", lang="latin")
print(f"RustO v{version()} ready: {is_ready()}")
```

```csharp
// C# (.NET)
using RustODotnet;

string[] paths = RustO.DownloadModel("ppocrv6-tiny", "latin");
```

## 6. Verifikasi Checksum

Setiap rilis menyertakan berkas `SHA256SUMS`. Anda dapat memverifikasi integritas unduhan dengan:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```
