`OcrRunOptions` (dan API fluent `DetectTextBuilder` yang terpadu) mengonfigurasi parameter runtime untuk setiap eksekusi OCR individual. Pada v0.4.0, opsi runtime disusun berdasarkan **4 sakelar pipeline** dan **6 fase pemrosesan terpisah**.

Setiap opsi dapat diberikan melalui objek konfigurasi atau dirangkai secara langsung melalui metode builder berantai yang diakhiri dengan `.run()`.

```mermaid
flowchart TD
    A["Sumber Gambar Mentah"] --> U{"autoUnwarp?<br/>(withAutoUnwarp)"}
    U -->|true| U1["Ratakan Kelengkungan 3D Dokumen (UVDoc)"]
    U -->|false| L{"layoutReading?<br/>(withLayoutReading)"}
    U1 --> L
    L -->|true| L1["Segmen Tata Letak &amp; Alur Baca Dokumen"]
    L -->|false| O{"orientationDetection?<br/>(withOrientationDetection)"}
    L1 --> O
    O -->|true| O1["Putar Kanvas Menjadi Tegak 0&deg;/90&deg;/180&deg;/270&deg;"]
    O -->|false| P1["Fase 1: Pra-Deteksi<br/>(targetMaxSide, descreen)"]
    O1 --> P1
    P1 --> P2["Fase 2: Deteksi<br/>(limitSideLen, limitType, norm)"]
    P2 --> P3["Fase 3: Pasca-Deteksi<br/>(threshold, boxThreshold, unclipRatio)"]
    P3 --> C{"lineClassification?<br/>(withLineClassification)"}
    C -->|true| C1["Balik Baris Terbalik 180&deg;"]
    C -->|false| P4["Fase 4: Pra-Pengenalan<br/>(lineYThreshold, wordXThreshold)"]
    C1 --> P4
    P4 --> P5["Fase 5: Pengenalan Teks<br/>(batchSize, workers, maxWorkers)"]
    P5 --> P6["Fase 6: Pasca-Pengenalan<br/>(scoreThreshold)"]
    P6 --> OUT[".run() &rarr; DetectTextResult<br/>(lines / words / spatial / blocks)"]
```

## Spesifikasi Parameter

### 1. Sakelar Pipeline (Pipeline Toggles)

| Metode Sakelar                    | Properti Wire          | Tipe Data | Nilai Default | Deskripsi                                                                                    |
| --------------------------------- | ---------------------- | --------- | ------------- | -------------------------------------------------------------------------------------------- |
| `.withAutoUnwarp(bool)`           | `autoUnwarp`           | `boolean` | `false`       | Meratakan kelengkungan 3D halaman, lipatan kertas, dan distorsi punggung buku via UVDoc.     |
| `.withLayoutReading(bool)`        | `layoutReading`        | `boolean` | `false`       | Menganalisis tata letak dokumen dan memulihkan urutan alur baca kolom alami via transformer. |
| `.withOrientationDetection(bool)` | `orientationDetection` | `boolean` | `false`       | Mengidentifikasi rotasi halaman penuh dan memutar kanvas tegak lurus (0°, 90°, 180°, 270°).  |
| `.withLineClassification(bool)`   | `lineClassification`   | `boolean` | `false`       | Menjalankan klasifikasi orientasi baris 180° dan membalik teks yang terbalik.                |

---

### 2. Enam Fase Pemrosesan

#### Fase 1: Pra-Deteksi (`preDetection`)

Mengonfigurasi pengkondisian gambar dan batas resolusi sebelum inferensi.

| Opsi               | Tipe Data | Nilai Default | Deskripsi                                                                                             |
| ------------------ | --------- | ------------- | ----------------------------------------------------------------------------------------------------- |
| `targetMaxSide`    | `integer` | `null`        | Penskalaan sisi terpanjang sebelum detektor untuk mencegah lonjakan memori pada foto resolusi tinggi. |
| `descreenStrength` | `float`   | `null`        | Filter descreening halftone untuk media cetak hasil pindai.                                           |
| `cropPaddingX`     | `float`   | `null`        | Margin padding horizontal dalam piksel untuk area pemotongan.                                         |
| `cropPaddingY`     | `float`   | `null`        | Margin padding vertikal dalam piksel untuk area pemotongan.                                           |

#### Fase 2: Deteksi (`detection`)

Mengonfigurasi dimensi masukan dan normalisasi untuk model detektor DBNet.

| Opsi           | Tipe Data  | Nilai Default           | Deskripsi                                                                        |
| -------------- | ---------- | ----------------------- | -------------------------------------------------------------------------------- |
| `limitSideLen` | `integer`  | `960`                   | Batas dimensi resolusi input detektor.                                           |
| `limitType`    | `string`   | `"max"`                 | `"max"` membatasi sisi terpanjang; `"min"` menskalakan sisi terpendek ke target. |
| `mean`         | `float[3]` | `[0.485, 0.456, 0.406]` | Nilai mean normalisasi per kanal RGB.                                            |
| `std`          | `float[3]` | `[0.229, 0.224, 0.225]` | Nilai standar deviasi normalisasi per kanal RGB.                                 |

#### Fase 3: Pasca-Deteksi (`postDetection`)

Mengonfigurasi ekstraksi poligon kontur, ambang batas binarisasi, dan morfologi.

| Opsi               | Tipe Data | Nilai Default | Deskripsi                                                                                 |
| ------------------ | --------- | ------------- | ----------------------------------------------------------------------------------------- |
| `threshold`        | `float`   | `0.3`         | Batas ambang probabilitas binarisasi piksel.                                              |
| `boxThreshold`     | `float`   | `0.6`         | Batas ambang skor kepercayaan rata-rata poligon teks.                                     |
| `unclipRatio`      | `float`   | `2.0`         | Rasio ekspansi poligon Vatti untuk menangkap batas atas/bawah huruf (ascender/descender). |
| `useDilation`      | `boolean` | `true`        | Dilatasi morfologis untuk memperbaiki goresan karakter yang tipis atau terputus.          |
| `scoreMode`        | `string`  | `"fast"`      | Mode kalkulasi skor kotak (`"fast"` atau `"slow"`).                                       |
| `maxCandidates`    | `integer` | `1000`        | Jumlah maksimal kandidat poligon teks yang diproses.                                      |
| `minHeight`        | `float`   | `32.0`        | Tinggi minimum kotak pembatas.                                                            |
| `minSideLen`       | `float`   | `64.0`        | Panjang sisi minimum kotak pembatas.                                                      |
| `maxSideLen`       | `float`   | `1600.0`      | Panjang sisi maksimum kotak pembatas.                                                     |
| `widthHeightRatio` | `float`   | `-1.0`        | Rasio aspek padding pengenalan (`-1` mempertahankan rasio asli).                          |

#### Fase 4: Pra-Pengenalan (`preRecognition`)

Mengatur toleransi kluster spasial sebelum model pengenal teks membaca teks.

| Opsi             | Tipe Data | Nilai Default | Deskripsi                                                                         |
| ---------------- | --------- | ------------- | --------------------------------------------------------------------------------- |
| `lineYThreshold` | `float`   | `0.5`         | Pengali toleransi vertikal untuk menggabungkan kotak teks menjadi baris terpisah. |
| `wordXThreshold` | `float`   | `0.4`         | Pengali toleransi horizontal untuk memisahkan kata dan kolom.                     |

#### Fase 5: Pengenalan Teks (`recognition`)

Mengatur inferensi model pengenalan karakter (CTC) serta konkurensi thread worker.

| Opsi         | Tipe Data         | Nilai Default | Deskripsi                                                                                                     |
| ------------ | ----------------- | ------------- | ------------------------------------------------------------------------------------------------------------- |
| `batchSize`  | `integer`         | `8`           | Jumlah potongan baris teks yang diproses secara simultan oleh model pengenal.                                 |
| `workers`    | `integer \| null` | `null`        | Jumlah thread worker paralel untuk eksekusi pengenalan ini (`null` memakai bawaan `rec_workers` mesin).       |
| `maxWorkers` | `integer \| null` | `null`        | Batas maksimal worker (`>= 1`) saat penskalaan otomatis (`null` memakai bawaan `max_rec_workers` mesin, `8`). |

#### Fase 6: Pasca-Pengenalan (`postRecognition`)

Penyaringan hasil akhir berdasarkan tingkat kepercayaan (confidence score).

| Opsi             | Tipe Data | Nilai Default | Deskripsi                                                                          |
| ---------------- | --------- | ------------- | ---------------------------------------------------------------------------------- |
| `scoreThreshold` | `float`   | `0.5`         | Batas minimum skor kepercayaan pengenalan; teks di bawah nilai ini akan diabaikan. |

---

### 3. Granularitas Output

| Metode Builder                                    | Nilai Wire  | Bentuk Kembalian   | Deskripsi                                                                    |
| ------------------------------------------------- | ----------- | ------------------ | ---------------------------------------------------------------------------- |
| `.as_lines()` / `.asLines()` / `.AsLines()`       | `"lines"`   | Daftar terstruktur | Baris teks terdeteksi lengkap dengan koordinat quad, bounding box, dan skor. |
| `.as_words()` / `.asWords()` / `.AsWords()`       | `"words"`   | Daftar terstruktur | Kata-kata terpisah beserta posisi spasial masing-masing.                     |
| `.as_spatial()` / `.asSpatial()` / `.AsSpatial()` | `"spatial"` | String teks murni  | Rekonstruksi visual 2D dengan spasi dan kolom yang sejajar seperti aslinya.  |

> [!TIP]
> Di Rust, panggil `.run_blocks()` pada `DetectTextBuilder` (atau `.to_blocks()` pada `DetectTextResult`) untuk mengelompokkan baris ke dalam `BlockResult` berdasarkan tata letak, dan gunakan `.with_rec_workers(n)` / `.with_max_rec_workers(n)` untuk menimpa paralelisme pengenalan per gambar.

## Contoh Fluent Builder Lintas Bahasa

### Rust

```rust
use rusto::{DetectTextBuilderExt, ImageSource, InitializeConfig, RustO};

let mut ocr = RustO::initialize(InitializeConfig::indra("det.rten", "rec.rten", "dict.txt"))?;

let result = ocr.detect_text_builder(ImageSource::Path("document.jpg".into()))
    .with_auto_unwarp(true)
    .with_layout_reading(true)
    .with_post_detection(PostDetectionOptions {
        use_dilation: Some(true),
        unclip_ratio: Some(2.0),
        ..Default::default()
    })
    .asLines()
    .run()?;
```

### .NET / C#

```csharp
using RustODotnet;

using var ocr = RustO.Initialize(InitializeConfig.Indra());

var result = ocr.DetectText("document.jpg")
    .WithAutoUnwarp()
    .WithLayoutReading()
    .WithPostDetection(p => { p.UseDilation = true; p.UnclipRatio = 2.0f; })
    .AsLines()
    .Run();
```

### Swift (iOS)

```swift
import RustO

let ocr = try RustO.initialize(config: .indra())

let result = try ocr.detectText(image: "document.jpg")
    .withAutoUnwarp()
    .withLayoutReading()
    .withPostDetection { $0.useDilation = true; $0.unclipRatio = 2.0 }
    .asLines()
    .run()
```
