Setiap eksekusi deteksi OCR memproses satu `ImageSource` dan menghasilkan blok pembatas terstruktur atau teks tata letak spasial yang direkonstruksi.

## 📥 Sumber Gambar Masukan & Titik Masuk Fluent Builder

| Binding          | Entri Fluent & Sumber Berkas / URI            | Sumber Buffer Memori RAM                       | Catatan                                                          |
| ---------------- | --------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------- |
| **Rust**         | `detect_text_builder(ImageSource::Path(...))` | `detect_text_builder(ImageSource::Bytes(...))` | Dekode byte memori menggunakan mesin `image` Rust murni.         |
| **Python**       | `detect_text(path)`                           | `detect_text(bytes)`                           | Binding native UniFFI.                                           |
| **Node.js**      | `detectText(path)`                            | `detectText().image(buffer)`                   | Binding native N-API.                                            |
| **Java**         | `detectText().image(path)`                    | `detectText().data(bytes)`                     | Dynamic linking JNA ke `librusto`.                               |
| **Golang**       | `DetectText().Image(path)`                    | `DetectText().Data(bytes)`                     | Binding Cgo native ke `librusto`.                                |
| **Flutter/Dart** | `detectText(path)`                            | `detectText(bytes)`                            | Pure Dart FFI & plugin platform Flutter.                         |
| **.NET**         | `DetectText(path)`                            | `DetectText(bytes)`                            | Managed .NET bindings.                                           |
| **Swift**        | `detectText(image: path)`                     | `detectText(data: bytes)`                      | Menerima path berkas atau string URL berkas.                     |
| **Kotlin**       | `detectText(uri)`                             | `detectText(bytes)`                            | Mengurai URI `content://` Android dan `file://` secara otomatis. |
| **Web**          | `detectText(elementOrUrl)`                    | `detectText(bytes)`                            | HTMLImageElement, Canvas, Blob, URLs.                            |
| **React Native** | `detectText({ uri })`                         | `detectText({ bytes })` atau `{ base64 }`      | Wajib memuat tepat satu properti dalam objek masukan.            |

## 📐 Ruang Koordinat & Geometri

Koordinat dinyatakan dalam satuan piksel gambar terhadap titik asal kiri-atas `(0, 0)`:

```mermaid
flowchart TD
    subgraph RuangGambar ["Ruang Piksel Gambar: Titik Asal (0,0) Kiri-Atas &rarr; +X Kanan, +Y Bawah"]
        direction TB
        TL["box_points[0]<br/>Kiri-Atas (x1, y1)"] --- TR["box_points[1]<br/>Kanan-Atas (x2, y2)"]
        TL --- BL["box_points[3]<br/>Kiri-Bawah (x4, y4)"]
        TR --- BR["box_points[2]<br/>Kanan-Bawah (x3, y3)"]
        BL --- BR
    end
```

- **`box_points`**: Tepat 4 titik sudut poligon segiempat: `[Kiri-Atas, Kanan-Atas, Kanan-Bawah, Kiri-Bawah]`. Mengikuti sudut kemiringan teks yang sebenarnya.
- **`frame`**: Kotak batas sejajar sumbu (_axis-aligned bounding rectangle_): `(left, top, width, height)` yang dihitung dari batas terluar poligon.

## 📤 Rincian Mode Keluaran

| Mode                  | Bentuk Hasil Kembalian              | Kegunaan                                                                                       |
| --------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------- |
| **`lines`** (Default) | Daftar Terstruktur (`TextResult[]`) | Membaca dokumen standar, paragraf teks, dan formulir baris per baris.                          |
| **`words`**           | Daftar Terstruktur (`TextResult[]`) | Interaksi klik per kata, penyorotan teks kata per kata, atau visualisasi kotak batas granular. |
| **`spatial`**         | String Teks Biasa (`string`)        | Mempertahankan kolom 2D, perataan tabel, baris struk, dan indentasi dokumen.                   |

### Metadata Tata Letak (`regionId`, `layoutType`)

Saat `withLayoutReading()` aktif, setiap `TextResult` juga membawa wilayah tata letak tempat teks berada:

| Field              | Rust                              | .NET / C#    | Swift / Kotlin / Dart / Web / RN (Node.js uses `region_id`, `layout_type`) | Python        | Go                  |
| ------------------ | --------------------------------- | ------------ | -------------------------------------------------------------------------- | ------------- | ------------------- |
| **Indeks wilayah** | `region_id: Option<i32>`          | `RegionId`   | `regionId`                                                                 | `region_id`   | `RegionID *int32`   |
| **Kelas wilayah**  | `layout_type: Option<LayoutType>` | `LayoutType` | `layoutType`                                                               | `layout_type` | `LayoutType *int32` |

`layoutType` bernilai salah satu dari `text`, `title`, `figure`, `figureCaption`, `table`, `tableCaption`, `header`, `footer`, `reference`, atau `equation`. Kedua field kosong jika pembacaan tata letak nonaktif. Pada C FFI, `CTextResult.region_id` dan `CTextResult.layout_type` bertipe `int32_t` dengan nilai `-1` saat belum ditetapkan dan `0..9` sesuai urutan di atas.

### Keluaran Tingkat Blok (`BlockResult`)

Untuk dokumen multi-wilayah, Rust menyediakan pengelompokan blok hierarkis melalui `BlockResult`:

```rust
pub struct BlockResult {
    pub layout_type: LayoutType, // Title, Text, Figure, Table, Header, Footer, ... atau Unassigned
    pub lines: Vec<TextResult>,  // Baris teks terurut di dalam blok ini
}
```

Gunakan `DetectTextBuilder::run_blocks()` atau konversi `DetectTextResult` yang sudah ada via `.to_blocks()` (menggunakan `rusto::cluster_text_results_into_blocks`):

```rust
use rusto::{DetectTextBuilderExt, ImageSource};

let blocks = ocr
    .detect_text_builder(ImageSource::Path("document.jpg".into()))
    .with_layout_reading(true)
    .run_blocks()?; // -> Vec<BlockResult>

for block in &blocks {
    println!("[{:?}]\n{}\n", block.layout_type, block.text());
}

// Atau kelompokkan baris dari hasil detect_text(...) standar:
let blocks_from_res = ocr.detect_text(&source, &options)?.to_blocks();
```

Saat `with_layout_reading(true)` aktif, baris dikelompokkan berdasarkan `(region_id, layout_type)`; jika tidak, seluruh baris digabungkan dalam satu blok `LayoutType::Unassigned`.

## 💻 Contoh Penanganan Hasil di Berbagai Bahasa

### Pada Rust

```rust
match ocr.detect_text(&source, &options)? {
    DetectTextResult::Structured(items) => {
        for item in items {
            println!("{} ({:.1}%) di [{}, {}]", item.text, item.score * 100.0, item.frame.left, item.frame.top);
        }
    }
    DetectTextResult::Spatial(spatial_text) => {
        println!("{spatial_text}");
    }
}
```

### Pada .NET / C#

```csharp
var result = ocr.DetectText(source, options);

if (result is StructuredDetectTextResult structured)
{
    foreach (var item in structured.Items)
    {
        Console.WriteLine($"{item.Text} ({item.Score:P0}) [{item.Frame.Left}, {item.Frame.Top}]");
    }
}
else if (result is SpatialDetectTextResult spatial)
{
    Console.WriteLine(spatial.Text);
}
```

### Pada iOS (Swift)

```swift
let result = try ocr.detectText(source, options: options)

switch result {
case .structured(let items):
    for item in items {
        print("\(item.text) (\(item.score)) [\(item.frame.left), \(item.frame.top)]")
    }
case .spatial(let text):
    print(text)
}
```

### Pada Android (Kotlin)

```kotlin
when (val result = ocr.detectText(source, options)) {
    is DetectTextResult.Structured -> {
        result.items.forEach { item ->
            println("${item.text} (${item.score}) [${item.frame.left}, ${item.frame.top}]")
        }
    }
    is DetectTextResult.Spatial -> {
        println(result.text)
    }
}
```

### Pada React Native

```typescript
// Keluaran Lines -> TextResult[]
const lines = await detectText({ uri }, { output: 'lines' });
lines.forEach((item) => console.log(item.text, item.frame));

// Keluaran Spatial -> string
const spatialText = await detectText({ uri }, { output: 'spatial' });
console.log(spatialText);
```
