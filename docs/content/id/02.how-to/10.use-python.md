Paket `rusto` menyediakan binding performa tinggi berbasis [UniFFI](https://mozilla.github.io/uniffi-rs/), memungkinkan aplikasi Python menjalankan OCR berbasis Rust murni tanpa terhambat Python GIL selama eksekusi jaringan saraf.

## Instalasi

```bash
pip install rusto
```

---

## 1. Inisialisasi & Context Manager

Memanggil `RustO.initialize()` tanpa argumen secara otomatis menyiapkan dan mengunduh model bawaan **Indra OCR** (`indraocr`) ke direktori cache lokal. `RustO` mendukung protokol context manager Python (`with ... as engine:`) maupun pemanggilan eksplisit `engine.close()`:

```python
from rusto import InitializeConfig, RustO

# Opsi A: Zero-config dengan context manager (otomatis mengunduh Indra OCR jika belum ada di cache)
with RustO.initialize() as engine:
    print("Versi mesin:", engine.version())

# Opsi B: Konfigurasi preset eksplisit (Indra OCR atau PP-OCRv6)
config = InitializeConfig.ppv6(
    det_model_path="models/det.rten",
    rec_model_path="models/rec.rten",
    dict_path="models/dict.txt",
)
custom_engine = RustO.initialize(config)
custom_engine.close()
```

Untuk lingkungan tanpa akses internet saat runtime, Anda dapat mengunduh aset model terlebih dahulu menggunakan `RustO.download_model("indraocr")`.

## 2. Deteksi & Pengenalan Teks via Fluent Builder

Pada v0.4.0, rangkai opsi pemindaian pada `engine.detect_text(...)`, pilih granularitas keluaran dengan `.as_lines()`, `.as_words()`, atau `.as_spatial()`, lalu akhiri dengan `.run()`:

```python
from rusto import PostRecognitionOptions, RustO

with RustO.initialize() as engine:
    result = (
        engine.detect_text("receipt.jpg")
        .with_auto_unwarp()
        .with_layout_reading()
        .with_post_recognition(PostRecognitionOptions(score_threshold=0.6))
        .as_lines()
        .run()
    )

    if result.is_STRUCTURED():
        for item in result.results:
            print(f"[{item.score:.2f}] {item.text}")
            if item.layout_type is not None:
                print(f"  Wilayah #{item.region_id}: {item.layout_type}")
```

Untuk deteksi tingkat kata, ganti `.as_lines()` menjadi `.as_words()`. Anda juga dapat meneruskan `bytes` gambar terenkode secara langsung ke `engine.detect_text(image_bytes)`.

## 3. Rekonstruksi Tata Letak Spasial

Untuk mempertahankan perataan tabel, kolom, struk belanja, dan faktur menjadi teks 2D terformat:

```python
from rusto import PreRecognitionOptions, RustO

with RustO.initialize() as engine:
    spatial_result = (
        engine.detect_text("invoice.png")
        .with_pre_recognition(
            PreRecognitionOptions(line_y_threshold=0.5, word_x_threshold=0.4)
        )
        .as_spatial()
        .run()
    )

    if spatial_result.is_SPATIAL():
        print(spatial_result.text)
```
