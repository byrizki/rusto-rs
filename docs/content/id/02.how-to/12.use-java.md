Paket `rusto-java` menyediakan binding JVM berkinerja tinggi menggunakan Java Native Access (JNA). Kelas `RustO` mengimplementasikan `AutoCloseable` untuk manajemen memori native otomatis di dalam blok `try-with-resources`.

## Instalasi

### Gradle (Kotlin DSL)

```kotlin
repositories {
    mavenCentral()
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.byrizki.rusto-rs:rusto-java:0.4.0")
}
```

### Maven

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.byrizki.rusto-rs</groupId>
    <artifactId>rusto-java</artifactId>
    <version>0.4.0</version>
</dependency>
```

Pastikan pustaka native `librusto` (`librusto.so`, `librusto.dylib`, atau `rusto.dll`) terpasang pada `jna.library.path` atau jalur pustaka sistem.

## Contoh Penggunaan

Memanggil `RustO.initialize()` tanpa argumen secara otomatis menyiapkan dan mengunduh model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0). Anda juga dapat meneruskan string JSON konfigurasi ke `RustO.initialize(configJson)`.

Metode fluent builder `.asLines()`, `.asWords()`, dan `.asSpatial()` diakhiri dengan satu metode terminal `.run()` yang mengembalikan `RustO.DetectTextResult`:

```java
import com.byrizki.rusto.RustO;
import com.byrizki.rusto.TextResult;

public class Main {
    public static void main(String[] args) {
        // Zero-config: otomatis menggunakan/mengunduh ppocrv6-tiny (atau teruskan JSON ke RustO.initialize(configJson))
        try (RustO engine = RustO.initialize()) {
            // 1. Deteksi baris terstruktur (.asLines().run())
            RustO.DetectTextResult structured = engine.detectText("receipt.jpg")
                .withAutoUnwarp()
                .withLayoutReading()
                .asLines()
                .run();

            for (TextResult r : structured.results()) {
                System.out.printf("[%0.2f] %s (wilayah=%s, tipe=%s)%n",
                    r.score(), r.text(), r.regionId(), r.layoutType());
            }

            // 2. Deteksi tingkat kata (.asWords().run())
            RustO.DetectTextResult words = engine.detectText("receipt.jpg")
                .asWords()
                .run();
            System.out.printf("Total kata terdeteksi: %d%n", words.results().size());

            // 3. Rekonstruksi tata letak 2D spasial (.asSpatial().run())
            RustO.DetectTextResult spatial = engine.detectText("receipt.jpg")
                .asSpatial()
                .run();
            if (spatial.isSpatial()) {
                System.out.println("--- Tata Letak Spasial ---");
                System.out.println(spatial.text());
            }
        }
    }
}
```
