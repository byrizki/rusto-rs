RustO! menyediakan dukungan kelas satu untuk iOS dan macOS melalui XCFramework universal dan pembungkus Swift yang ergonomis. Mendukung arsitektur Apple Silicon (`arm64`), Intel (`x86_64`), dan Simulator iOS tanpa memerlukan rantai alat kompilasi C++.

---

## Instalasi

Anda dapat mengintegrasikan RustO! ke dalam proyek iOS Anda menggunakan **Swift Package Manager (SPM)** atau **CocoaPods**.

### Metode A: Swift Package Manager (Direkomendasikan)

#### Melalui Xcode

1. Buka proyek Anda di Xcode.
2. Buka menu **File > Add Package Dependencies...**
3. Masukkan URL repositori:
   ```text
   https://github.com/byrizki/rusto-rs.git
   ```
4. Pilih produk pustaka `RustO` dan tentukan aturan versi paket yang diinginkan (misalnya `0.4.0`).

#### Melalui `Package.swift`

Jika Anda membuat paket modular atau pustaka Swift:

```swift
// swift-tools-version: 5.9
import PackageDescription

let package = Package(
    name: "MyScannerApp",
    platforms: [
        .iOS(.v13),
        .macOS(.v11)
    ],
    dependencies: [
        .package(url: "https://github.com/byrizki/rusto-rs.git", from: "0.4.0")
    ],
    targets: [
        .target(
            name: "MyScannerApp",
            dependencies: [
                .product(name: "RustO", package: "rusto-rs")
            ]
        )
    ]
)
```

Paket ini secara otomatis menyediakan modul C FFI level rendah (`RustOFFI`) dan API Swift level tinggi (`RustO`).

---

### Metode B: CocoaPods

Pada file `Podfile` proyek Anda:

```ruby
target 'YourApp' do
  use_frameworks!

  # XCFramework runtime mesin OCR inti
  pod 'RustO', '~> 0.4.0'
end
```

Kemudian jalankan:

```bash
pod install
```

## 1. Konfigurasi Izin (`Info.plist`)

Jika mengambil gambar dari kamera atau galeri foto, tambahkan deklarasi deskripsi izin pada file `Info.plist` aplikasi Anda:

```xml
<key>NSCameraUsageDescription</key>
<string>Izinkan akses kamera untuk memindai dokumen dan mengekstrak teks.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Izinkan akses galeri foto untuk memilih gambar dokumen untuk dipindai.</string>
```

## 2. Inisialisasi Mesin & Resolusi Model

### Opsi 1: Resolusi Model Otomatis & Auto-Download (Indra OCR)

`RustO.initialize()` memeriksa bundel aplikasi terlebih dahulu; apabila model belum dibundel, RustO! secara otomatis mengunduh model bawaan **Indra OCR** (`indraocr`) ke direktori cache aplikasi (`Library/Caches/rusto/models`):

```swift
import RustO

do {
    let ocr = try RustO.initialize()
} catch {
    print("Inisialisasi OCR gagal: \(error)")
}
```

Anda juga dapat mengunduh aset model lebih awal menggunakan `try RustO.downloadModel(model: "indraocr")`.

### Opsi 2: Menggunakan Bundel Aplikasi atau Preset Eksplisit

Jika Anda menyertakan model di dalam bundel aplikasi atau ingin menggunakan konfigurasi eksplisit:

```swift
import Foundation
import RustO

func createCustomEngine() throws -> RustO {
    guard let detPath = Bundle.main.path(forResource: "det", ofType: "rten"),
          let recPath = Bundle.main.path(forResource: "rec", ofType: "rten"),
          let dictPath = Bundle.main.path(forResource: "meta", ofType: "json") else {
        throw NSError(domain: "RustO", code: -1, userInfo: [NSLocalizedDescriptionKey: "Berkas model tidak ditemukan di bundel"])
    }

    let config = InitializeConfig.indra(
        detModelPath: detPath,
        recModelPath: recPath,
        dictPath: dictPath
    )

    return try RustO.initialize(config: config)
}
```

## 3. Sumber Masukan Gambar

`DetectTextBuilder` mendukung jalur berkas lokal (`detectText(image:)`), buffer `Data` terenkode (`detectText(data:)`), `ImageSource`, maupun piksel RGB24 mentah (`detectText().rgb(...)`):

```swift
import UIKit
import RustO

// 1. Jalur berkas lokal atau file:// URI
let fileSource = ImageSource.path(path: "/path/to/invoice.png")

// 2. UIImage dikonversi menjadi data JPEG atau PNG
guard let image = UIImage(named: "receipt"),
      let imageData = image.jpegData(compressionQuality: 0.95) else { return }

let memorySource = ImageSource.bytes(data: imageData)
```

## 4. Chaining Fluent Builder (`DetectTextBuilder`)

Sesuaikan parameter deteksi per permintaan pemindaian menggunakan metode granularitas `.asLines()`, `.asWords()`, atau `.asSpatial()`, lalu akhiri dengan `.run()`:

```swift
let result = try ocr.detectText(data: imageData)
    .withAutoUnwarp()
    .withLayoutReading()
    .withPostDetection {
        $0.useDilation = true
        $0.unclipRatio = 1.8
    }
    .withPostRecognition {
        $0.scoreThreshold = 0.6
    }
    .asLines()
    .run()
```

## 5. Deteksi Terstruktur vs Rekonstruksi Spasial

### Deteksi Baris Terstruktur (`.asLines()`)

Mengembalikan koordinat kotak pembatas, titik poligon, kategori tata letak, dan skor keyakinan:

```swift
let result = try ocr.detectText(data: imageData)
    .withLayoutReading()
    .asLines()
    .run()

if case .structured(let items) = result {
    for line in items {
        print("[\(String(format: "%.2f", line.score))] \(line.text)")
        print("  Frame: X=\(line.frame.left), Y=\(line.frame.top), W=\(line.frame.width), H=\(line.frame.height)")
        print("  Titik Poligon: \(line.boxPoints)")
        if let layoutType = line.layoutType {
            print("  Tata Letak: \(layoutType) (Wilayah: \(line.regionId ?? -1))")
        }
    }
}
```

### Rekonstruksi Tata Letak Spasial (`.asSpatial()`)

Menyusun ulang geometri teks multikolom atau tabel menjadi teks rapi terformat:

```swift
let result = try ocr.detectText(data: imageData)
    .asSpatial()
    .run()

if case .spatial(let layoutText) = result {
    print("--- Tata Letak Spasial ---\n\(layoutText)")
}
```

## 6. Contoh Lengkap Pemindai Dokumen di SwiftUI

Selalu jalankan inferensi OCR pada antrean latar belakang (_background thread_) atau Swift Concurrency (`Task.detached`) agar antarmuka utama tetap responsif:

```swift
import SwiftUI
import PhotosUI
import RustO

struct DocumentScannerView: View {
    @State private var selectedItem: PhotosPickerItem?
    @State private var previewImage: UIImage?
    @State private var recognizedText: String = ""
    @State private var isProcessing: Bool = false
    @State private var ocrEngine: RustO?

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                if let previewImage {
                    Image(uiImage: previewImage)
                        .resizable()
                        .scaledToFit()
                        .frame(maxHeight: 240)
                        .cornerRadius(12)
                }

                PhotosPicker(selection: $selectedItem, matching: .images) {
                    Label("Pilih Dokumen", systemImage: "doc.text.viewfinder")
                        .font(.headline)
                        .frame(maxWidth: .infinity)
                        .padding()
                        .background(Color.orange)
                        .foregroundColor(.white)
                        .cornerRadius(10)
                }
                .onChange(of: selectedItem) { _, newItem in
                    Task {
                        guard let data = try? await newItem?.loadTransferable(type: Data.self),
                              let uiImage = UIImage(data: data) else { return }
                        previewImage = uiImage
                        await runOcr(data: data)
                    }
                }

                if isProcessing {
                    ProgressView("Mengekstrak teks dengan RustO!...")
                        .padding()
                }

                ScrollView {
                    Text(recognizedText.isEmpty ? "Belum ada teks yang dipindai." : recognizedText)
                        .font(.system(.body, design: .monospaced))
                        .frame(maxWidth: .infinity, alignment: .leading)
                        .padding()
                        .background(Color(UIColor.secondarySystemBackground))
                        .cornerRadius(8)
                }
            }
            .padding()
            .navigationTitle("Pemindai Dokumen RustO!")
            .task {
                ocrEngine = try? RustO.initialize()
            }
        }
    }

    private func runOcr(data: Data) async {
        guard let engine = ocrEngine else { return }
        isProcessing = true
        recognizedText = ""

        let resultText: String = await Task.detached(priority: .userInitiated) {
            do {
                let result = try engine.detectText(data: data)
                    .withAutoUnwarp()
                    .withPreRecognition {
                        $0.lineYThreshold = 0.5
                        $0.wordXThreshold = 0.4
                    }
                    .asSpatial()
                    .run()

                if case .spatial(let text) = result {
                    return text
                }
                return "Tidak ada teks yang terdeteksi."
            } catch {
                return "Kesalahan OCR: \(error.localizedDescription)"
            }
        }.value

        recognizedText = resultText
        isProcessing = false
    }
}
```
