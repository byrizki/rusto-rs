Paket `@rustors/node` menyediakan binding N-API native berkecepatan tinggi untuk Node.js, memanggil mesin RustO! berbasis Rust murni secara langsung tanpa overhead proses anak (_child process_) atau IPC.

## Instalasi

```bash
npm install @rustors/node
```

---

## 1. Inisialisasi & Pembersihan Mesin

`RustO.initialize()` tanpa argumen secara otomatis menyiapkan dan mengunduh model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) ke direktori cache lokal. Anda juga dapat memberikan objek `InitializeConfig` atau mengunduh model lebih awal dengan `RustO.downloadModel('ppocrv6-tiny')`:

```javascript
const { RustO } = require('@rustors/node');

// Opsi A: Zero-config (otomatis menggunakan/mengunduh ppocrv6-tiny)
const engine = RustO.initialize();

// Opsi B: Jalur model lokal eksplisit
const customEngine = RustO.initialize({
  preset: 'ppv6',
  detection: { modelPath: 'models/det.rten' },
  recognition: { modelPath: 'models/rec.rten', dictPath: 'models/dict.txt' },
});
```

Setelah selesai memproses, panggil `engine.close()` untuk melepaskan sesi memori native:

```javascript
engine.close();
customEngine.close();
```

## 2. Deteksi & Pengenalan Teks via Fluent Builder

Pada v0.4.0, pilih format keluaran menggunakan `.asLines()`, `.asWords()`, atau `.asSpatial()`, lalu jalankan inferensi dengan `.run()`:

### Dari Berkas Gambar

```javascript
const results = engine
  .detectText('receipt.jpg')
  .withAutoUnwarp()
  .withLayoutReading()
  .asLines()
  .run();

results.forEach((item, index) => {
  console.log(`[Baris ${index + 1}] ${item.text} (${(item.score * 100).toFixed(1)}%)`);
  console.log(`  Poligon: ${JSON.stringify(item.box_points)}`);
  if (item.layout_type) {
    console.log(`  Wilayah #${item.region_id}: ${item.layout_type}`);
  }
});
```

### Dari Buffer Memori atau Piksel RGB

```javascript
const fs = require('fs');

const imageBuffer = fs.readFileSync('document.png');
const words = engine.detectText(imageBuffer).asWords().run();

console.log(`Terdeteksi ${words.length} kata.`);
```

## 3. Rekonstruksi Tata Letak Spasial

Untuk mempertahankan format tabel, kolom, struk belanja, dan faktur sebagai string 2D terformat:

```javascript
const spatialText = engine
  .detectText('invoice.png')
  .withPreRecognition({ lineYThreshold: 0.5, wordXThreshold: 0.4 })
  .asSpatial()
  .run();

console.log('--- Dokumen Tata Letak Spasial ---');
console.log(spatialText);
```

## 4. Dukungan TypeScript

`@rustors/node` menyertakan definisi tipe TypeScript lengkap untuk seluruh opsi 6-fase dan hasil deteksi:

```typescript
import { RustO, TextResult } from '@rustors/node';

const engine = RustO.initialize();

const results: TextResult[] = engine
  .detectText('invoice.png')
  .withAutoUnwarp()
  .withLayoutReading()
  .withPostRecognition({ scoreThreshold: 0.6 })
  .asLines()
  .run();

const spatial: string = engine.detectText('invoice.png').asSpatial().run();

engine.close();
```
