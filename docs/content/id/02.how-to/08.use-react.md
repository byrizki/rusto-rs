# Menggunakan React

Paket `@rustors/react` menyediakan komponen dan hook deklaratif di atas `@rustors/web`: `<RustoProvider />`, `useOcr()`, `<OcrOverlay />`, dan `<OcrDropzone />`.

## Instalasi

```bash
npm install @rustors/react @rustors/web
# atau
yarn add @rustors/react @rustors/web
# atau
pnpm add @rustors/react @rustors/web
```

## Konfigurasi Provider

Bungkus aplikasi Anda dengan `RustoProvider` untuk mengelola siklus hidup Web Worker dan konfigurasi model. Preset `'ppv6'` menjadi bawaan (selain `'indra'`, `'ppv5'`, `'ppv4'`, dan `'ppv3'`):

```tsx
import React from 'react';
import { RustoProvider } from '@rustors/react';

// Opsi A: Aset lokal di folder public/
const localModels = {
  detection: '/models/ppocrv6-tiny/det.rten',
  recognition: '/models/ppocrv6-tiny/rec.rten',
  dictionary: '/models/ppocrv6-tiny/dict.txt',
  unwarp: '/models/uvdoc.rten', // Opsional
  layout: '/models/layout_cdla.rten', // Opsional
  order: '/models/indra_order.rten', // Opsional
};

// Opsi B: Dihosting langsung via Hugging Face Hub (CORS aktif)
const HF_BASE = 'https://huggingface.co/byrizki/rusto-models/resolve/main';
const remoteModels = {
  detection: `${HF_BASE}/ppocrv6-tiny/det.rten`,
  recognition: `${HF_BASE}/ppocrv6-tiny/rec.rten`,
  dictionary: `${HF_BASE}/ppocrv6-tiny/dict.txt`,
};

export function App() {
  return (
    <RustoProvider
      config={{
        preset: 'ppv6',
        wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
        models: localModels,
      }}
    >
      <OcrScanner />
    </RustoProvider>
  );
}
```

## Memindai dengan `useOcr` dan `<OcrOverlay />`

Hook `useOcr()` menyediakan metode `detect(source, options)` beserta state reaktif `results`, `spatialText`, `isProcessing`, `error`, dan `reset`:

```tsx
import React, { useState } from 'react';
import { OcrDropzone, OcrOverlay, useOcr } from '@rustors/react';

export function OcrScanner() {
  const [imageSrc, setImageSrc] = useState<string | null>(null);
  const { detect, results, spatialText, isProcessing, error } = useOcr();

  const handleFileSelect = async (file: File) => {
    setImageSrc(URL.createObjectURL(file));
    await detect(file, {
      output: 'lines',
      autoUnwarp: true,
      layoutReading: true,
      postRecognition: { scoreThreshold: 0.6 },
    });
  };

  return (
    <div>
      <OcrDropzone onFileSelect={handleFileSelect} />

      {isProcessing && <p>Memindai dokumen...</p>}
      {error && <p>Kesalahan: {error.message}</p>}

      {imageSrc && results.length > 0 && (
        <OcrOverlay
          imageSrc={imageSrc}
          results={results}
          onItemClick={(item) => console.log('Kotak diklik:', item.text)}
        />
      )}

      {spatialText && <pre>{spatialText}</pre>}
    </div>
  );
}
```

Jika Anda membutuhkan akses langsung ke fluent builder `WebOcrEngine` di dalam React, panggil `detectText(file).withAutoUnwarp().asLines().run()` dari `@rustors/web` atau instans mesin layanan pada `RustoContext`.

## Pemecahan Masalah Kebijakan Keamanan Konten (CSP)

Saat mengintegrasikan `@rustors/react` pada aplikasi React, Vite, Next.js, atau Remix dengan aturan CSP yang ketat:

```http
Content-Security-Policy:
  script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net;
  connect-src 'self' https://cdn.jsdelivr.net https://huggingface.co blob:;
  worker-src 'self' blob:;
  img-src 'self' data: blob:;
```

- Jika muncul `EvalError: Refused to compile or instantiate WebAssembly module`, tambahkan `'wasm-unsafe-eval'` pada `script-src`.
- Jika berkas model gagal diunduh dari CDN atau Hugging Face, tambahkan domain asal model pada `connect-src`.
- Jika pembuatan Web Worker gagal dengan `SecurityError`, tambahkan `worker-src 'self' blob:`.
