# Penggunaan RustO di Aplikasi React

Paket `react-rusto` menyediakan komponen deklaratif untuk React: `<RustoProvider />`, `useOcr()`, `<OcrOverlay />`, dan `<OcrDropzone />`.

## Instalasi

```bash
npm install react-rusto rusto-web rusto-models-ppocrv6-tiny
# atau
yarn add react-rusto rusto-web rusto-models-ppocrv6-tiny
# atau
pnpm add react-rusto rusto-web rusto-models-ppocrv6-tiny
```

## Konfigurasi Provider

Bungkus aplikasi Anda dengan `RustoProvider` untuk mengelola daur hidup engine:

```tsx
import React from 'react';
import { RustoProvider } from 'react-rusto';
import { getModelUrls } from 'rusto-models-ppocrv6-tiny';

const modelUrls = getModelUrls('/models/ppocrv6-tiny');

export function App() {
  return (
    <RustoProvider
      config={{
        preset: 'ppv6',
        models: {
          detection: modelUrls.detection,
          recognition: modelUrls.recognition,
          dictionary: modelUrls.dictionary,
        },
      }}
    >
      <OcrScanner />
    </RustoProvider>
  );
}
```

## Memindai dengan `useOcr` dan `<OcrOverlay />`

```tsx
import React, { useState } from 'react';
import { useOcr, OcrOverlay, OcrDropzone } from 'react-rusto';

export function OcrScanner() {
  const [imageSrc, setImageSrc] = useState<string | null>(null);
  const { detect, results, isProcessing } = useOcr();

  const handleFileSelect = async (file: File) => {
    setImageSrc(URL.createObjectURL(file));
    await detect(file);
  };

  return (
    <div>
      <OcrDropzone onFileSelect={handleFileSelect} />

      {isProcessing && <p>Memindai dokumen...</p>}

      {imageSrc && results.length > 0 && (
        <OcrOverlay
          imageSrc={imageSrc}
          results={results}
          onItemClick={(item) => console.log('Kotak diklik:', item.text)}
        />
      )}
    </div>
  );
}
```
