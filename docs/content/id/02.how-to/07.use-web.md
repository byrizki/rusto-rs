# Menggunakan Web

Paket `@rustors/web` menyediakan kapabilitas OCR sisi klien untuk peramban modern, Web Workers, dan framework frontend berbasis WebAssembly dengan dukungan TypeScript penuh.

## Instalasi

```bash
npm install @rustors/web
# atau
yarn add @rustors/web
# atau
pnpm add @rustors/web
```

## Memulai Cepat

`@rustors/web` mendukung preset `'indra'` (bawaan unggulan), `'ppv6'`, `'ppv5'`, `'ppv4'`, dan `'ppv3'`, serta model opsional untuk pelurusan (`unwarp`), orientasi (`orient`), tata letak (`layout`), dan urutan baca neural (`order` / `indra_order.rten`).

> [!IMPORTANT]
> Memanggil `detectText(source)` tanpa argumen kedua mengembalikan `DetectTextBuilder` (bukan `Promise` langsung). Selalu akhiri rantai builder dengan `.run()`.

```ts
import { detectText, initialize } from '@rustors/web';

// 1. Inisialisasi mesin dengan preset Indra OCR dan URL/path model
await initialize({
  preset: 'indra',
  models: {
    detection: '/models/indraocr/det.rten',
    recognition: '/models/indraocr/rec.rten',
    dictionary: '/models/indraocr/meta.json',
    unwarp: '/models/uvdoc.rten', // Opsional: pelurusan dokumen 3D
    orient: '/models/indra_orient.rten', // Opsional: rotasi halaman 0°/90°/180°/270°
    layout: '/models/layout_cdla.rten', // Opsional: deteksi wilayah tata letak
    order: '/models/indra_order.rten', // Opsional: urutan baca neural
  },
});

// 2. Jalankan OCR via chaining fluent builder yang diakhiri .run()
const results = await detectText(document.getElementById('my-image') as HTMLImageElement)
  .withAutoUnwarp()
  .withLayoutReading()
  .asLines()
  .run();

for (const item of results) {
  console.log(`${item.text} (${(item.score * 100).toFixed(1)}%)`);
}
```

## Penggunaan CDN & Aset Remote

Anda dapat memuat runtime WebAssembly dari jsDelivr dan bobot model dari Hugging Face Hub atau GitHub Releases tanpa menyertakan biner besar ke dalam bundel aplikasi:

### Pada Bundler (Vite, Next.js, Nuxt)

```ts
import { detectText, initialize } from '@rustors/web';

const HF_BASE = 'https://huggingface.co/byrizki/rten-models/resolve/main';

await initialize({
  preset: 'indra',
  wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
  models: {
    detection: `${HF_BASE}/indraocr/det.rten`,
    recognition: `${HF_BASE}/indraocr/rec.rten`,
    dictionary: `${HF_BASE}/indraocr/meta.json`,
  },
});

const results = await detectText(imageFile).asLines().run();
```

### Vanilla HTML / Browser ES Modules

Dapat dijalankan langsung di peramban tanpa langkah kompilasi bundler:

```html
<script type="module">
  import { initialize, detectText } from 'https://cdn.jsdelivr.net/npm/@rustors/web/+esm';

  const HF_BASE = 'https://huggingface.co/byrizki/rten-models/resolve/main';

  await initialize({
    preset: 'indra',
    wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
    models: {
      detection: `${HF_BASE}/indraocr/det.rten`,
      recognition: `${HF_BASE}/indraocr/rec.rten`,
      dictionary: `${HF_BASE}/indraocr/meta.json`,
    },
  });

  const results = await detectText('https://example.com/sample-receipt.jpg').asLines().run();
  console.log('Hasil deteksi teks:', results);
</script>
```

## Format Keluaran via Fluent Builder

```ts
// Baris terstruktur (bawaan): Promise<TextResult[]>
const lines = await detectText(imageFile).asLines().run();

// Token tingkat kata: Promise<TextResult[]>
const words = await detectText(imageFile).asWords().run();

// Rekonstruksi tata letak 2D spasial: Promise<string>
const spatialText = await detectText(imageFile)
  .withPreRecognition({ lineYThreshold: 0.5, wordXThreshold: 0.4 })
  .asSpatial()
  .run();
console.log(spatialText);
```

## Kebijakan Keamanan Konten (CSP)

Jika aplikasi web Anda menerapkan header HTTP Content Security Policy yang ketat, pastikan direktif berikut telah dikonfigurasi:

```http
Content-Security-Policy:
  default-src 'self';
  script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net;
  connect-src 'self' https://cdn.jsdelivr.net https://huggingface.co blob:;
  worker-src 'self' blob:;
  img-src 'self' data: blob:;
```

- **`script-src 'wasm-unsafe-eval'`**: Diperlukan oleh peramban modern untuk mengompilasi modul WebAssembly.
- **`connect-src https://cdn.jsdelivr.net https://huggingface.co blob:`**: Mengizinkan pengunduhan runtime `.wasm` dan berkas model dari CDN/repositori atau objek blob lokal.
- **`worker-src 'self' blob:`**: Diperlukan karena `@rustors/web` menjalankan inferensi di dalam Web Worker latar belakang secara bawaan.
- **`img-src 'self' data: blob:`**: Mengizinkan pembacaan pratinjau berkas gambar lokal maupun data URI.
