# Menggunakan Web

Paket `@rustors/web` menyediakan kapabilitas OCR sisi klien untuk browser modern, Web Workers, dan framework frontend dengan dukungan TypeScript penuh.

## Instalasi

```bash
npm install @rustors/web
# atau
yarn add @rustors/web
# atau
pnpm add @rustors/web
```

## Memulai Cepat

```ts
import { initialize, detectText } from '@rustors/web';

// 1. Inisialisasi engine dengan URL model atau path aset lokal
await initialize({
  preset: 'ppv6',
  models: {
    detection: '/models/ppocrv6-tiny/det.rten',
    recognition: '/models/ppocrv6-tiny/rec.rten',
    dictionary: '/models/ppocrv6-tiny/dict.txt',
  },
});

// 2. Jalankan OCR pada sumber gambar (Elemen Gambar, Canvas, File, Blob, atau URL)
const results = await detectText(document.getElementById('my-image') as HTMLImageElement);

for (const item of results) {
  console.log(`${item.text} (${(item.score * 100).toFixed(1)}%)`);
}
```

## Penggunaan CDN & Aset Remote

Anda dapat memuat runtime WebAssembly dari jsDelivr dan model langsung dari GitHub Releases atau CDN mandiri tanpa perlu menyertakan biner besar ke dalam berkas build:

### Pada Bundler (Vite, Next.js, Nuxt)

```ts
import { initialize, detectText } from '@rustors/web';

const RELEASE_BASE = 'https://github.com/byrizki/rusto-rs/releases/download/models-rten-v0.3.2';

await initialize({
  preset: 'ppv6',
  wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_rten_wasm_bg.wasm',
  models: {
    detection: `${RELEASE_BASE}/ppocrv6_tiny_det.rten`,
    recognition: `${RELEASE_BASE}/ppocrv6_tiny_rec.rten`,
    dictionary: `${RELEASE_BASE}/ppocrv6_dict.txt`,
  },
});

const results = await detectText(imageFile);
```

### Vanilla HTML / Browser ES Modules

Dapat langsung dijalankan di peramban tanpa alat build:

```html
<script type="module">
  import { initialize, detectText } from 'https://cdn.jsdelivr.net/npm/@rustors/web/+esm';

  const RELEASE_BASE = 'https://github.com/byrizki/rusto-rs/releases/download/models-rten-v0.3.2';

  await initialize({
    preset: 'ppv6',
    wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_rten_wasm_bg.wasm',
    models: {
      detection: `${RELEASE_BASE}/ppocrv6_tiny_det.rten`,
      recognition: `${RELEASE_BASE}/ppocrv6_tiny_rec.rten`,
      dictionary: `${RELEASE_BASE}/ppocrv6_dict.txt`,
    },
  });

  const results = await detectText('https://example.com/sample-receipt.jpg');
  console.log('Hasil deteksi teks:', results);
</script>
```

## Format Keluaran (Output Granularity)

```ts
// Lines (bawaan): kandidat teks dikelompokkan per baris
const lines = await detectText(imageFile, { output: 'lines' });

// Words: token terpisah per kata individual
const words = await detectText(imageFile, { output: 'words' });

// Spatial: teks dengan format spasi dan tata letak asli
const spatialText = await detectText(imageFile, { output: 'spatial' });
console.log(spatialText);
```

## Kebijakan Keamanan Konten (CSP)

Jika aplikasi web Anda menerapkan header HTTP Content Security Policy yang ketat, pastikan direktif berikut telah dikonfigurasi:

```http
Content-Security-Policy:
  default-src 'self';
  script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net;
  connect-src 'self' https://cdn.jsdelivr.net blob:;
  worker-src 'self' blob:;
  img-src 'self' data: blob:;
```

- **`script-src 'wasm-unsafe-eval'`**: Diperlukan oleh peramban modern untuk mengompilasi biner WebAssembly.
- **`connect-src https://cdn.jsdelivr.net blob:`**: Mengizinkan pengunduhan runtime `.wasm` dan berkas model dari CDN atau objek blob lokal.
- **`worker-src 'self' blob:`**: Wajib karena `@rustors/web` mengeksekusi inferensi pada Web Worker latar belakang secara default.
- **`img-src 'self' data: blob:`**: Mengizinkan pembacaan berkas gambar lokal pratinjau maupun base64.
