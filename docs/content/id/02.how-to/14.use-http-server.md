`rusto-server` (`crates/rusto-server`) adalah crate workspace mandiri yang menyediakan server HTTP dengan bentuk permintaan `POST /v1/ocr` yang kompatibel dengan Mistral di atas `rusto-rs` (PP-OCRv6). Kode yang ditulis untuk API HTTP OCR Mistral dapat diarahkan ke instance `rusto-server` self-hosted cukup dengan mengganti base URL.

Crate ini dipisahkan dari workspace inti agar dependensi async dan web (`axum`, `tokio`, `ureq`) tidak masuk ke `rusto-core` maupun target C/mobile.

> **Catatan kompatibilitas**: Kompatibilitas telah diuji dengan permintaan HTTP polos berbentuk API Mistral, bukan dengan SDK resmi Mistral.

---

## Mulai Cepat

Siapkan direktori model dengan satu subdirektori per model, masing-masing berisi `det.onnx`, `rec.onnx`, dan `dict.txt`:

```text
models/
├── tiny/
│   ├── det.onnx
│   ├── rec.onnx
│   └── dict.txt
└── small/
    ├── det.onnx
    ├── rec.onnx
    └── dict.txt
```

Jalankan server dengan `cargo run`:

```bash
OCR_MODELS_DIR=/path/to/models cargo run -p rusto-server --release
```

Atau jalankan satu direktori model secara langsung:

```bash
OCR_MODEL_DIR=/path/to/models/tiny cargo run -p rusto-server --release
```

Secara bawaan, server mendengarkan di `127.0.0.1:8895`.

## Endpoint

| Endpoint     | Metode | Autentikasi | Deskripsi                                                                         |
| :----------- | :----: | :---------: | :-------------------------------------------------------------------------------- |
| `/health`    | `GET`  |    Tidak    | Pemeriksaan kesehatan yang mengembalikan `ok`.                                    |
| `/v1/models` | `GET`  |  Opsional   | Menampilkan daftar model yang dikonfigurasi dan menandai model `default`.         |
| `/v1/ocr`    | `POST` |  Opsional   | Menjalankan OCR pada URI `data:` base64 atau URL gambar `http(s)` yang diizinkan. |

Saat `OCR_API_KEY` disetel, endpoint `/v1/*` mewajibkan header `Authorization: Bearer <key>` dan mengembalikan format error Mistral jika tidak valid.

## Permintaan & Respons `POST /v1/ocr`

### Field Permintaan

- **`document.type`**: `"image_url"` atau `"document_url"`.
- **`document.image_url` / `document.document_url`**: String URL langsung atau objek `{ "url": "..." }`. Mendukung URI `data:` base64 atau URL `http(s)` dari host pada `OCR_ALLOWED_HOSTS` (tanpa redirect, batas 32 MB). Mendukung **PNG** dan **JPEG**.
- **`model`** _(opsional)_: Memilih model per permintaan:
  - Nama direktori terkonfigurasi (misal `"tiny"`, `"small"`) atau `"rusto-ppocrv6-<nama>"`.
  - `"mistral-ocr-*"` atau kosong menggunakan `OCR_DEFAULT_MODEL`.
  - Nama lain mengembalikan `400 Bad Request`.
  - Model dimuat secara _lazy_ saat pertama kali digunakan.
- **`autorotate`** _(opsional, ekstra non-Mistral)_: Boolean untuk menimpa `OCR_AUTOROTATE` agar menerapkan orientasi EXIF sebelum deteksi.

### Contoh Permintaan

```bash
B64=$(base64 -w0 receipt.png)

curl -s http://127.0.0.1:8895/v1/ocr \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"rusto-ppocrv6-tiny\",
    \"document\": {
      \"type\": \"image_url\",
      \"image_url\": \"data:image/png;base64,${B64}\"
    }
  }"
```

### Bentuk Respons

Mengembalikan field yang kompatibel dengan Mistral beserta field ekstra non-Mistral pada setiap halaman (diabaikan oleh klien Mistral standar):

- `pages[]`:
  - `index`, `markdown` (baris teks sesuai urutan rusto), `images` (selalu `[]`), `dimensions` (`width`, `height`, `dpi: null`).
  - **Ekstra**: `lines` (`text`, `score`, `box`), `blocks` (wilayah tata letak dengan `region_id`, `layout_type`, `text`, `score`, `box`), `orientation_corrected` (`bool`), dan `text_angle` (kemiringan median dalam derajat, atau `null`).
- `model`: `"rusto-ppocrv6-<nama>"`.
- `usage_info`: `{ "pages_processed": 1, "doc_size_bytes": ... }`.

### Belum Didukung

PDF, tabel, header/footer terpisah, ekstraksi gambar, opsi confidence, anotasi, pemilihan `pages`, dan alur unggah `/v1/files` belum didukung.

## Variabel Lingkungan

| Variabel            | Bawaan           | Deskripsi                                                                                                  |
| :------------------ | :--------------- | :--------------------------------------------------------------------------------------------------------- |
| `OCR_MODELS_DIR`    | _(kosong)_       | Direktori induk berisi satu subdirektori per model (`det.onnx`, `rec.onnx`, `dict.txt`).                   |
| `OCR_MODEL_DIR`     | `models/tiny`    | Pintasan model tunggal yang disajikan sebagai `tiny` (dipakai jika `OCR_MODELS_DIR` kosong).               |
| `OCR_DEFAULT_MODEL` | `tiny`           | Model bawaan ketika `model` kosong atau menggunakan ID `mistral-ocr-*`.                                    |
| `OCR_LISTEN`        | `127.0.0.1:8895` | Alamat listen TCP (`host:port`).                                                                           |
| `OCR_POOL_SIZE`     | `2`              | Jumlah instance mesin `RustO` per model (dibatasi `1..=64`).                                               |
| `OCR_API_KEY`       | _(kosong)_       | Token bearer opsional yang diwajibkan pada rute `/v1/*`.                                                   |
| `OCR_ALLOWED_HOSTS` | _(kosong)_       | Daftar hostname dipisahkan koma yang diizinkan untuk pengambilan URL `http(s)` (URI `data:` selalu aktif). |
| `OCR_AUTOROTATE`    | `false`          | Bawaan server untuk menerapkan orientasi EXIF (`1`, `true`, `yes`, `on`).                                  |

## Menjalankan Pengujian

```bash
OCR_MODELS_DIR=/path/to/models cargo test -p rusto-server --profile release-with-debug
```

> **Catatan**: Profil `release` workspace menggunakan `panic = "abort"` yang tidak dapat di-link oleh test harness Rust, sedangkan inferensi tanpa optimasi terlalu lambat. Gunakan `--profile release-with-debug` saat menjalankan uji integrasi `rusto-server`.
