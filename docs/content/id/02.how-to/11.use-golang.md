Modul `github.com/byrizki/rusto-rs/packages/go` menyediakan binding native Go via Cgo dengan dukungan `sync.RWMutex` yang aman serta konfigurasi dynamic linker bawaan (`-Wl,-rpath`).

## Instalasi

```bash
go get github.com/byrizki/rusto-rs/packages/go
```

Pastikan pustaka bersama `librusto.so` (Linux), `librusto.dylib` (macOS), atau `rusto.dll` (Windows) tersedia pada sistem atau path library Anda.

---

## 1. Inisialisasi Mesin

`rusto.Initialize()` (atau alias `rusto.New()`) menerima argumen JSON konfigurasi opsional (`configJSON ...string`). Jika dipanggil tanpa argumen, RustO! secara otomatis menyiapkan dan mengunduh model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0):

```go
package main

import (
	"fmt"
	"log"

	"github.com/byrizki/rusto-rs/packages/go"
)

func main() {
	// Opsi A: Zero-config (otomatis mengunduh ppocrv6-tiny jika belum ada di cache)
	engine, err := rusto.Initialize()
	if err != nil {
		log.Fatalf("Gagal inisialisasi RustO: %v", err)
	}
	defer engine.Close()

	// Opsi B (Opsional): Konfigurasi jalur model lokal eksplisit
	// customJSON := `{"template":"ppv6","detection":{"model_path":"models/det.rten"},"recognition":{"model_path":"models/rec.rten","dict_path":"models/dict.txt"}}`
	// customEngine, err := rusto.Initialize(customJSON)

	// 1. Deteksi baris terstruktur via fluent builder (.AsLines() -> .Run())
	res, err := engine.DetectText("receipt.jpg").
		WithAutoUnwarp(true).
		WithLayoutReading(true).
		WithPostRecognition(rusto.PostRecognitionOptions{ScoreThreshold: 0.6}).
		AsLines().
		Run()
	if err != nil {
		log.Fatalf("Deteksi gagal: %v", err)
	}

	for _, item := range res.Results {
		fmt.Printf("[%0.2f] %s (region=%d, layout=%d)\n",
			item.Score, item.Text, item.RegionID, item.LayoutType)
	}

	// 2. Rekonstruksi tata letak visual 2D spasial (.AsSpatial() -> .Run())
	spatial, err := engine.DetectText("receipt.jpg").
		WithPreRecognition(rusto.PreRecognitionOptions{
			LineYThreshold: 0.5,
			WordXThreshold: 0.4,
		}).
		AsSpatial().
		Run()
	if err != nil {
		log.Fatalf("Deteksi spasial gagal: %v", err)
	}

	if spatial.IsSpatial {
		fmt.Println("--- Tata Letak Spasial ---")
		fmt.Println(spatial.Text)
	}
}
```

## 2. Struktur `DetectTextResult` & `TextResult`

Metode terminal `.Run()` mengembalikan `(*rusto.DetectTextResult, error)`:

- Saat menggunakan `.AsLines()` atau `.AsWords()`: `res.IsSpatial` bernilai `false`, dan kandidat yang dikenali tersedia pada `res.Results` (`[]rusto.TextResult`). Setiap `TextResult` memuat `Text`, `Score`, `BoxPoints` (`[4][2]float32`), `Frame`, `RegionID` (`int32`, `-1` jika belum ditetapkan), dan `LayoutType` (`int32`, `-1` jika belum ditetapkan).
- Saat menggunakan `.AsSpatial()`: `res.IsSpatial` bernilai `true`, dan teks tata letak 2D hasil rekonstruksi tersedia pada `res.Text` (`string`).
