RustO! menyediakan binding FFI untuk Dart murni (`package:rusto/rusto.dart`) serta plugin Flutter (`package:rusto_flutter/rusto_flutter.dart`) yang mengekspor ulang seluruh API `RustO` beserta penautan biner native otomatis untuk Android, iOS, dan desktop.

## Instalasi

### Untuk Proyek Flutter

```bash
flutter pub add rusto_flutter
```

### Untuk Proyek Dart Murni / Server

```bash
dart pub add rusto
```

---

## 1. Inisialisasi & Pembersihan Mesin (`RustO`)

Baik `package:rusto_flutter/rusto_flutter.dart` maupun `package:rusto/rusto.dart` mengekspos kelas utama `RustO`. Memanggil `RustO.initialize()` tanpa argumen menginisialisasi model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) dan mengunduhnya secara otomatis jika belum tersedia di cache:

```dart
// Gunakan 'package:rusto_flutter/rusto_flutter.dart' pada proyek Flutter
import 'package:rusto/rusto.dart';

// Opsi A: Zero-config (otomatis menggunakan/mengunduh ppocrv6-tiny)
final engine = RustO.initialize();

// Opsi B: Jalur model lokal eksplisit melalui string JSON atau InitializeConfig
final customEngine = RustO.initialize('''
{
  "template": "ppv6",
  "detection": { "modelPath": "models/det.rten" },
  "recognition": { "modelPath": "models/rec.rten", "dictPath": "models/dict.txt" }
}
''');

// Selalu panggil close() untuk membebaskan handle native saat selesai
customEngine.close();
```

Anda juga dapat mengunduh model lebih awal dengan `RustO.downloadModel(model: 'ppocrv6-tiny')`.

## 2. Pengenalan Teks via Fluent Builder

Pada v0.4.0, rangkai opsi pemindaian pada `engine.detectText(...)`, pilih granularitas keluaran dengan `.asLines()`, `.asWords()`, atau `.asSpatial()`, lalu akhiri dengan `.run()` yang mengembalikan `DetectTextResult` (`DetectTextResultStructured` atau `DetectTextResultSpatial`):

### Deteksi Baris Terstruktur (`.asLines()`)

```dart
final result = engine
    .detectText('receipt.jpg')
    .withAutoUnwarp()
    .withLayoutReading()
    .withPostRecognition(scoreThreshold: 0.5)
    .asLines()
    .run();

if (result is DetectTextResultStructured) {
  for (final line in result.results) {
    print('[${line.score.toStringAsFixed(2)}] ${line.text}');
    print(
      '  Frame: left=${line.frame.left}, top=${line.frame.top}, '
      'w=${line.frame.width}, h=${line.frame.height}',
    );
    if (line.layoutType != null) {
      print('  Tata Letak: ${line.layoutType} (Wilayah #${line.regionId})');
    }
  }
}
```

### Dari Byte Gambar `Uint8List`

```dart
import 'dart:io';

final bytes = File('document.png').readAsBytesSync();
final wordRes = engine.detectText(bytes).asWords().run();
if (wordRes is DetectTextResultStructured) {
  print('Total kata: ${wordRes.results.length}');
}
```

## 3. Rekonstruksi Tata Letak Spasial (`.asSpatial()`)

```dart
final spatialRes = engine
    .detectText('invoice.png')
    .withPreRecognition(lineYThreshold: 0.5, wordXThreshold: 0.4)
    .asSpatial()
    .run();

if (spatialRes is DetectTextResultSpatial) {
  print('--- Tata Letak Dokumen Spasial ---');
  print(spatialRes.text);
}

engine.close();
```

## 4. Menjalankan di Aplikasi Flutter tanpa Memblokir UI (`Isolate.run`)

Karena panggilan FFI bersifat sinkron dan intensif CPU, jalankan inisialisasi dan inferensi di dalam `Isolate.run(...)` pada aplikasi Flutter agar animasi antarmuka tetap berjalan mulus 60/120 FPS:

```dart
import 'dart:isolate';
import 'package:rusto_flutter/rusto_flutter.dart';

Future<List<TextResult>> scanInBackground(String imagePath) {
  return Isolate.run(() {
    final engine = RustO.initialize();
    try {
      final res = engine
          .detectText(imagePath)
          .withAutoUnwarp()
          .withLayoutReading()
          .asLines()
          .run();
      return res is DetectTextResultStructured ? res.results : <TextResult>[];
    } finally {
      engine.close();
    }
  });
}
```

## 5. Praktik Terbaik Pengujian di Flutter (`testWidgets`)

Saat menulis `testWidgets` yang berinteraksi dengan FFI native, muat berkas gambar pengujian menggunakan operasi sinkron (`File(path).readAsBytesSync()`) alih-alih `await File(path).readAsBytes()` untuk menghindari kebuntuan antrean event pada zona `FakeAsync` milik Flutter.
