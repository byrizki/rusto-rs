RustO! menyediakan 3 biner baris perintah mandiri khusus yang dioptimalkan untuk kebutuhan lingkungan dan mesin inferensi yang berbeda:

| Biner                |   Ukuran   | Mesin                         | Deskripsi                                                                                             | Perintah Kompilasi                                         |
| :------------------- | :--------: | :---------------------------- | :---------------------------------------------------------------------------------------------------- | :--------------------------------------------------------- |
| **`rusto`** (Bawaan) | **2.9 MB** | Pure-Rust MNN (`rusto-nn`)    | CLI memory-safe tanpa dependensi eksternal, mendukung `.mnn`, `.onnx`, dan `.rten` (FP32, FP16, INT8) | `cargo build --release --bin rusto`                        |
| **`rusto-rten`**     | **6.7 MB** | Pure-Rust RTen (`rusto-rten`) | Biner khusus yang dikompilasi dengan mesin inferensi RTen FlatBuffers murni Rust (`.rten` FP32/INT8)  | `cargo build --release --bin rusto-rten --features rten`   |
| **`rusto-mnn`**      | **5.5 MB** | Alibaba MNN C++ (`rusto-mnn`) | Biner khusus yang dikompilasi dengan backend Alibaba MNN C++ asli                                     | `cargo build --release --bin rusto-mnn --features mnn-cpp` |

## Instalasi & Kompilasi

Kompilasi biner CLI langsung dari kode sumber dengan optimasi Release:

```bash
# Kompilasi biner bawaan rusto berbasis Rust murni (2.9 MB)
cargo build --release --bin rusto

# Kompilasi ketiga varian biner sekaligus
cargo build --release --bin rusto --bin rusto-rten --bin rusto-mnn --features rten,mnn-cpp
```

Berkas biner hasil kompilasi berada di `target/release/rusto` (serta `rusto-rten` dan `rusto-mnn`). Anda juga dapat memasang biner bawaan ke dalam `$PATH` sistem:

```bash
cargo install --path . --bin rusto
```

## 1. Pemanggilan Cepat

CLI `rusto` menerima path berkas gambar secara langsung (`rusto <IMAGE>`) maupun melalui subperintah eksplisit (`rusto ocr <IMAGE>`). Saat dijalankan tanpa path model lokal, `rusto` secara otomatis mengunduh model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`) ke direktori cache lokal (`~/.cache/rusto/models` di Linux):

```bash
# Pemanggilan langsung tanpa konfigurasi (bawaan: ppocrv6-tiny, keluaran JSON)
rusto receipt.jpg

# Bentuk ekuivalen menggunakan subperintah ocr
rusto ocr receipt.jpg

# Menjalankan model alternatif Indra OCR
rusto receipt.jpg --model indraocr

# Menghasilkan rekonstruksi tata letak 2D spasial dengan pelurusan & analisis tata letak
rusto invoice.png --enable-unwarp --enable-layout --format spatial
```

## 2. Pengunduh Model Khusus (`rusto download`)

Unduh bobot model terlebih dahulu untuk lingkungan luring (_offline_), kontainer Docker, atau pipeline CI:

```bash
# Unduh model bawaan (ppocrv6-tiny) ke direktori cache
rusto download

# Unduh model bawaan beserta model pendukung unwarp, orientasi, tata letak, dan urutan baca
rusto download --orient --unwarp --layout --reading-order

# Unduh model lain (misal PP-OCRv6 Small atau Indra OCR)
rusto download --model ppocrv6-small
rusto download --model indraocr

# Unduh paket bahasa regional
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang ja

# Unduh seluruh aset model kanonikal yang tersedia
rusto download --all

# Gunakan direktori cache kustom
rusto download --model indraocr --cache-dir /opt/rusto-models
```

## 3. Referensi Perintah & Opsi CLI

### Pola Perintah Utama

| Perintah                      | Deskripsi                                                                   |
| :---------------------------- | :-------------------------------------------------------------------------- |
| `rusto <IMAGE> [OPTIONS]`     | Menjalankan deteksi dan pengenalan teks secara langsung pada berkas gambar. |
| `rusto ocr <IMAGE> [OPTIONS]` | Subperintah eksplisit untuk menjalankan deteksi dan pengenalan teks.        |
| `rusto download [OPTIONS]`    | Mengunduh bobot model ke direktori cache lokal tanpa menjalankan OCR.       |

### Opsi `rusto` / `rusto ocr`

| Opsi                   | Flag                | Tipe     | Nilai Bawaan            | Deskripsi                                                                                                                                                                                                         |
| :--------------------- | :------------------ | :------- | :---------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Model**              | `-m`, `--model`     | `String` | `ppocrv6-tiny`          | Pipeline model kanonikal (`ppocrv6-tiny`, `ppocrv6-tiny-fp16`, `ppocrv6-tiny-int8`, `ppocrv6-small`, `ppocrv6-small-int8`, `ppocrv6-medium`, `ppocrv6-medium-int8`, `indraocr`, `ppocrv5`, `ppocrv4`, `ppocrv3`). |
| **Bahasa**             | `-l`, `--lang`      | `String` | Tidak Ada               | Kode bahasa target (`latin`, `ja`, `ko`, `ar`, `cyrillic`, `devanagari`, `chinese-cht`, dll.).                                                                                                                    |
| **Folder Model**       | `--model-path`      | `Path`   | Tidak Ada               | Direktori lokal yang berisi berkas deteksi, pengenalan, dan kamus/metadata.                                                                                                                                       |
| **Model Deteksi**      | `--det-model`       | `Path`   | Tidak Ada               | Jalur override ke berkas model deteksi (`.mnn` / `.rten` / `.onnx`).                                                                                                                                              |
| **Model Pengenalan**   | `--rec-model`       | `Path`   | Tidak Ada               | Jalur override ke berkas model pengenalan teks (`.mnn` / `.rten` / `.onnx`).                                                                                                                                      |
| **Kamus / Metadata**   | `--dict`            | `Path`   | Tidak Ada               | Jalur override ke berkas kosakata karakter atau metadata (`.txt` / `.json`).                                                                                                                                      |
| **Folder Cache**       | `--cache-dir`       | `Path`   | `~/.cache/rusto/models` | Jalur direktori cache untuk menyimpan dan mencari model unduhan.                                                                                                                                                  |
| **Unduh Saja**         | `--download-only`   | `Flag`   | `false`                 | Mengunduh aset model yang dibutuhkan ke cache lalu berhenti tanpa menjalankan inferensi.                                                                                                                          |
| **Format Keluaran**    | `-f`, `--format`    | `Enum`   | `json`                  | Format hasil: `json`, `text`, `tsv`, `markdown`, `text-ordered`, atau `spatial`.                                                                                                                                  |
| **Aktifkan CLS**       | `--enable-cls`      | `Flag`   | `false`                 | Mengaktifkan pengklasifikasi rotasi baris teks 180°.                                                                                                                                                              |
| **Model CLS**          | `--cls-model`       | `Path`   | Tidak Ada               | Jalur ke berkas model klasifikasi baris teks (`ppocr_cls.mnn` / `ppocr_cls.rten`).                                                                                                                                |
| **Aktifkan Orientasi** | `--enable-orient`   | `Flag`   | `false`                 | Mengaktifkan deteksi orientasi halaman dokumen (0°/90°/180°/270°).                                                                                                                                                |
| **Model Orientasi**    | `--orient-model`    | `Path`   | Tidak Ada               | Jalur ke berkas model orientasi dokumen (`indra_orient.mnn` / `ppocr_orient.mnn`).                                                                                                                                |
| **Aktifkan Unwarp**    | `--enable-unwarp`   | `Flag`   | `false`                 | Mengaktifkan pelurusan dokumen melengkung / kusut menggunakan UVDoc.                                                                                                                                              |
| **Model Unwarp**       | `--unwarp-model`    | `Path`   | Tidak Ada               | Jalur ke berkas model pelurusan dokumen (`uvdoc.mnn` / `uvdoc.rten`).                                                                                                                                             |
| **Aktifkan Layout**    | `--enable-layout`   | `Flag`   | `false`                 | Mengaktifkan deteksi wilayah tata letak dokumen dan pengurutan bacaan multikolom.                                                                                                                                 |
| **Varian Layout**      | `--layout-variant`  | `String` | `cdla`                  | Varian model tata letak: `cdla` (10 kelas, bawaan) atau `publaynet` (5 kelas).                                                                                                                                    |
| **Model Layout**       | `--layout-model`    | `Path`   | Tidak Ada               | Jalur ke berkas model deteksi tata letak (`layout_cdla.mnn` / `layout_cdla.rten`).                                                                                                                                |
| **Urutan Baca Neural** | `--reading-order`   | `Flag`   | `false`                 | Mengaktifkan pemulihan urutan baca berbasis transformer (`indra_order.mnn` / `indra_order.rten`).                                                                                                                 |
| **Batas Deteksi**      | `--det-limit`       | `Int`    | Sesuai preset           | Batas dimensi sisi gambar pada tahap inferensi deteksi (misal `736` atau `960`).                                                                                                                                  |
| **Sisi Maksimum**      | `--max-side-len`    | `Float`  | Tidak Ada               | Panjang sisi maksimum gambar pada tahap pra-deteksi untuk mempercepat pemindaian resolusi tinggi.                                                                                                                 |
| **Ambang Skor**        | `--score-threshold` | `Float`  | `0.5`                   | Skor kepercayaan minimum pengenalan teks `[0.0 - 1.0]` pada tahap pasca-pengenalan.                                                                                                                               |
| **Ukuran Batch**       | `--rec-batch-num`   | `Int`    | `6` (PP) / `1` (Indra)  | Jumlah potongan baris teks yang diproses serentak per batch inferensi pengenalan.                                                                                                                                 |

### Opsi Khusus `rusto download`

Selain `-m`/`--model`, `-l`/`--lang`, `--layout-variant`, `--reading-order`, dan `--cache-dir`, subperintah `rusto download` mendukung flag `--all` (unduh semua model), `--cls`, `--orient`, `--unwarp`, dan `--layout`.

### 2. Rekonstruksi Tata Letak Spasial 2D (`--format spatial`)

Merekonstruksi perataan kolom tabel, baris struk belanja, dan spasi horizontal dokumen asli secara visual. (Berbeda dengan `--format text-ordered` yang mengurutkan baris teks biasa dari atas ke bawah dan kiri ke kanan tanpa spasi perataan kolom):

```bash
rusto invoice.jpg --format spatial
```

```text
Deskripsi Barang           Jml       Harga       Total
Keyboard Mekanik             1 Rp1.200.000 Rp1.200.000
Mouse Nirkabel               2   Rp450.000   Rp900.000
USB-C Hub                    1   Rp350.000   Rp350.000
──────────────────────────────────────────────────────
Total Pembayaran:                          Rp2.450.000
```

## 5. Integrasi Shell & Pemrosesan Massal

### Menyimpan Hasil ke Berkas & Memfilter JSON dengan `jq`

Keluaran utama ditulis ke `stdout` sehingga dapat dialihkan langsung ke berkas atau dipipakan ke `jq`:

```bash
# Simpan keluaran JSON ke berkas
rusto receipt.jpg --format json > receipt.json

# Filter baris dengan skor kepercayaan di atas 95%
rusto receipt.jpg --score-threshold 0.7 --format json | \
  jq -r '.[] | select(.score > 0.95) | "\(.text) (\(.score * 100 | round)%)"'
```

### Pemindaian Seluruh Direktori Secara Paralel

Pindai seluruh gambar `.jpg` dan `.png` secara paralel menggunakan `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto {} --format spatial
```
