RustO! dilengkapi dengan antarmuka baris perintah (CLI) berperforma tinggi untuk OCR desktop, alur kerja terminal, manajemen model, dan otomatisasi CI/CD.

## Instalasi & Kompilasi

Kompilasi CLI langsung dari kode sumber dengan optimasi Release:

```bash
cargo build --release
```

Berkas biner hasil kompilasi berada di `target/release/rusto`. Anda juga dapat memasangnya langsung ke direktori `$PATH` sistem:

```bash
cargo install --path .
```

## 1. Pemanggilan Cepat

### Unduh Otomatis & Inferensi Bawaan

Pada RustO!, Anda tidak diwajibkan menentukan jalur model secara manual jika ingin menggunakan model kanonikal. RustO! secara otomatis mengunduh model yang diperlukan ke `~/.cache/rusto/models` saat pertama kali dijalankan:

```bash
# Menggunakan model kanonikal bawaan (indraocr)
rusto ocr receipt.jpg

# Menjalankan model ringan alternatif PP-OCRv6 Tiny
rusto ocr receipt.jpg --model ppocrv6-tiny

# Menghasilkan tata letak spasial 2D terformat
rusto ocr invoice.png --format text-ordered
```

---

## 2. Pengunduh Model Khusus (`rusto download`)

Unduh bobot model sebelumnya untuk lingkungan tanpa internet (offline), kontainer Docker, atau alur kerja CI:

```bash
# Unduh model bawaan (indraocr) ke ~/.cache/rusto/models
rusto download

# Unduh model kanonikal tertentu
rusto download --model ppocrv6-tiny
rusto download --model ppocrv6-small

# Unduh paket bahasa regional
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang japan

# Unduh seluruh model kanonikal yang tersedia
rusto download --all

# Tentukan direktori cache kustom
rusto download --model indraocr --cache-dir /opt/models
```

## 3. Referensi Perintah & Opsi CLI

### Subperintah

| Subperintah                   | Deskripsi                                                                                         |
| :---------------------------- | :------------------------------------------------------------------------------------------------ |
| `rusto ocr [IMAGE] [OPTIONS]` | Menjalankan deteksi dan pengenalan teks pada berkas gambar (bawaan jika berkas gambar diberikan). |
| `rusto download [OPTIONS]`    | Mengunduh bobot model pra-latih `.rten` ke direktori cache lokal.                                 |

### Opsi `rusto ocr`

| Opsi                  | Flag               | Tipe     | Nilai Bawaan            | Deskripsi                                                                                            |
| :-------------------- | :----------------- | :------- | :---------------------- | :--------------------------------------------------------------------------------------------------- |
| **Model**             | `--model`          | `String` | `indraocr`              | Nama model kanonikal (`indraocr`, `ppocrv6-tiny`, `ppocrv6-small`, `ppocrv5`, `ppocrv4`, `ppocrv3`). |
| **Folder Model**      | `--model-path`     | `Path`   | Tidak Ada               | Direktori dasar yang memuat berkas `det.rten`, `rec.rten`, dan `dict.txt`.                           |
| **Model Deteksi**     | `--det-model`      | `Path`   | Tidak Ada               | Jalur override khusus untuk berkas model pendeteksi DBNet.                                           |
| **Model Pengenalan**  | `--rec-model`      | `Path`   | Tidak Ada               | Jalur override khusus untuk berkas model pengenal CTC.                                               |
| **Kamus Karakter**    | `--dict`           | `Path`   | Tidak Ada               | Jalur override khusus untuk berkas teks kosakata kamus karakter.                                     |
| **Bahasa**            | `--lang`           | `String` | Tidak Ada               | Kode paket bahasa (misal `latin`, `cyrillic`, `ar`, `ja`, `ko`, `devanagari`).                       |
| **Folder Cache**      | `--cache-dir`      | `Path`   | `~/.cache/rusto/models` | Jalur direktori cache kustom untuk model yang diunduh.                                               |
| **Format Keluaran**   | `-f`, `--format`   | `Enum`   | `json`                  | Format hasil keluaran (`json`, `text`, `tsv`, `markdown`, `text-ordered`).                           |
| **Ambang Skor**       | `--text-score`     | `Float`  | `0.5`                   | Ambang batas skor kepercayaan minimum pengenalan teks [0.0 - 1.0].                                   |
| **Ukuran Batch**      | `--batch-num`      | `Int`    | `6`                     | Jumlah baris teks yang diproses serentak per batch inferensi pengenalan.                             |
| **Orientasi Dokumen** | `--enable-orient`  | `Flag`   | `false`                 | Mengaktifkan deteksi rotasi 0°/90°/180°/270° pada dokumen penuh.                                     |
| **Model Orientasi**   | `--orient-model`   | `Path`   | Tidak Ada               | Jalur ke berkas model pengklasifikasi orientasi dokumen.                                             |
| **Model CLS**         | `--cls-model`      | `Path`   | Tidak Ada               | Jalur ke berkas model klasifikasi inversi baris teks 180°.                                           |
| **Model Unwarp**      | `--unwarp-model`   | `Path`   | Tidak Ada               | Jalur ke berkas model unwarping / pelurusan lipatan dokumen.                                         |
| **Model Tata Letak**  | `--layout-model`   | `Path`   | Tidak Ada               | Jalur ke berkas model analisis tata letak dokumen.                                                   |
| **Varian Tata Letak** | `--layout-variant` | `String` | `cdla`                  | Varian model tata letak: `cdla` (10 kelas) atau `publaynet` (5 kelas).                               |
| **Urutan Baca**       | `--reading-order`  | `Flag`   | `false`                 | Mengaktifkan transformer pemulihan urutan baca alami dokumen.                                        |

## 4. Contoh Nyata Format Keluaran

### 1. JSON Terstruktur (`--format json`)

Menghasilkan JSON terstruktur lengkap dengan poligon kuad dan kotak pembatas (frame):

```bash
rusto ocr receipt.jpg --format json
```

```json
[
  {
    "text": "COFFEE SHOP",
    "score": 0.992,
    "box_points": [
      [95.0, 30.0],
      [275.0, 30.0],
      [275.0, 55.0],
      [95.0, 55.0]
    ],
    "frame": {
      "left": 95.0,
      "top": 30.0,
      "width": 180.0,
      "height": 25.0
    }
  },
  {
    "text": "Total $16.50",
    "score": 0.988,
    "box_points": [
      [40.0, 245.0],
      [320.0, 245.0],
      [320.0, 265.0],
      [40.0, 265.0]
    ],
    "frame": {
      "left": 40.0,
      "top": 245.0,
      "width": 280.0,
      "height": 20.0
    }
  }
]
```

### 2. Tata Letak Spasial Terformat (`--format text-ordered`)

Mempertahankan kolom tabel, baris struk belanja, dan indentasi dokumen asli:

```bash
rusto ocr invoice.jpg --format text-ordered
```

```text
Item Description           Qty       Price       Total
Mechanical Keyboard          1     $120.00     $120.00
Wireless Mouse               2      $45.00      $90.00
USB-C Hub                    1      $35.00      $35.00
──────────────────────────────────────────────────────
Total Amount:                                  $245.00
```

---

### 3. Nilai Berpemisah Tab (`--format tsv`)

Sangat cocok untuk pemrosesan skrip shell menggunakan `awk`, `cut`, atau spreadsheet:

```bash
rusto ocr receipt.jpg --format tsv
```

```text
COFFEE SHOP	0.992	95.0,30.0,275.0,30.0,275.0,55.0,95.0,55.0
2026-08-20	0.981	40.0,70.0,140.0,70.0,140.0,90.0,40.0,90.0
Total $16.50	0.988	40.0,245.0,320.0,245.0,320.0,265.0,40.0,265.0
```

## 5. Integrasi Shell & Pemrosesan Massal

### Memfilter JSON dengan `jq`

Mengekstrak baris teks dengan kepercayaan tinggi:

```bash
rusto ocr receipt.jpg --format json | \
  jq -r '.[] | select(.score > 0.95) | "\(.text) (\(.score * 100 | round)%)"'
```

### Pemindaian Seluruh Direktori Secara Paralel

Pindai seluruh gambar `.jpg` dan `.png` secara simultan menggunakan `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto ocr {} --format text-ordered
```
