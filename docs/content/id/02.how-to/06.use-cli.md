RustO! dilengkapi dengan aplikasi baris perintah (_command line interface_ / CLI) berkinerja tinggi untuk pemindaian OCR desktop, alur kerja terminal, dan automasi pipeline CI.

## Instalasi & Kompilasi

Kompilasi CLI langsung dari kode sumber dengan profil optimasi Release:

```bash
cargo build --release
```

Biner hasil kompilasi akan berada di `target/release/rusto`. Anda juga dapat memasangnya ke `$PATH` sistem:

```bash
cargo install --path .
```

---

## 1. Pemanggilan Dasar CLI

```bash
rusto --det-model models/det.mnn --rec-model models/rec.mnn --dict models/dict.txt receipt.jpg
```

---

## 2. Referensi Opsi & Flag CLI

| Opsi             | Flag              | Tipe   | Default | Deskripsi                                                          |
| ---------------- | ----------------- | ------ | ------- | ------------------------------------------------------------------ |
| Model Deteksi    | `--det-model`     | `Path` | Wajib   | Path ke berkas model deteksi MNN DBNet.                            |
| Model Pengenalan | `--rec-model`     | `Path` | Wajib   | Path ke berkas model pengenalan MNN CTC.                           |
| Kamus Karakter   | `--dict`          | `Path` | Wajib   | Path ke berkas teks kamus kosakata karakter.                       |
| Format Keluaran  | `-f`, `--format`  | `Enum` | `json`  | Mode keluaran (`json`, `text`, `tsv`, `markdown`, `text-ordered`). |
| Orientasi        | `--enable-orient` | `Flag` | `false` | Aktifkan deteksi orientasi halaman penuh.                          |
| Model Orientasi  | `--orient-model`  | `Path` | `None`  | Path ke berkas model orientasi MNN LCNet.                          |

## 3. Format Keluaran dengan Contoh Nyata

### 1. JSON Terstruktur (`--format json`)

Menghasilkan JSON terstruktur dengan titik-titik koordinat poligon dan frame kotak batas:

```bash
rusto --det-model det.mnn --rec-model rec.mnn --dict dict.txt --format json receipt.jpg
```

```json
[
  {
    "text": "KEDAI KOPI",
    "score": 0.992,
    "box_points": [
      [95.0, 30.0],
      [275.0, 30.0],
      [275.0, 55.0],
      [95.0, 55.0]
    ],
    "frame": {
      "left": 95.0,

      "width": 180.0,
```

### 2. Tata Letak Spasial Terformat (`--format text-ordered`)

Mempertahankan perataan kolom tabel, baris struk, dan indentasi dokumen:

```bash
rusto --det-model det.mnn --rec-model rec.mnn --dict dict.txt --format text-ordered invoice.jpg
```

```text
Deskripsi Barang           Jumlah        Harga         Total
Keyboard Mekanikal              1    Rp1.200.000   Rp1.200.000
Mouse Nirkabel                  2      Rp450.000     Rp900.000
Hub USB-C                       1      Rp350.000     Rp350.000
──────────────────────────────────────────────────────────────
Total Pembayaran:                                  Rp2.450.000
```

### 3. Nilai Dipisahkan Tab (`--format tsv`)

Ideal untuk pemrosesan skrip bash atau impor spreadsheet:

```bash
rusto --det-model det.mnn --rec-model rec.mnn --dict dict.txt --format tsv receipt.jpg
```


## 4. Integrasi Skrip Shell & Pemrosesan Batch

### Menyalurkan Keluaran ke `jq` untuk Pemfilteran

Ambil teks dengan tingkat kepercayaan di atas 95%:

```bash
rusto --det-model det.mnn --rec-model rec.mnn --dict dict.txt receipt.jpg | \
  jq -r '.[] | select(.score > 0.95) | "\(.text) (\(.score * 100 | round)%)"'
```

### Pemindaian Batch Seluruh Direktori

Pindai semua gambar `.jpg` dan `.png` secara paralel menggunakan `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto --det-model det.mnn --rec-model rec.mnn --dict dict.txt --format text-ordered {}
```
