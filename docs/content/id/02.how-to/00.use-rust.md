Crate `rusto-rs` (diimpor dalam kode sebagai `rusto`) adalah mesin inti Rust murni yang mentenagai seluruh binding platform RustO!. Crate ini menyediakan abstraksi tanpa biaya (_zero-cost_), jaminan keamanan memori, serta pra-pemrosesan gambar terakselerasi SIMD tanpa ketergantungan pada OpenCV.

## Instalasi

Tambahkan `rusto-rs` ke dalam `Cargo.toml`:

```toml
[dependencies]
rusto-rs = "0.4.0"
```

Secara bawaan, `rusto-rs` menyertakan runtime inferensi MNN berbasis Rust murni (`rusto-nn`) dan mengaktifkan fitur `default = ["ffi", "rten"]`. Fitur yang tersedia meliputi `rten` (backend inferensi RTen untuk model `.rten`), `ffi` (binding C FFI & UniFFI), `webgpu` (akselerasi GPU WebGPU), `cuda` (akselerasi NVIDIA GPU), dan `mnn-cpp` (backend MNN C++ opsional).

## 1. Inisialisasi Mesin (`InitializeConfig`)

Inisialisasi mesin OCR satu kali per siklus aplikasi atau thread worker. Panggil `rusto::init()` terlebih dahulu untuk mendaftarkan backend inferensi.

### Opsi A: Zero-Config dengan Pengunduhan Model Otomatis (Indra OCR)

Saat jalur model tidak ditentukan secara eksplisit, `parse_config_with_auto_download("{}")` secara otomatis mengunduh model bawaan **Indra OCR** (`indraocr`) ke direktori cache lokal (`~/.cache/rusto/models`):

```rust
use rusto::download::parse_config_with_auto_download;
use rusto::RustO;

rusto::init();
let config = parse_config_with_auto_download("{}")?;
let mut ocr = RustO::initialize(config)?;
```

Jika model sudah berada di cache lokal, Anda juga dapat langsung memanggil `RustO::initialize(InitializeConfig::default())?`.

### Opsi B: Preset Eksplisit (`indra`, `ppv6`, `ppv5`, `ppv4`)

Untuk lingkungan dengan berkas model lokal, gunakan konstruktor preset sesuai arsitektur model (.mnn atau .rten):

```rust
use rusto::{InitializeConfig, RustO};

rusto::init();

// Preset unggulan Indra OCR
let indra_cfg = InitializeConfig::indra("models/det.mnn", "models/rec.mnn", "models/meta.json");
let mut indra_ocr = RustO::initialize(indra_cfg)?;

// Preset multibahasa PP-OCRv6
let ppv6_cfg = InitializeConfig::ppv6("models/det.mnn", "models/rec.mnn", "models/dict.txt")
    .with_det_thresh(0.3)
    .with_det_box_thresh(0.6)
    .with_limit_side_len(736)
    .with_limit_type("min")
    .with_unclip_ratio(2.0)
    .with_use_dilation(true)
    .with_text_score(0.5)
    .with_rec_batch_num(6);

let mut ppv6_ocr = RustO::initialize(ppv6_cfg)?;
```

### Model Pipeline Tambahan (Orientasi, CLS, Unwarp & Tata Letak)

Untuk dokumen hasil foto kamera yang melengkung, miring, atau multikolom, rangkai model pendukung pada `InitializeConfig`:

```rust
use rusto::{InitializeConfig, LayoutConfig, RustO, UnwarpConfig};

let mut config = InitializeConfig::indra("models/det.mnn", "models/rec.mnn", "models/meta.json")
    .with_orientation_threshold("models/indra_orient.mnn", 0.85);

config.unwarp = Some(UnwarpConfig::new("models/uvdoc.mnn"));
config.layout = Some(LayoutConfig::new("models/layout_cdla.mnn"));

let mut ocr = RustO::initialize(config)?;
```

### Komposisi Mesin Generik & Pluggable

RustO! menyediakan trait `InferenceSession` sehingga Anda dapat memasang sesi inferensi kustom (seperti ONNX Runtime `ort`, Tract, Candle, atau sesi tiruan untuk pengujian unit) tanpa menyentuh logika geometri OCR:

```rust
use rusto::{InitializeConfig, RustO, TextDetector, TextRecognizer};

let config = InitializeConfig::ppv6("models/det.mnn", "models/rec.mnn", "models/dict.txt");

// Pilihan 1: Berikan sesi inferensi kustom secara langsung
let ocr = RustO::with_custom_engines(config.clone(), my_det_session, my_rec_session)?;

// Pilihan 2: Gabungkan komponen TextDetector dan TextRecognizer
let det = TextDetector::new(config.det.clone())?;
let rec = TextRecognizer::new(config.rec.clone())?;
let ocr = RustO::with_components(config.global, det, rec)?;
```

## 2. Opsi Permintaan & Fluent Builder

Pada v0.4.0, opsi runtime dirangkai melalui trait `DetectTextBuilderExt` (`detect_text_builder` / `detect_text_rgb_builder`), dipilih granularitas keluarannya dengan `.as_lines()`, `.as_words()`, atau `.as_spatial()`, lalu dieksekusi dengan satu metode akhir `.run()`:

```rust
use rusto::{
    DetectTextBuilderExt, ImageSource, PostDetectionOptions, PostRecognitionOptions,
    PreRecognitionOptions,
};

let result = ocr
    .detect_text_builder(ImageSource::Path("data/invoice.jpg".into()))
    .with_auto_unwarp(true)
    .with_layout_reading(true)
    .with_post_detection(PostDetectionOptions {
        use_dilation: Some(true),
        unclip_ratio: Some(2.0),
        threshold: Some(0.3),
        box_threshold: Some(0.6),
        ..Default::default()
    })
    .with_pre_recognition(PreRecognitionOptions {
        line_y_threshold: Some(0.5),
        word_x_threshold: Some(0.4),
    })
    .with_post_recognition(PostRecognitionOptions {
        score_threshold: Some(0.6),
    })
    .as_lines()
    .run()?;
```

## 3. Sumber Gambar yang Didukung

`ImageSource` menerima path berkas sistem maupun buffer byte gambar terenkode di memori, sedangkan `detect_text_rgb_builder` menerima piksel RGB24 mentah yang sudah didekode:

```rust
use rusto::ImageSource;
use std::path::PathBuf;

// 1. Path berkas filesystem
let source_path = ImageSource::Path(PathBuf::from("data/invoice.jpg"));

// 2. Buffer byte terenkode dalam memori RAM (PNG, JPEG)
let raw_bytes: Vec<u8> = std::fs::read("data/invoice.jpg")?;
let source_bytes = ImageSource::Bytes(raw_bytes);
```

## 4. Contoh Praktis & Penanganan Keluaran

### Contoh A: Mengekstrak Baris Teks Terstruktur

```rust
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource};

let result = ocr
    .detect_text_builder(ImageSource::Path("invoice.png".into()))
    .with_layout_reading(true)
    .as_lines()
    .run()?;

if let DetectTextResult::Structured(items) = result {
    for item in items {
        println!("Teks: {}", item.text);
        println!("Skor: {:.3}", item.score);
        println!("Titik Poligon [TL, TR, BR, BL]: {:?}", item.box_points);
        println!(
            "Frame: Kiri={}, Atas={}, Lebar={}, Tinggi={}",
            item.frame.left, item.frame.top, item.frame.width, item.frame.height
        );
        if let Some(layout_type) = item.layout_type {
            println!("Wilayah #{:?}: {:?}", item.region_id, layout_type);
        }
    }
}
```

### Contoh B: Rekonstruksi Tata Letak Spasial Dokumen

Pertahankan perataan kolom tabel, faktur, dan formulir menjadi teks 2D terformat menggunakan `.as_spatial()`:

```rust
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource, PreRecognitionOptions};

if let DetectTextResult::Spatial(layout_text) = ocr
    .detect_text_builder(ImageSource::Path("table.png".into()))
    .with_pre_recognition(PreRecognitionOptions {
        line_y_threshold: Some(0.5),
        word_x_threshold: Some(0.4),
    })
    .as_spatial()
    .run()?
{
    println!("{layout_text}");
}
```

### Contoh C: Pemrosesan Batch Multi-Thread dengan Rayon

Karena setiap instans `RustO` memegang status sesi inferensi secara eksklusif (`&mut self`), gunakan instans per worker thread untuk beban kerja paralel:

```rust
use rayon::prelude::*;
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource, InitializeConfig, RustO};
use std::path::PathBuf;

rusto::init();

let image_paths: Vec<PathBuf> = vec![
    "doc1.jpg".into(),
    "doc2.jpg".into(),
    "doc3.jpg".into(),
    "doc4.jpg".into(),
];

image_paths.par_iter().for_each(|path| {
    let config = InitializeConfig::indra("models/det.mnn", "models/rec.mnn", "models/meta.json");
    let mut thread_ocr = RustO::initialize(config).expect("Gagal inisialisasi thread OCR");

    let result = thread_ocr
        .detect_text_builder(ImageSource::Path(path.clone()))
        .as_lines()
        .run()
        .expect("Terjadi kesalahan OCR");

    if let DetectTextResult::Structured(lines) = result {
        println!("Selesai memproses {:?}: ditemukan {} baris", path, lines.len());
    }
});
```
