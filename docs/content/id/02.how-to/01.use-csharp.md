Paket NuGet `RustODotnet` menyediakan binding C# berkinerja tinggi dan menyertakan runtime native bawaan untuk Windows (`x64`, `arm64`), Linux (`x64`, `arm64`), dan macOS (`x64`, `arm64`).

## Instalasi

Pasang paket inti dari NuGet:

```bash
dotnet add package RustODotnet
```

Model bawaan **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`) diunduh secara otomatis pada eksekusi pertama saat memanggil `RustO.Initialize()`, dapat diunduh terlebih dahulu melalui `RustO.DownloadModel("ppocrv6-tiny")` atau perintah CLI `rusto download`, maupun diarahkan ke path berkas lokal secara eksplisit.

## 1. Siklus Hidup Mesin & Inisialisasi

`RustO` mengelola pointer memori native unmanaged melalui `IDisposable`. Selalu gunakan pernyataan `using` atau panggil `Dispose()` pada blok `using` saat instans tidak lagi digunakan:

```csharp
using System;
using RustODotnet;

// 1. Inisialisasi tanpa konfigurasi (otomatis mengunduh model bawaan PP-OCRv6 Tiny FP32 jika belum ada di cache)
using var ocr = RustO.Initialize();

// 2. Atau gunakan preset Indra OCR / PP-OCRv6 dengan jalur model lokal eksplisit:
var customConfig = InitializeConfig.Indra(
    detModelPath: "models/det.rten",
    recModelPath: "models/rec.rten",
    dictPath: "models/meta.json"
);

using var customOcr = RustO.Initialize(customConfig);
```

## 2. Opsi Permintaan & Fluent Builder

Pada v0.4.0, konfigurasikan opsi runtime menggunakan fluent builder chaining dengan pemilih granularitas `.AsLines()`, `.AsWords()`, atau `.AsSpatial()`, lalu akhiri dengan `.Run()`:

```csharp
var result = ocr.DetectText("invoices/sample.jpg")
    .WithAutoUnwarp()
    .WithLayoutReading()
    .WithPostDetection(p =>
    {
        p.UseDilation = true;
        p.UnclipRatio = 2.0f;
        p.Threshold = 0.3f;
        p.BoxThreshold = 0.6f;
    })
    .WithPreRecognition(p =>
    {
        p.LineYThreshold = 0.5f;
        p.WordXThreshold = 0.4f;
    })
    .WithPostRecognition(p =>
    {
        p.ScoreThreshold = 0.6f;
    })
    .AsLines()
    .Run();
```

## 3. Sumber Gambar yang Didukung

`ImageSource` menerima path berkas/URI atau larik byte gambar terenkode di memori, sedangkan `.Rgb(...)` menerima piksel RGB24 mentah:

```csharp
using System.IO;
using RustODotnet;

// 1. Path filesystem atau file:// URI
var uriSource = new UriImageSource("invoices/sample.jpg");

// 2. Larik byte dalam memori (misal dari stream atau ASP.NET Core IFormFile)
byte[] imageBytes = await File.ReadAllBytesAsync("invoices/sample.jpg");
var bytesSource = new BytesImageSource(imageBytes);
```

## 4. Contoh Praktis & Penanganan Keluaran

### Contoh A: Deteksi Baris Terstruktur dengan Koordinat Frame & Tata Letak

```csharp
using System;
using RustODotnet;

using var ocr = RustO.Initialize();
var result = ocr.DetectText("receipt.jpg")
    .WithLayoutReading()
    .AsLines()
    .Run();

if (result is StructuredDetectTextResult structured)
{
    Console.WriteLine($"Ditemukan {structured.Items.Count} baris teks:\n");
    foreach (var item in structured.Items)
    {
        Console.WriteLine($"[{item.Frame.Left:F0}, {item.Frame.Top:F0}, {item.Frame.Width:F0}x{item.Frame.Height:F0}]");
        Console.WriteLine($"  Teks: {item.Text}");
        Console.WriteLine($"  Skor: {item.Score:P1}");
        if (item.LayoutType != null)
        {
            Console.WriteLine($"  Tata Letak: {item.LayoutType} (Wilayah #{item.RegionId})");
        }
    }
}
```

### Contoh B: Mengekstrak Tabel Dokumen ke Tata Letak Spasial

```csharp
using System;
using RustODotnet;

using var ocr = RustO.Initialize();

var spatialResult = ocr.DetectText("invoice_table.png")
    .WithPreRecognition(p =>
    {
        p.LineYThreshold = 0.5f;
        p.WordXThreshold = 0.4f;
    })
    .AsSpatial()
    .Run();

if (spatialResult is SpatialDetectTextResult spatial)
{
    Console.WriteLine("--- Teks Spasial Hasil Rekonstruksi ---");
    Console.WriteLine(spatial.Text);
}
```

### Contoh C: Implementasi Controller ASP.NET Core Web API

```csharp
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Mvc;
using RustODotnet;
using System.IO;
using System.Threading.Tasks;

[ApiController]
[Route("api/[controller]")]
public class OcrController : ControllerBase
{
    private readonly RustO _ocr;

    public OcrController()
    {
        // Inisialisasi satu kali sebagai service singleton / scoped
        _ocr = RustO.Initialize();
    }

    [HttpPost("scan")]
    public async Task<IActionResult> ScanDocument(IFormFile file)
    {
        if (file == null || file.Length == 0)
            return BadRequest("Tidak ada berkas gambar yang diunggah.");

        using var memoryStream = new MemoryStream();
        await file.CopyToAsync(memoryStream);

        var result = _ocr
            .DetectText(new BytesImageSource(memoryStream.ToArray()))
            .AsSpatial()
            .Run();

        if (result is SpatialDetectTextResult spatial)
        {
            return Ok(new { text = spatial.Text });
        }

        return StatusCode(500, "Pemrosesan OCR gagal.");
    }
}
```
