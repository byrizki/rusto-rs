**RustO!** adalah mesin _Optical Character Recognition_ (OCR) berperforma tinggi dan toolkit lintas-platform yang ditulis dalam bahasa Rust murni. Berbasis [RapidOCR](https://github.com/RapidAI/RapidOCR) dan ditenagai oleh model _deep learning_ [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) dengan mesin inferensi ringan Rust murni [RTen](https://github.com/robertknight/rten) (serta arsitektur komposisi mesin kustom yang mudah diganti), RustO! menghadirkan kecepatan inferensi sub-detik, konsumsi memori sangat rendah, bebas dari ketergantungan runtime OpenCV, dan mencapai **paritas transkripsi karakter 100%** pada kumpulan uji dokumen standar serta paritas akurasi penuh pada dataset OmniDocBench dibandingkan implementasi C++ OpenCV bawaan.

## 🎯 Alur Arsitektur Pipeline

RustO! mengorkestrasi pipeline OCR dan analisis tata letak visual dari ujung ke ujung (_end-to-end_) yang dioptimalkan untuk perangkat _edge_ dan server berkecepatan tinggi:

```mermaid
flowchart TD
    A["Sumber Gambar Masukan<br/>(Path Filesystem, Buffer RAM, atau URI Native)"] --> B["1. Pra-pemrosesan & Penskalaan Ukuran<br/>(Penskalaan Aspek Rasio, Padding, Normalisasi)"]
    B --> C["2. Deteksi Teks DBNet<br/>(Peta Probabilitas, Binarisasi, Dilatasi, Pemotongan Poligon)"]
    C --> D{"3. Pengklasifikasi CLS?<br/>(Opsional: Teks Terbalik 0° vs 180°)"}
    D -->|Aktif| E["Putar Teks Terbalik 180°"]
    D -->|Nonaktif / Dilewati| F["Pemotongan Perspektif & Batch Paralel Rayon"]
    E --> F
    F --> G["4. Pengenalan Teks CTC<br/>(Batched SVTR/CRNN, Kamus 50 Bahasa)"]
    G --> H{"Pilihan Mode Keluaran?"}
    H -->|lines / words| I["Keluaran Terstruktur<br/>(TextResult dengan BoxPoints & Frame)"]
    H -->|spatial| J["5. Rekonstruksi Tata Letak Spasial<br/>(Kluster Baris Y & Perataan Kolom X)"]
    J --> K["Teks Terformat Spasial<br/>(Tabel, Struk, dan Indentasi Rapi)"]
```

## ⚡ Keunggulan Utama

- **🚀 Inti Rust 100% Murni**: Tanpa dependensi OpenCV. Binarisasi gambar, pelacakan kontur, _polygon clipping_, dan transformasi afinitas diimplementasikan dalam Rust yang aman memori dengan akselerasi SIMD.
- **📦 Ukuran Biner Sangat Ringkas**: Biner mandiri berukuran ~5 MB, dibandingkan 50+ MB pada tumpukan OpenCV + ONNX runtime tradisional.
- **📄 Rekonstruksi Tata Letak Spasial**: Dukungan bawaan untuk merekonstruksi struk, faktur (invoice), tabel multikolom, dan formulir langsung menjadi teks yang terformat rapi.
- **🧠 Ekosistem Model Lengkap**: Dukungan langsung untuk arsitektur **PP-OCRv6** (Tiny, Small, Medium), **PP-OCRv5** (Mobile, Server), dan **PP-OCRv4** (Mobile, Server).
- **🌐 50+ Bahasa dalam Satu Model**: PP-OCRv6 menggunakan kamus terpadu yang mendukung alfabet Latin, Sirilik, CJK (Mandarin/Jepang/Korea), Dewanagari, Arab, dan lainnya secara bersamaan.
- **📱 SDK Lintas Platform**: Paket siap pakai untuk **Rust**, **.NET / C#**, **React Native**, **iOS (Swift)**, **Android (Kotlin)**, dan **C FFI**.

## 📊 Perbandingan Kinerja & Paritas Akurasi

Dievaluasi secara empiris terhadap PaddleOCR resmi dan RapidOCR (C++ ONNX Runtime) menggunakan dataset standar **OmniDocBench** dan pemindaian dokumen riil (1600×993 px, 27 baris teks):

| Metrik                                             | RustO! (Rust Murni + RTen)                            | Pipeline Tradisional OpenCV + C++                 | Keunggulan                        |
| :------------------------------------------------- | :---------------------------------------------------- | :------------------------------------------------ | :-------------------------------- |
| **Latensi Rata-Rata OmniDocBench**                 | **439.2 ms** (Indra) / **1,104.4 ms** (PP-OCRv6 Tiny) | 605.3 ms (PaddleOCR) / 1,011.5 ms (RapidOCR Tiny) | ⚡ Eksekusi Rust murni yang cepat |
| **Pipeline Dokumen Tunggal (1600×993 px)**         | **678.08 ms** (Det: 312 ms, Rec: 169 ms, 27 baris)    | 447.83 ms (C++ ONNX Runtime)                      | ⚡ Sub-detik ujung ke ujung       |
| **Paritas Transkripsi (Pindaian Resolusi Tinggi)** | **100% identik karakter per karakter**                | Tolok ukur dasar (100%)                           | 🎯 Kotak batas & teks identik     |
| **Akurasi Dasar OmniDocBench (1 - NED)**           | **45.34%** (PP-OCRv6 Tiny)                            | 45.33% (PaddleOCR Tiny)                           | 🎯 Paritas eksak (Δ < 0.01%)      |
| **Puncak Konsumsi Memori (RAM)**                   | **253.9 MB** (PP-OCRv6 Tiny pada OmniDocBench)        | 392.5 MB (RapidOCR) / 659.3 MB (PaddleOCR)        | 🔒 **Hemat 35%–61% memori**       |
| **Ukuran Biner CLI**                               | **5.5 MB** (Mandiri)                                  | ~55 MB+ (libopencv, onnxruntime shared libs)      | 📦 **Hemat 90%**                  |
| **Ukuran Bundle WASM**                             | **517 KB** (gzipped Rust Murni RTen)                  | 3.78 MB (gzipped ONNX Runtime WASM)               | 🌐 **86% lebih ringan di web**    |
| **Keamanan & Konkurensi**                          | _Memory-safe_ (Jaminan Rust borrow checker)           | Manajemen pointer manual & thread lock            | 🛡️ Nol celah _data race_          |
