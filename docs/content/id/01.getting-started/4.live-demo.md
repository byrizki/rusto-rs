## Cara Kerja

1. **Pemrosesan Sisi Klien**: Pipeline inferensi OCR berjalan langsung di perangkat Anda menggunakan WebAssembly (`@rustors/web`) tanpa mengunggah gambar ke server.
2. **Kotak Pembatas Interaktif**: Arahkan kursor ke kotak deteksi mana pun pada kanvas gambar untuk melihat teks, wilayah tata letak, dan tingkat kepercayaan skor. Klik kotak untuk menyalin teks.
3. **Pilihan Granularitas**: Pilih antara pengelompokan baris (`lines` / `.asLines()`) dan token kata individual (`words` / `.asWords()`), atau lihat rekonstruksi tata letak 2D spasial (`spatial` / `.asSpatial()`) pada sub-tab Tata Letak Spasial.
4. **Ekspor Data**: Salin hasil dengan cepat ke Papan Klip, format tabel CSV, atau JSON terstruktur.
