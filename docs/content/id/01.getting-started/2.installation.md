RustO! dikemas secara modular di berbagai ekosistem manajer paket bahasa. Bobot model (`.mnn`, `.rten`) dipisahkan dari biner SDK dan otomatis diunduh dari Hugging Face Hub (`byrizki/rusto-models`) ke cache lokal saat inisialisasi pertama (`ppocrv6-tiny` FP32 secara bawaan), atau dapat diunduh sebelumnya untuk lingkungan luring (_offline_). Pilih target lingkungan pengembangan Anda di bawah ini.

## 1. Rust (`Cargo.toml`)

Tambahkan `rusto-rs` via `cargo`:

```bash
cargo add rusto-rs
```

Atau definisikan langsung pada file `Cargo.toml`:

```toml
[dependencies]
rusto-rs = "0.4.0"
```

### Fitur Cargo & Biner Khusus

Secara bawaan, `rusto-rs` menyertakan runtime inferensi MNN berbasis Rust murni (`rusto-nn`) dan mengaktifkan `default = ["ffi"]`.

RustO! menyediakan 3 biner CLI terdedikasi:

- `rusto`: Biner CLI utama yang ringan (**2.9 MB**) berbasis Rust murni MNN (`rusto-nn`) untuk model `.mnn` (termasuk FP16 dan INT8) dengan dukungan bawaan format ONNX dan RTen.
- `rusto-rten`: Biner CLI terdedikasi (**6.7 MB**) menggunakan mesin inferensi RTen asli (`rusto-rten`) untuk model `.rten` (FP32 dan INT8, `--features rten`).
- `rusto-mnn`: Biner CLI terdedikasi (**5.5 MB**) menggunakan mesin inferensi Alibaba MNN C++ asli (`rusto-mnn`) untuk model `.mnn` (`--features mnn-cpp`).

| Fitur     | Status Bawaan | Deskripsi                                                                                                   |
| --------- | :-----------: | ----------------------------------------------------------------------------------------------------------- |
| `ffi`     |      Ya       | Mengaktifkan binding C FFI dan perancah UniFFI untuk mengintegrasikan RustO! ke runtime bahasa lain.        |
| `rten`    |     Tidak     | Mengaktifkan mesin inferensi jaringan saraf RTen (`rusto-rten`) untuk model `.rten`.                        |
| `mnn-cpp` |     Tidak     | Mengaktifkan backend inferensi MNN C++ opsional (`rusto-mnn`) untuk eksekusi berakselerasi perangkat keras. |
| `webgpu`  |     Tidak     | Mengaktifkan akselerasi GPU lintas-platform berbasis WebGPU (`rusto-nn-webgpu`).                            |
| `cuda`    |     Tidak     | Mengaktifkan akselerasi GPU NVIDIA melalui `rusto-nn-cuda`.                                                 |

Untuk hanya bergantung pada runtime inti Rust murni MNN tanpa RTen atau C FFI:

```toml
[dependencies]
rusto-rs = { version = "0.4.0", default-features = false }
```

### Server HTTP (`rusto-server`)

Jalankan server HTTP `POST /v1/ocr` self-hosted yang kompatibel dengan Mistral dari crate workspace `crates/rusto-server`:

```bash
OCR_MODELS_DIR=/path/to/models cargo run -p rusto-server --release
```

Lihat [Panduan Server HTTP](../02.how-to/14.use-http-server.md) untuk detail endpoint dan konfigurasi variabel lingkungan.

## 2. Node.js (npm / yarn / pnpm)

Pasang `@rustors/node` via manajer paket pilihan Anda:

```bash
npm install @rustors/node
# atau yarn add @rustors/node
# atau pnpm add @rustors/node
```

Biner native N-API yang telah dirakit secara otomatis terdeteksi untuk Linux (x64/arm64), macOS (Apple Silicon & Intel), dan Windows (x64).

---

## 3. Python (pip / PyPI)

Pasang wheel pra-rakit dari PyPI:

```bash
pip install rusto
```

Mendukung Python 3.9+ di seluruh lingkungan Linux, macOS, dan Windows.

---

## 4. Golang (Cgo)

Unduh paket Go:

```bash
go get github.com/byrizki/rusto-rs/packages/go
```

> **Catatan**: Kompilasi membutuhkan library bersama `librusto`. Atur `CGO_LDFLAGS="-L/path/to/lib -Wl,-rpath,/path/to/lib"` atau tempatkan `librusto.so` / `librusto.dylib` ke dalam path library sistem Anda.

---

## 5. Java / JVM (JitPack / Gradle / Maven)

Tambahkan `rusto-java` dari JitPack menggunakan Gradle:

```groovy
repositories {
    mavenCentral()
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-java:0.4.0'
}
```

Atau Maven:

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.byrizki.rusto-rs</groupId>
    <artifactId>rusto-java</artifactId>
    <version>0.4.0</version>
</dependency>
```

## 7. .NET / C# (NuGet)

Pasang paket inti dari NuGet:

```bash
dotnet add package RustODotnet
```

Bobot model dipisahkan dari paket NuGet dan diselesaikan secara otomatis saat pertama kali aplikasi dijalankan melalui `RustO.Initialize()` atau diunduh sebelumnya dengan `RustO.DownloadModel("ppocrv6-tiny")`.

## 8. React Native (npm / yarn / pnpm)

Pasang paket React Native npm:

```bash
npm install @rustors/react-native
```

### Konfigurasi iOS (`ios/Podfile`)

Pada `ios/Podfile`, pastikan tautan statis standar diaktifkan:

```ruby
target 'YourApp' do
  use_frameworks! :linkage => :static
end
```

Kemudian jalankan instalasi CocoaPods:

```bash
cd ios && pod install
```

### Konfigurasi Android (`android/app/build.gradle`)

Pada root `settings.gradle`, pastikan repositori JitPack sudah ditambahkan:

```groovy
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}
```

Aset model dapat disertakan dalam folder `assets/` aplikasi atau diunduh secara dinamis saat runtime melalui `initialize({ model: 'ppocrv6-tiny' })`.

---

## 9. iOS (Swift / CocoaPods & SPM)

### Swift Package Manager (SPM)

Di Xcode, pilih **File > Add Package Dependencies...** dan masukkan:

```text
https://github.com/byrizki/rusto-rs.git
```

Atau dalam file `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/byrizki/rusto-rs.git", from: "0.4.0")
]
```

### CocoaPods

Pada file `Podfile` proyek Anda:

```ruby
target 'YourApp' do
  use_frameworks!

  pod 'RustO', '~> 0.4.0'
end
```

Jalankan perintah `pod install`. Berkas model dapat disertakan langsung ke target aplikasi, diletakkan pada folder dokumen aplikasi, atau diunduh otomatis saat runtime dengan `try RustO.initialize()` maupun `try RustO.downloadModel(model: "ppocrv6-tiny")`.

## 10. Android (Kotlin / Gradle)

Pastikan repositori JitPack terdaftar pada `settings.gradle`:

```groovy
repositories {
    maven { url 'https://jitpack.io' }
}
```

Tambahkan pustaka inti pada `build.gradle` aplikasi Anda:

```groovy
dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-android:v0.4.0'
}
```

Berkas bobot model diekstrak dari folder `assets/` jika dibundel, atau diunduh secara otomatis ke `context.cacheDir/rusto/models` saat memanggil `RustO.initialize(context)`.

## 12. C / Native Shared Libraries & Headers

Pustaka bersama dinamis pra-rakit dan file header C dirilis pada setiap [GitHub Release](https://github.com/byrizki/rusto-rs/releases):

- **Linux**: `librusto.so` (`x86_64`, `aarch64`)
- **macOS**: `librusto.dylib` (Universal `arm64` + `x86_64`)
- **Windows**: `rusto.dll`, `rusto.lib` (`x64`, `arm64`)
- **Header C**: `rusto.h`

Untuk melakukan kompilasi dari kode sumber dengan fitur FFI aktif:

```bash
# Kompilasi profil release standar (performa tinggi opt-level=3, hasil di target/release/)
cargo build --release --locked --features ffi,rten --lib

# Profil teroptimasi ukuran (opt-level="z", hasil di target/compressed/)
cargo build --profile compressed --locked --features ffi,rten --lib
```

File pustaka dinamis dan statis hasil kompilasi akan berada di direktori `target/release/` (atau `target/compressed/` jika menggunakan `--profile compressed`).
