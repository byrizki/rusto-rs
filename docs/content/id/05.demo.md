Uji deteksi dan pengenalan teks OCR secara langsung di browser Anda. Seluruh pemrosesan berjalan penuh di sisi klien menggunakan paket **`rusto-web`** dan model **PP-OCRv6 Tiny** tanpa mengirimkan data gambar ke server eksternal.

::web-ocr-demo
::

## Cara Kerja

1. **Pemrosesan Sisi Klien**: Pipeline inferensi OCR berjalan langsung di perangkat Anda menggunakan WebAssembly.
2. **Kotak Pembatas Interaktif**: Arahkan kursor ke kotak deteksi mana pun pada kanvas gambar untuk melihat teks dan tingkat kepercayaan skor. Klik kotak untuk menyalin teks.
3. **Pilihan Granularitas**: Pilih antara pengelompokan baris (`lines`), token kata individual (`words`), atau rekonstruksi tata letak spasial (`spatial`).
4. **Ekspor Data**: Salin hasil dengan cepat ke Papan Klip, format tabel CSV, atau JSON terstruktur.
