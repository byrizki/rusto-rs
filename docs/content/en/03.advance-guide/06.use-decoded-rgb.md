# OCR from Decoded RGB Pixels

High-throughput image processing callers (such as `libvips`, `imagor`, OpenCV, camera feeds, and GUI viewports) already maintain uncompressed, decoded pixel arrays in memory. Encoding these pixels as JPEG or PNG solely to invoke `rocr_detect_text_data` adds redundant codec overhead and, in the case of lossy formats like JPEG, introduces compression artifacts that degrade recognition accuracy.

RustO! provides direct, validated raw RGB input methods that bypass compression and decompression entirely while utilizing the same detection, recognition, and coordinate systems.

## Key Properties

- **Input Format**: Interleaved unsigned 8-bit **RGB** (`RGB8`), with no alpha channel and no EXIF auto-rotation.
- **Row Padding**: Supports padded row strides (`stride >= width * 3`). The buffer must contain at least `(height - 1) * stride + width * 3` readable bytes (the final row does not require trailing padding).
- **Fast-Path Memory Copy**: When `stride == width * 3` (unpadded contiguous pixels), buffers are ingested in a single vectorized memory pass.
- **Safe Memory Invariants**: The caller retains ownership of the pixel buffer. RustO copies the active pixels and never retains, modifies, or frees the caller's pointer.
- **Backend Requirement**: Requires the default pure-Rust image backend.

## C / C++ Integration

Build RustO! with `cargo build --release --features ffi`. C declarations are exported in [`include/rusto.h`](file:///mnt/development/Quadrant/rusto-rs/include/rusto.h).

### Structured Output (`rocr_detect_text_rgb`)

```c
#include "rusto.h"

/* handle is an initialized ROCRHandle*; pixels is caller-owned RGB8 buffer. */
CTextResult *results = NULL;
size_t count = 0;
int status = rocr_detect_text_rgb(
    handle,
    pixels,
    buffer_length,
    width,
    height,
    stride_bytes,
    "{}",
    &results,
    &count
);

if (status == 0) {
    for (size_t i = 0; i < count; ++i) {
        printf("Detected: %s (confidence: %.2f)\n", results[i].text, results[i].score);
    }
    rocr_free_results(results, count);
}
```

### Spatial Output (`rocr_detect_text_rgb_spatial`)

```c
#include "rusto.h"

char *spatial_json = rocr_detect_text_rgb_spatial(
    handle,
    pixels,
    buffer_length,
    width,
    height,
    stride_bytes,
    "{}"
);

if (spatial_json != NULL) {
    printf("Spatial JSON: %s\n", spatial_json);
    rocr_free_string(spatial_json);
}
```

### Return Codes

| Code | Meaning                                                                                 |
| :--- | :-------------------------------------------------------------------------------------- |
| `0`  | Success                                                                                 |
| `-1` | NULL pointer passed for a required argument                                             |
| `-2` | Invalid dimensions, insufficient stride, or short buffer length                         |
| `-3` | Engine or inference execution failure                                                   |
| `-4` | Invalid options JSON string                                                             |
| `-5` | Spatial output requested on structured API (use `rocr_detect_text_rgb_spatial` instead) |

## Native Rust API

```rust
use rusto::{DetectTextBuilderExt, InitializeConfig, RustO};

let mut ocr = RustO::initialize(InitializeConfig::default())?;

// pixels: &[u8], width: u32, height: u32, stride: usize
let result = ocr
    .detect_text_rgb_builder(pixels, width, height, stride)
    .with_layout_reading(true)
    .as_lines()
    .run()?;
```

## Language Bindings

Every SDK exposes a fluent `rgb(...)` input on the same builder used for files and encoded bytes, finished with the single `run()` terminal call.

### Node.js (`packages/node`)

```javascript
const results = engine.detectText().rgb(pixels, width, height, stride).asLines().run();
```

### Python (`packages/python`)

```python
result = engine.detect_text().rgb(pixel_bytes, width, height, stride).as_lines().run()
```

### Go (`packages/go`)

```go
res, err := engine.DetectText().RGB(pixels, width, height, stride).AsLines().Run()
if err != nil {
    log.Fatal(err)
}
```

### Java & JVM (`packages/java`)

```java
RustO.DetectTextResult res = engine.detectText().rgb(pixelBytes, width, height, stride).asLines().run();
```

### .NET (`packages/dotnet`)

```csharp
var result = ocr.DetectText().Rgb(pixelBytes, width, height, stride).AsLines().Run();
```

### Flutter & Dart (`packages/flutter`, `packages/dart`)

```dart
final result = engine.detectText().rgb(pixelBytes, width, height, stride).asLines().run();
```
