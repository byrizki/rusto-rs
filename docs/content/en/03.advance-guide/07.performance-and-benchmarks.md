All benchmarks published on this page are derived from actual, empirical measurements conducted with reproducible test suites against official baseline implementations. No speculative values or assumptions are used.

> [!NOTE]
> **Benchmark Test Environment**:
>
> - **Processor**: 11th Gen Intel(R) Core(TM) i7-1185G7 @ 3.00GHz (4 physical cores / 8 threads)
> - **Memory**: 32 GB RAM
> - **Operating System**: Linux x86_64
> - **Core Runtime**: RustO! (release profile with LTO), published `rten 0.27.0`

## 1. OmniDocBench Comprehensive Evaluation

Evaluated against the diverse real-world **OmniDocBench** dataset (created by [DataLab](https://github.com/datalab-to), covering academic papers, textbooks, newspapers, magazines, presentation slides, and examination papers) comparing native RustO (powered by published `rten 0.27.0`) against official Python PaddleOCR and RapidOCR (C++ ONNX Runtime), as well as DataLab's official Indra OCR pipeline.

### Part I: Base OCR Benchmark (Pure Detection + Recognition)

In this baseline comparison, all engines execute solely **Text Detection and Text Recognition** using standard 1D spatial reading order (top-to-bottom, left-to-right).

| **PaddleOCR + PP-OCRv6 Tiny**   | Python (Paddle)    |  120.1 MB   |    6.1 MB     |    605.3 ms    |   1,322.0 ms   |     659.3 MB     |   0.5467   |       45.33%       |   **0.7331**    |

> **Accuracy Parity**: Under identical 1D spatial sorting, all runtimes exhibit character recognition parity within **0.01%** (RustO: 45.34% vs PaddleOCR: 45.33%). Upgrading from Tiny to Small quadruples model weights (6.1 MB → 29.8 MB) and inflates latency by 3.3x with zero accuracy gain on this benchmark.

## 2. Inference Engine Runtime Head-to-Head

Evaluated on fixed-shape inputs (Detection: 640×640, Recognition: 16 crops) comparing native machine learning inference engines across execution latency, binary footprints, and runtime dependencies:

| Metric / Dimension                   |   RTen (Pure Rust `.rten`)    |    Direct ONNX (C++ ORT)    |     MNN (Native C++ FFI)     |      Tract (Pure Rust)      |
| :----------------------------------- | :---------------------------: | :-------------------------: | :--------------------------: | :-------------------------: |
| **Core Language**                    |         **Pure Rust**         |           C++ FFI           |           C++ FFI            |        **Pure Rust**        |
| **Model Serialization Format**       |    **FlatBuffers `.rten`**    |  Protocol Buffers `.onnx`   |      Proprietary `.mnn`      |  Protocol Buffers `.onnx`   |
| **Runtime Dependencies & Linker**    |  **None (100% static link)**  | Dynamic C++ shared library  | Compiled C++ shared library  | **None (100% static link)** |
| **Cold Model Load Time**             |         **17.53 ms**          |          38.80 ms           |         **5.20 ms**          |          45.10 ms           |
| **Detection Latency (640×640)**      |           51.17 ms            |          35.49 ms           |         **~24.5 ms**         |          191.04 ms          |
| **Recognition Latency (Avg / Crop)** |            3.26 ms            |           1.86 ms           |         **~0.95 ms**         |           8.19 ms           |
| **Total Recognition (16 crops)**     |           52.19 ms            |          29.78 ms           |         **~15.2 ms**         |          130.99 ms          |
| **Total Neural Inference Latency**   |         **103.36 ms**         |          65.27 ms           |         **~39.7 ms**         |          322.03 ms          |
| **Total End-to-End Pipeline**        |         **678.08 ms**         |          447.83 ms          |          479.07 ms           |          ~1,100 ms          |
| **WASM Engine Bundle (gzipped)**     |          **517 KB**           |          ~3.78 MB           |  N/A (Emscripten required)   |           1.99 MB           |
| **Cross-Platform Portability**       | **Universal (Native + Web)**  | Platform-specific binaries  |     Mobile & Desktop C++     | Pure Rust (limited op set)  |
| **Deployment Simplicity**            | **Zero-config static binary** | Path & shared library setup | Custom toolchain & build FFI |   Pure Rust static binary   |

### Key Architectural Takeaways

1. **RTen (Pure Rust Default)**:
   - Delivers the premier developer experience and cross-platform portability.
   - Eliminates all external C/C++ toolchain requirements, linking cleanly into native applications and compiling down to an ultra-compact **517 KB** WebAssembly binary for browser execution.
   - Zero-copy FlatBuffers memory mapping enables cold model initialization in just **17.53 ms**.
2. **Direct ONNX Runtime (C++ ORT)**:
   - Provides optimized CPU inference (65.27 ms total neural execution) through mature multi-threaded graph optimization.
   - Requires dynamic library distribution (`libonnxruntime.so` / `.dylib` / `.dll`), creating packaging friction across containerized environments and multi-platform app targets.
3. **Alibaba MNN**:
   - Fastest raw CPU execution (~39.7 ms inference) powered by assembly-level vector kernels.
   - Demands custom C++ build scripts, linker configurations, and proprietary model conversion.
4. **Tract**:
   - Pure Rust execution without C++ dependencies, but suffers from higher inference latency (322.03 ms) on dynamic-dimension convolutional networks.
