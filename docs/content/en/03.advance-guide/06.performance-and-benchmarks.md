## ⚡ Performance Optimizations in RustO!

### 1. Pure Rust Image Preprocessing

Traditional OCR pipelines rely on heavy OpenCV shared libraries for resizing, morphological dilation, and contour tracing. RustO! implements these algorithms directly in pure Rust with SIMD auto-vectorization, eliminating inter-library marshalling and memory allocations.

### 2. Multi-Core Rayon Parallelism

After DBNet detects bounding polygons, perspective affine cropping, rectification, and batch tensor preparation are distributed across available CPU cores via [Rayon](https://crates.io/crates/rayon):

```rust
// Internally cropped text candidate boxes are parallelized across threads:
let crop_imgs: Vec<Mat> = padded_boxes.par_iter().map(|b| {
    get_rotate_crop_image(&padded, b).unwrap()
}).collect();
```

### 3. Aggressive Release Compiler Profile

The production release profile enables Fat Link-Time Optimization (LTO), single codegen unit compilation, and aggressive dead code elimination:

```toml
[profile.release]
opt-level = 3
lto = "fat"
codegen-units = 1
strip = true
panic = "abort"
```
