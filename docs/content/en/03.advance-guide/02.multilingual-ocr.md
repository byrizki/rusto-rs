RustO! provides OCR capabilities across dozens of writing systems. Models are organized into **default flagship models (`indraocr`)**, **bilingual models (`ppocrv6`)**, and **specialized regional language packs (`indraocr`, `ppocrv5`, & `ppocrv4`)**.

---

## 1. Flagship & Bilingual Models

### Default Flagship: Indra OCR (`indraocr`)

The default **Indra OCR** pipeline (`datalab-to/indra-ocr`) is tuned for Indonesian vernacular vocabulary, regional identity documents (KTP, SIM), tax forms, receipts, and general Latin documents, while offering dedicated multi-script recognizers (`cjk`, `rtl`, `world`).

### PP-OCRv6 Bilingual Scope (Chinese + English / Latin)

| Tier                            | Dictionary Size       | Script & Character Coverage                                                                                                                                            | Best For                                                                                    |
| :------------------------------ | :-------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| **Indra OCR** _(Default)_       | `indra_meta.json`     | Indonesian vernacular, English, Latin script, numbers, punctuation, and currency symbols (`Rp`, `\$`, etc.).                                                           | Identity cards, tax forms, receipts, and high-speed Latin document OCR.                     |
| **PP-OCRv6 Tiny**               | **6,904 characters**  | Simplified Chinese, English, standard Latin alphabet (Indonesian, Spanish, French, German), numerals (`0-9`), punctuation, and currency symbols (`\$`, `€`, `¥`, `£`). | Mobile apps, receipts, invoices, and standard documents in English, Indonesian, or Chinese. |
| **PP-OCRv6 Small** & **Medium** | **18,708 characters** | All characters in Tiny plus Traditional Chinese ideographs, rare CJK characters, and Japanese Kana (Hiragana and Katakana).                                            | Scans containing mixed Chinese, Japanese Kana, and Latin text.                              |

## 3. How to Switch Language Models in Code

Provide the canonical `lang` identifier in `InitializeConfig` — RustO! automatically resolves or downloads the matching recognition model and dictionary:

### In Rust

```rust
use rusto::download::parse_config_with_auto_download;
use rusto::{DetectTextBuilderExt, ImageSource, RustO};

rusto::init();
let config = parse_config_with_auto_download(r#"{
    "model": "ppocrv4",
    "lang": "japan"
}"#)?;

let mut ocr = RustO::initialize(config)?;
let result = ocr
    .detect_text_builder(ImageSource::Path("japanese_receipt.jpg".into()))
    .as_lines()
    .run()?;
```

### In Node.js

```typescript
import { RustO } from '@rustors/node';

const ocr = RustO.initialize({
  model: 'ppocrv5',
  lang: 'arabic',
});

const lines = ocr.detectText('arabic_invoice.png').asLines().run();
ocr.close();
```

### In Python

```python
from rusto import RustO, create_initialize_config_for_model

config = create_initialize_config_for_model(model="ppocrv5", lang="korean")
with RustO.initialize(config) as engine:
    result = engine.detect_text("korean_document.png").as_lines().run()
    if result.is_STRUCTURED():
        for item in result.results:
            print(item.text)
```

## 4. Pre-Downloading Language Packs with `rusto download`

Pre-cache language models for offline use with the CLI:

```bash
rusto download --model indraocr --lang cjk
rusto download --model indraocr --lang rtl
rusto download --model ppocrv5 --lang arabic
rusto download --model ppocrv4 --lang japan
```

## 5. Right-to-Left (RTL) Scripts

When processing **Arabic, Persian, or Urdu** (`--lang rtl` or `--lang arabic`):

- Bounding polygon vertices in structured output (`as_lines` / `asLines`) preserve true 2D document coordinates.
- In spatial text mode (`as_spatial` / `asSpatial`), lines preserve row clustering and horizontal token spacing.
