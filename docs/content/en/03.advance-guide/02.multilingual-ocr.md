RustO! delivers state-of-the-art multilingual OCR capabilities supporting diverse alphabets, scripts, and typography across 50+ languages.

## 1. PP-OCRv6 Unified 50-Language Model (Recommended)

PP-OCRv6 introduces a single unified multi-script recognition network (`rec.mnn` + `ppocrv6_dict.txt`). It recognizes multiple scripts simultaneously in mixed-language documents without switching models or dictionaries:

| Script Family        | Languages Included                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Latin**            | English, Indonesian, Spanish, French, German, Portuguese, Italian, Vietnamese, Turkish, Polish, Dutch, etc. |
| **Cyrillic**         | Russian, Ukrainian, Belarusian, Bulgarian, Serbian, Macedonian, Kazakh, etc.                                |
| **CJK**              | Simplified Chinese, Traditional Chinese, Japanese (Kanji/Hiragana/Katakana), Korean (Hangul).               |
| **Devanagari**       | Hindi, Marathi, Sanskrit, Nepali, Bhojpuri, etc.                                                            |
| **Arabic / Persian** | Arabic, Persian (Farsi), Urdu, Uyghur, Pashto.                                                              |
| **Southeast Asian**  | Thai, Lao, Khmer, Burmese.                                                                                  |
| **Others**           | Greek, Hebrew, Georgian, Armenian.                                                                          |

## 3. Loading Language Models in Code

### In Rust:

```rust
use rusto::{InitializeConfig, RustO};

// Load Japanese language recognition model
let config = InitializeConfig::ppv4(
    "models/det.mnn",
    "models/japan_rec.mnn",
    "models/japan_dict.txt",
);

let mut ocr = RustO::initialize(config)?;
```

### In .NET / C#:

```csharp
using RustODotnet;

var config = new InitializeConfig
{
    Template = "ppv5",
    Recognition = new RecognitionConfig
    {
        ModelPath = "models/arabic_rec.mnn",
        DictPath = "models/arabic_dict.txt"
    }
};

using var ocr = RustO.Initialize(config);
```
