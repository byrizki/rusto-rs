RustO! separates its core runtime engine from model weights so your production binaries stay under 10 MB and never bundle bloated static payloads.

If you are unsure which model to pick: **start with `ppocrv6-tiny` (default, FP32, Apache 2.0)**. At ~5.9–6.1 MB, it achieves **46.53%** baseline OmniDocBench accuracy (**62.72%** with pure-Rust heuristic reading order, **57.91%** with CDLA full pipeline) across 50+ scripts under a permissive Apache 2.0 license. For tighter FP16 or INT8 storage budgets, choose **`ppocrv6-tiny-fp16`** (~3.1 MB on `rusto-nn` / `rusto-webgpu`) or **`ppocrv6-tiny-int8`** (~3.3–3.4 MB). DataLab **`indraocr`** (~5.4 MB) is also available as an opt-in preset with **45.70%** base / **63.90%** full-pipeline accuracy (note: Indra model weights use a modified OpenRAIL-M license).

## 2. Decoupled Pipeline Architecture

RustO! decouples the **Base OCR Pipeline** from **Optional Auxiliary Stages**:

```mermaid
flowchart TD
    subgraph BASE["Base OCR Pipeline (Pluggable Core)"]
        DET["Text Detection<br/>(indra_det.mnn / det.mnn)"] --> REC["Text Recognition<br/>(indra_rec.mnn + indra_meta.json / dict.txt)"]
    end

    subgraph EXTRAS["Optional Pluggable Stages (Independent Assets)"]
        UNWARP["1. Document Unwarp<br/>(uvdoc.mnn / uvdoc.rten)"]
        ORIENT["2. Page Orientation<br/>(indra_orient.mnn / ppocr_orient.mnn)"]
        LAYOUT["3. Layout Analysis<br/>(layout_cdla.mnn / layout_publaynet.mnn)"]
        CLS["4. Line Angle Classifier<br/>(ppocr_cls.mnn / ppocr_cls.rten)"]
        ORDER["5. Neural Reading Order<br/>(indra_order.mnn / indra_order.rten)"]
    end

    UNWARP -.-> BASE
    ORIENT -.-> BASE
    LAYOUT -.-> BASE
    BASE -.-> CLS
    BASE -.-> ORDER
```

### Pluggable Model Assets:

- **Decoupled base weights**: Base pipelines (`det` + `rec` + `dict`/`meta.json`) and optional stages (`cls`, `orient`, `unwarp`, `layout`, `reading-order`) are delivered as independent `.mnn` or `.rten` files.
- **Layout & Neural Reading Order Models**:
  - **`layout_cdla.mnn` / `layout_cdla.rten`** (5.8 MB): 10-class document layout segmentation (`Text`, `Title`, `Figure`, `FigureCaption`, `Table`, `TableCaption`, `Header`, `Footer`, `Reference`, `Equation`).
  - **`layout_publaynet.mnn` / `layout_publaynet.rten`** (5.2 MB): 5-class document layout segmentation (`Text`, `Title`, `List`, `Table`, `Figure`).
  - **`indra_order.mnn` / `indra_order.rten`** (2.9 MB): DataLab Indra Neural Reading Order & Layout Transformer. Sequences multi-column text lines into natural human reading order.
- **Neural Reading Order Recovery**: Enabled via `--reading-order` on the CLI or `enableReadingOrder: true` in `InitializeConfig`.

## 3. Model Resolution Flow

RustO! follows a deterministic 3-tier lookup flow across all SDKs and the `rusto` CLI:

```mermaid
flowchart LR
    A["1. User Specified Path<br/>(--model-path / modelPath / overrides)"] -->|Found| RUN["Run Inference"]
    A -->|Not Found| B["2. Local Cache Directory<br/>(~/.cache/rusto/models)"]
    B -->|Found| RUN
    B -->|Not Found| C["3. Auto-Download<br/>(Hugging Face Hub)"]
    C -->|Download & Cache| RUN
```

1. **User Specified Path**: If `--model-path` / `modelPath` or explicit component paths (`--det-model`, `--rec-model`, `--dict`) are passed, RustO! checks that location first.
2. **Cache Directory**: If omitted, RustO! checks the cache directory (`~/.cache/rusto/models`, `RUSTO_CACHE_DIR`, or custom `--cache-dir` / `cacheDir`).
3. **Auto-Download**: If missing from the cache, RustO! downloads the standalone model and vocabulary files from Hugging Face Hub (`https://huggingface.co/byrizki/rusto-models`) and atomically caches them.

## 4. Downloading Models

### Using the CLI (`rusto download`)

Download model assets ahead of time for offline or containerized deployments:

```bash
# Download default model (ppocrv6-tiny) to cache
rusto download

# Download default model with auxiliary unwarp, orientation, layout, and reading-order stages
rusto download --orient --unwarp --layout --reading-order

# Download another canonical model (e.g., DataLab Indra OCR or PP-OCRv6 Small)
rusto download --model indraocr
rusto download --model ppocrv6-small

# Download a regional language pack
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang japan

# Download all canonical models ahead of time
rusto download --all

# Specify a custom cache directory
rusto download --model ppocrv6-tiny --cache-dir /opt/models/cache
```

### Programmatic Download Across SDKs

```typescript
// TypeScript / Node.js & Web
import { RustO, downloadModel, isReady, version } from '@rustors/node';

const paths = RustO.downloadModel('ppocrv6-tiny', 'latin');
console.log(`RustO v${version()} ready: ${isReady()}`);
```

```python
# Python
from rusto import RustO, download_model, is_ready, version

paths = download_model(model="ppocrv6-tiny", lang="latin")
print(f"RustO v{version()} ready: {is_ready()}")
```

```csharp
// C# (.NET)
using RustODotnet;

string[] paths = RustO.DownloadModel("ppocrv6-tiny", "latin");
```

## 6. Checksum Verification

Every release includes a `SHA256SUMS` file. Verify your downloaded assets:

```bash
sha256sum -c SHA256SUMS --ignore-missing
```
