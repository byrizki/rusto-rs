When integrating RustO! into your application or service, one of your primary architectural decisions is **which model tier to use** and **how to deliver the weights** to your users.

RustO! decouples the lightweight core runtime library from the model weights. This guide walks you through selecting the right model for your application's constraints and choosing the most convenient delivery method.

---

## 1. Quick Decision Guide: Which Model Should I Choose?

| Your Target Environment / Use Case | Recommended Model | Archive Size | Inference Speed (CPU) | Why This Is the Best Choice |
| :--- | :--- | :--- | :--- | :--- |
| **Mobile Apps (iOS / Android / RN / Flutter)** | **PP-OCRv6 Tiny (FP32)** *(Recommended Default)* | **~6.0 MB** | ⚡ 30–60 ms | Outstanding accuracy with minimal battery/CPU impact and instant cold start. |
| **Ultra-Low Memory / Embedded (IoT, Low RAM)** | **PP-OCRv6 Tiny (INT8)** | **~2.8 MB** | ⚡ 20–40 ms | 50% smaller package size, 8-bit integer quantized with <0.5% character accuracy variance. |
| **Desktop Apps & Edge Micro-Servers** | **PP-OCRv6 Small (FP32)** | **~30 MB** | ⏱️ 80–150 ms | Enhanced backbone with higher recall on small fonts, dense receipts, and rotated text. |
| **Cloud Servers & Bulk Document Archiving** | **PP-OCRv6 Medium (FP32)** | **~134 MB** | ⏱️ 200–450 ms | Maximum precision on complex forms, multi-column reports, and noisy document scans. |
| **Japanese / Traditional Chinese** | **PP-OCRv4 Japanese / TradChinese** | **~25 MB** | ⏱️ 60–120 ms | Includes specialized character dictionaries for Kanji, Kana, and traditional glyphs. |
| **Multilingual (Arabic, Cyrillic, Korean, etc.)** | **PP-OCRv5 Language Packs** | **~28 MB** | ⏱️ 60–110 ms | Dedicated regional alphabet dictionaries and recognition models. |

### Approach B: Native Package Managers (Zero Manual Download)

If building for iOS, Android, or .NET, you can avoid downloading files manually by referencing pre-packaged model bundles directly in your build manifests:

#### 1. iOS (CocoaPods)
In your `Podfile`:
```ruby
pod 'RustO-Models-PPOCRv6-Tiny', '~> 0.2.4'
```
The framework automatically locates the models inside the pod bundle when calling `try RustO.initialize()`.

#### 2. Android (Gradle)
In `android/app/build.gradle`:
```groovy
dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-models-ppocrv6-tiny:v0.2.4'
}
```
Models are embedded into the app's AAR assets and auto-extracted upon first engine start.

#### 3. .NET (NuGet)
```bash
dotnet add package RustODotnet.Models.PPOCRv6.Tiny
```
MSBuild automatically copies the `.rten` and `dict.txt` assets into your app's build output folder.

### Approach C: CLI Downloader Script (Development & CI)

Use the built-in downloader script in development workflows and automated CI pipelines:

```bash
# 1. Download recommended default PP-OCRv6 Tiny FP32 models
bash scripts/download_models.sh --model ppocrv6 --tier tiny --output-dir models/PPOCR_v6_tiny

# 2. Download quantized PP-OCRv6 Tiny INT8 models (~2.8 MB)
bash scripts/download_models.sh --model ppocrv6 --tier tiny --int8 --output-dir models/PPOCR_v6_tiny_int8

# 3. Download PP-OCRv6 Small models
bash scripts/download_models.sh --model ppocrv6 --tier small --output-dir models/PPOCR_v6_small

# 4. Download Japanese language pack
bash scripts/download_models.sh --model ppocrv4 --tier mobile --lang japan --output-dir models/PPOCR_v4_japan
```

## 4. Model Format Differences: `.rten` vs `.onnx` vs `_int8`

- **`.rten` (Recommended Default)**:
  - Designed specifically for pure-Rust [RTen](https://github.com/robertknight/rten).
  - Enables zero-copy memory mapping (`mmap`), meaning the OS can share read-only model memory pages without allocating heap.
  - Requires zero C/C++ runtimes or ONNX libraries.
  - SIMD accelerated on modern CPUs (AVX2, AVX-512, and ARM NEON).
- **`.onnx`**:
  - Useful if you integrate with ONNX Runtime (`ort`) or WebAssembly in browsers.
- **`_int8.rten` (Quantized)**:
  - Weights converted to 8-bit integers.
  - Reduces file size and RAM footprint by ~50–60%.
  - Up to 2x faster memory throughput on mobile memory buses with <0.5% character accuracy variance.

## 5. Verifying Model Archive Integrity

Every release includes a `SHA256SUMS` manifest. To verify your downloaded model archive:

```bash
# On Linux / macOS
sha256sum -c SHA256SUMS --ignore-missing

# Or verify single archive:
sha256sum RustO-Models-PPOCRv6-Tiny.zip
```
