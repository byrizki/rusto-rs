## How It Works

1. **Client-Side WASM Processing**: The OCR inference pipeline executes directly inside your browser Web Worker using WebAssembly (`@rustors/web`) with zero server uploads.
2. **Interactive Bounding Boxes**: Hover over any detected bounding polygon on the image canvas to inspect the recognized text, layout category, and confidence score. Click any box to copy its text.
3. **Flexible Output Modes**: Switch between line-level grouping (`asLines`), word-level tokens (`asWords`), and 2D spatial layout reconstruction (`asSpatial`).
4. **Instant Export**: Export recognition results to your Clipboard, CSV, or structured JSON.
