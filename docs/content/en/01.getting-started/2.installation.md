RustO! is packaged modularly across multiple language package managers and registries. Choose your target environment below.

## 1. Rust (`Cargo.toml`)

Add `rusto-rs` via `cargo`:

```bash
cargo add rusto-rs
```

Or add it directly to your `Cargo.toml`:

```toml
[dependencies]
rusto-rs = "0.3.1"
```

### Optional Cargo Features

| Feature      | Description                                                                          |
| ------------ | ------------------------------------------------------------------------------------ |
| `ffi`        | Enables C FFI and JNI bindings for embedding RustO! into foreign runtimes.           |
| `use-opencv` | Enables optional OpenCV backend for comparison testing and visual parity validation. |
| `metal`      | Enables Apple Metal GPU acceleration on macOS and iOS.                               |
| `coreml`     | Enables Apple CoreML neural engine backend on Apple Silicon.                         |
| `vulkan`     | Enables Vulkan compute shader acceleration for modern GPUs on Linux/Windows/Android. |
| `opencl`     | Enables OpenCL acceleration on supported GPUs.                                       |
| `cuda`       | Enables NVIDIA CUDA acceleration on Linux/Windows.                                   |
| `nnapi`      | Enables Android Neural Networks API acceleration on compatible mobile chipsets.      |

## 2. Node.js (npm / yarn / pnpm)

Install `@rustors/node` via your preferred package manager:

```bash
npm install @rustors/node
# or yarn add @rustors/node
# or pnpm add @rustors/node
```

Pre-built native N-API binaries are automatically resolved for Linux (x64/arm64), macOS (Apple Silicon & Intel), and Windows (x64).

---

## 3. Python (pip / PyPI)

Install the pre-built wheel from PyPI:

```bash
pip install rusto
```

Supports Python 3.9+ across Linux, macOS, and Windows.

---

## 4. Golang (Cgo)

Fetch the Go package:

```bash
go get github.com/byrizki/rusto-rs/packages/go
```

> **Note**: Building requires `librusto` shared library. Set `CGO_LDFLAGS="-L/path/to/lib -Wl,-rpath,/path/to/lib"` or place `librusto.so` / `librusto.dylib` in your system library path.

---

## 5. Java / JVM (JitPack / Gradle / Maven)

Add `rusto-java` from JitPack using Gradle:

```groovy
repositories {
    mavenCentral()
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-java:0.3.1'
}
```

Or Maven:

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.byrizki.rusto-rs</groupId>
    <artifactId>rusto-java</artifactId>
    <version>0.3.1</version>
</dependency>
```

## 7. .NET / C# (NuGet)

Install the core package from NuGet:

```bash
dotnet add package RustODotnet
```

### Pre-Packaged Model Bundles

To include lightweight pre-packaged models without manually managing model assets on disk, add one of the official model packages:

```bash
# Recommended default PP-OCRv6 Tiny models (~6 MB total)
dotnet add package RustODotnet.Models.PPOCRv6.Tiny

# Or specialized language/tier model packages:
dotnet add package RustODotnet.Models.PPOCRv6.Small
dotnet add package RustODotnet.Models.PPOCRv5.Latin
dotnet add package RustODotnet.Models.PPOCRv4.Japanese
```

## 8. React Native (npm / yarn / pnpm)

Install the React Native npm package:

```bash
npm install @rustors/react-native
```

### iOS Setup (`ios/Podfile`)

Add your preferred OCR model pod inside your app target in `ios/Podfile`:

```ruby
target 'YourApp' do
  pod 'RustO-Models-PPOCRv6-Tiny' # ~6 MB (Recommended)
end
```

Then install the CocoaPods dependencies:

```bash
cd ios && pod install
```

### Android Setup (`android/app/build.gradle`)

In your root `settings.gradle`, verify that JitPack is included:

```groovy
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}
```

In `android/app/build.gradle`, add the model bundle:

```groovy
dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-models-ppocrv6-tiny:0.3.2'
}
```

## 9. iOS (Swift / CocoaPods & SPM)

### Swift Package Manager (SPM)

In Xcode, select **File > Add Package Dependencies...** and enter:

```text
https://github.com/byrizki/rusto-rs.git
```

Or in your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/byrizki/rusto-rs.git", from: "0.3.1")
]
```

### CocoaPods

In your project's `Podfile`:

```ruby
target 'YourApp' do
  use_frameworks!

  pod 'RustO'
  pod 'RustO-Models-PPOCRv6-Tiny'
end
```

Run `pod install`.

## 10. Android (Kotlin / Gradle)

Ensure JitPack repository is registered in your root `settings.gradle`:

```groovy
repositories {
    maven { url 'https://jitpack.io' }
}
```

Add the core library and model package in your app's `build.gradle`:

```groovy
dependencies {
    implementation 'com.github.byrizki.rusto-rs:rusto-android:0.3.1'
    implementation 'com.github.byrizki.rusto-rs:rusto-models-ppocrv6-tiny:0.3.2'
}
```

## 12. C / Native Shared Libraries & Headers

Pre-compiled dynamic shared libraries and headers are published with every [GitHub Release](https://github.com/byrizki/rusto-rs/releases):

- **Linux**: `librusto.so` (`x86_64`, `aarch64`)
- **macOS**: `librusto.dylib` (Universal `arm64` + `x86_64`)
- **Windows**: `rusto.dll`, `rusto.lib` (`x64`, `arm64`)
- **C Header**: `rusto.h`

To compile from source with FFI enabled:

```bash
cargo build --release --features ffi
```

The output dynamic and static libraries will be located in `target/release/`.
