`OcrRunOptions` (and the unified `DetectTextBuilder` fluent API) configures runtime parameters for an individual OCR execution. In v0.4.0, runtime options are organized around **4 pipeline toggles** and **6 discrete processing phases**.

Every option can be supplied via a configuration object or chained seamlessly with builder methods ending in `.run()`.

```mermaid
flowchart TD
    A["Raw Image Source"] --> U{"autoUnwarp?<br/>(withAutoUnwarp)"}
    U -->|true| U1["Flatten 3D Page Curvature (UVDoc)"]
    U -->|false| L{"layoutReading?<br/>(withLayoutReading)"}
    U1 --> L
    L -->|true| L1["Segment Layout &amp; Reading Flow"]
    L -->|false| O{"orientationDetection?<br/>(withOrientationDetection)"}
    L1 --> O
    O -->|true| O1["Rotate Canvas Upright 0&deg;/90&deg;/180&deg;/270&deg;"]
    O -->|false| P1["Phase 1: Pre-Detection<br/>(targetMaxSide, descreen)"]
    O1 --> P1
    P1 --> P2["Phase 2: Detection<br/>(limitSideLen, limitType, norm)"]
    P2 --> P3["Phase 3: Post-Detection<br/>(threshold, boxThreshold, unclipRatio)"]
    P3 --> C{"lineClassification?<br/>(withLineClassification)"}
    C -->|true| C1["Flip Inverted Lines 180&deg;"]
    C -->|false| P4["Phase 4: Pre-Recognition<br/>(lineYThreshold, wordXThreshold)"]
    C1 --> P4
    P4 --> P5["Phase 5: Recognition<br/>(batchSize, workers, maxWorkers)"]
    P5 --> P6["Phase 6: Post-Recognition<br/>(scoreThreshold)"]
    P6 --> OUT[".run() &rarr; DetectTextResult<br/>(lines / words / spatial / blocks)"]
```

## Parameters Specification

### 1. Pipeline Toggles

| Toggle Method                     | Wire Property          | Type      | Default | Description                                                                               |
| --------------------------------- | ---------------------- | --------- | ------- | ----------------------------------------------------------------------------------------- |
| `.withAutoUnwarp(bool)`           | `autoUnwarp`           | `boolean` | `false` | Flattens 3D document curvature, folds, and book spine distortion via UVDoc.               |
| `.withLayoutReading(bool)`        | `layoutReading`        | `boolean` | `false` | Evaluates document layout and restores natural multi-column reading flow via transformer. |
| `.withOrientationDetection(bool)` | `orientationDetection` | `boolean` | `false` | Classifies whole-page rotation and rotates canvas upright (0°, 90°, 180°, 270°).          |
| `.withLineClassification(bool)`   | `lineClassification`   | `boolean` | `false` | Evaluates 180° inverted line classifier and flips upside-down text blocks.                |

---

### 2. Six Processing Phases

#### Phase 1: Pre-Detection (`preDetection`)

Configures image conditioning and pre-inference scaling.

| Option             | Type      | Default | Description                                                                                  |
| ------------------ | --------- | ------- | -------------------------------------------------------------------------------------------- |
| `targetMaxSide`    | `integer` | `null`  | Pre-scales image before passing to detector to prevent memory spikes on large camera photos. |
| `descreenStrength` | `float`   | `null`  | Applies halftone descreening filter for scanned printed media.                               |
| `cropPaddingX`     | `float`   | `null`  | Horizontal margin padding in pixels for cropped regions.                                     |
| `cropPaddingY`     | `float`   | `null`  | Vertical margin padding in pixels for cropped regions.                                       |

#### Phase 2: Detection (`detection`)

Configures DBNet neural detector input dimensions and normalization.

| Option         | Type       | Default                 | Description                                                                    |
| -------------- | ---------- | ----------------------- | ------------------------------------------------------------------------------ |
| `limitSideLen` | `integer`  | `960`                   | Detector input dimension limit.                                                |
| `limitType`    | `string`   | `"max"`                 | `"max"` caps the longest side; `"min"` scales the shortest side to the target. |
| `mean`         | `float[3]` | `[0.485, 0.456, 0.406]` | Image channel RGB normalization mean.                                          |
| `std`          | `float[3]` | `[0.229, 0.224, 0.225]` | Image channel RGB normalization standard deviation.                            |

#### Phase 3: Post-Detection (`postDetection`)

Configures polygon extraction, thresholding, and morphological filtering.

| Option             | Type      | Default  | Description                                                         |
| ------------------ | --------- | -------- | ------------------------------------------------------------------- |
| `threshold`        | `float`   | `0.3`    | Pixel probability binarization cutoff.                              |
| `boxThreshold`     | `float`   | `0.6`    | Polygon average confidence cutoff score.                            |
| `unclipRatio`      | `float`   | `2.0`    | Polygon expansion multiplier to encompass ascenders and descenders. |
| `useDilation`      | `boolean` | `true`   | Morphological dilation to repair faint or broken character strokes. |
| `scoreMode`        | `string`  | `"fast"` | Box scoring mode (`"fast"` or `"slow"`).                            |
| `maxCandidates`    | `integer` | `1000`   | Maximum candidate polygon contours retained.                        |
| `minHeight`        | `float`   | `32.0`   | Minimum bounding box height.                                        |
| `minSideLen`       | `float`   | `64.0`   | Minimum bounding box side length.                                   |
| `maxSideLen`       | `float`   | `1600.0` | Maximum bounding box side length.                                   |
| `widthHeightRatio` | `float`   | `-1.0`   | Recognition padding aspect ratio (`-1` preserves natural ratio).    |

#### Phase 4: Pre-Recognition (`preRecognition`)

Controls spatial clustering tolerances prior to text recognition.

| Option           | Type    | Default | Description                                                                      |
| ---------------- | ------- | ------- | -------------------------------------------------------------------------------- |
| `lineYThreshold` | `float` | `0.5`   | Vertical tolerance multiplier for clustering detected boxes into distinct lines. |
| `wordXThreshold` | `float` | `0.4`   | Horizontal tolerance multiplier for separating words and columns.                |

#### Phase 5: Recognition (`recognition`)

Controls text recognition inference and worker-thread parallelism.

| Option       | Type              | Default | Description                                                                                                  |
| ------------ | ----------------- | ------- | ------------------------------------------------------------------------------------------------------------ |
| `batchSize`  | `integer`         | `8`     | Number of text line crops passed concurrently to the recognition model.                                      |
| `workers`    | `integer \| null` | `null`  | Explicit number of parallel recognition worker threads for this run (`null` uses engine `rec_workers`).      |
| `maxWorkers` | `integer \| null` | `null`  | Maximum worker-thread clamp (`>= 1`) when auto-scaling (`null` falls back to engine `max_rec_workers`, `8`). |

#### Phase 6: Post-Recognition (`postRecognition`)

Applies confidence filtering to recognized strings.

| Option           | Type    | Default | Description                                                                |
| ---------------- | ------- | ------- | -------------------------------------------------------------------------- |
| `scoreThreshold` | `float` | `0.5`   | Minimum recognition confidence cutoff; low-confidence lines are discarded. |

---

### 3. Output Granularity

| Method                                            | Value       | Return Shape    | Description                                                           |
| ------------------------------------------------- | ----------- | --------------- | --------------------------------------------------------------------- |
| `.as_lines()` / `.asLines()` / `.AsLines()`       | `"lines"`   | Structured list | Detected lines with bounding boxes, quad coordinates, and confidence. |
| `.as_words()` / `.asWords()` / `.AsWords()`       | `"words"`   | Structured list | Clustered words with individual character bounding boxes.             |
| `.as_spatial()` / `.asSpatial()` / `.AsSpatial()` | `"spatial"` | Plain string    | 2D visual layout reconstructed with whitespace and aligned columns.   |

> [!TIP]
> In Rust, call `.run_blocks()` on `DetectTextBuilder` (or `.to_blocks()` on `DetectTextResult`) to group lines into hierarchical `BlockResult` layout sections, and use `.with_rec_workers(n)` / `.with_max_rec_workers(n)` to override recognition parallelism per image.

## Multi-Language Fluent Builder Examples

### Rust

```rust
use rusto::{DetectTextBuilderExt, ImageSource, InitializeConfig, RustO};

let mut ocr = RustO::initialize(InitializeConfig::indra("det.rten", "rec.rten", "dict.txt"))?;

let result = ocr.detect_text_builder(ImageSource::Path("document.jpg".into()))
    .with_auto_unwarp(true)
    .with_layout_reading(true)
    .with_post_detection(PostDetectionOptions {
        use_dilation: Some(true),
        unclip_ratio: Some(2.0),
        ..Default::default()
    })
    .asLines()
    .run()?;
```

### .NET / C#

```csharp
using RustODotnet;

using var ocr = RustO.Initialize(InitializeConfig.Indra());

var result = ocr.DetectText("document.jpg")
    .WithAutoUnwarp()
    .WithLayoutReading()
    .WithPostDetection(p => { p.UseDilation = true; p.UnclipRatio = 2.0f; })
    .AsLines()
    .Run();
```

### Swift (iOS)

```swift
import RustO

let ocr = try RustO.initialize(config: .indra())

let result = try ocr.detectText(image: "document.jpg")
    .withAutoUnwarp()
    .withLayoutReading()
    .withPostDetection { $0.useDilation = true; $0.unclipRatio = 2.0 }
    .asLines()
    .run()
```

}
