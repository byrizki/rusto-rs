The `RustODotnet` NuGet package provides idiomatic C# bindings and native runtimes for Windows (`x64`, `arm64`), Linux (`x64`, `arm64`), and macOS (`x64`, `arm64`).

## Installation

Install the package from NuGet:

```bash
dotnet add package RustODotnet
```

Model weights are downloaded automatically to your local cache on first run when calling `RustO.Initialize()`, or can be pre-fetched via `RustO.DownloadModel("indraocr")` or the `rusto download` CLI command.

---

## 1. Engine Lifecycle & Initialization

`RustO` manages native handles through `IDisposable`. Always use `using` declarations or call `Close()` / `Dispose()` when finished:

```csharp
using System;
using RustODotnet;

// 1. Zero-config initialization (auto-downloads Indra OCR when local files are absent)
using var ocr = RustO.Initialize();

// 2. Initialize with Indra OCR preset or a canonical model identifier
using var indraOcr = RustO.Initialize(InitializeConfig.Indra());
using var ppv6Tiny = RustO.Initialize(InitializeConfig.ForModel("ppocrv6-tiny"));

// 3. Configure custom local model paths explicitly
var customConfig = new InitializeConfig
{
    Template = "ppv6",
    Detection = new DetectionConfig { ModelPath = "models/det.rten", LimitSideLen = 736 },
    Recognition = new RecognitionConfig
    {
        ModelPath = "models/rec.rten",
        DictPath = "models/dict.txt"
    }
};

using var customOcr = RustO.Initialize(customConfig);
```

## 2. Request-Local Options & Fluent Builder

Configure per-request pipeline toggles, phase options, and output granularity (`.AsLines()`, `.AsWords()`, `.AsSpatial()`) before calling `.Run()`:

```csharp
var result = ocr.DetectText("invoices/sample.jpg")
    .WithAutoUnwarp()
    .WithLayoutReading()
    .WithPostDetection(p =>
    {
        p.UseDilation = true;
        p.UnclipRatio = 2.0f;
        p.Threshold = 0.3f;
        p.BoxThreshold = 0.6f;
    })
    .WithPreRecognition(p =>
    {
        p.LineYThreshold = 0.5f;
        p.WordXThreshold = 0.4f;
    })
    .WithPostRecognition(p =>
    {
        p.ScoreThreshold = 0.6f;
    })
    .AsLines()
    .Run();
```

## 3. Supported Image Sources

`DetectText` accepts filesystem paths, encoded in-memory `byte[]` arrays, `ImageSource` wrappers, or decoded RGB8 buffers via `.Rgb(...)`:

```csharp
using System.IO;
using RustODotnet;

// 1. Filesystem path or file:// URI
var r1 = ocr.DetectText("invoices/sample.jpg").AsLines().Run();

// 2. Encoded image bytes (e.g. from MemoryStream or ASP.NET Core IFormFile)
byte[] imageBytes = await File.ReadAllBytesAsync("invoices/sample.jpg");
var r2 = ocr.DetectText(imageBytes).AsLines().Run();

// 3. Decoded interleaved RGB8 pixel buffer
var r3 = ocr.DetectText()
    .Rgb(rgbBytes, width, height, stride: width * 3)
    .AsLines()
    .Run();
```

## 4. Practical Recipes & Output Examples

### Recipe A: Structured Line Detection with Bounding Frames

```csharp
using System;
using RustODotnet;

using var ocr = RustO.Initialize();
var result = ocr.DetectText("receipt.jpg")
    .AsLines()
    .Run();

if (result is StructuredDetectTextResult structured)
{
    Console.WriteLine($"Found {structured.Items.Count} lines:\n");
    foreach (var item in structured.Items)
    {
        Console.WriteLine($"[{item.Frame.Left:F0}, {item.Frame.Top:F0}, {item.Frame.Width:F0}x{item.Frame.Height:F0}]");
        Console.WriteLine($"  Text:  {item.Text}");
        Console.WriteLine($"  Score: {item.Score:P1}");
    }
}
```

#### Example Output:

```text

  Score: 99.1%

```

### Recipe B: Extracting Document Tables into Spatial Layout

```csharp
using System;
using RustODotnet;

using var ocr = RustO.Initialize();

var spatialResult = ocr.DetectText("invoice_table.png")
    .WithPreRecognition(p =>
    {
        p.LineYThreshold = 0.5f;
        p.WordXThreshold = 0.4f;
    })
    .AsSpatial()
    .Run();

if (spatialResult is SpatialDetectTextResult spatial)
{
    Console.WriteLine("--- Reconstructed Spatial Text ---");
    Console.WriteLine(spatial.Text);
}
```

### Recipe C: ASP.NET Core Web API Controller Example

```csharp
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Mvc;
using RustODotnet;
using System.IO;
using System.Threading.Tasks;

[ApiController]
[Route("api/[controller]")]
public class OcrController : ControllerBase
{
    private readonly RustO _ocr;

    public OcrController()
    {
        _ocr = RustO.Initialize();
    }

    [HttpPost("scan")]
    public async Task<IActionResult> ScanDocument(IFormFile file)
    {
        if (file == null || file.Length == 0)
            return BadRequest("No image uploaded.");

        using var memoryStream = new MemoryStream();
        await file.CopyToAsync(memoryStream);

        var result = _ocr.DetectText(memoryStream.ToArray())
            .WithAutoUnwarp()
            .AsSpatial()
            .Run();

        if (result is SpatialDetectTextResult spatial)
        {
            return Ok(new { text = spatial.Text });
        }

        return StatusCode(500, "OCR processing failed.");
    }
}
```
