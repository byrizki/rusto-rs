RustO! provides pure Dart FFI bindings (`package:rusto/rusto.dart`) and a native Flutter FFI plugin (`package:rusto_flutter/rusto_flutter.dart`, which directly re-exports the `rusto` API while bundling Android and iOS native libraries).

## Installation

### For Flutter Projects

```bash
flutter pub add rusto_flutter
```

### For Pure Dart / Server Projects

```bash
dart pub add rusto
```

---

## 1. Engine Initialization & Cleanup

Call `RustO.initialize()` with zero arguments to automatically download and cache the default **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) models on first run, or pass an explicit JSON configuration string. Always call `engine.close()` when finished to release native memory:

```dart
import 'package:rusto/rusto.dart';
// In Flutter apps: import 'package:rusto_flutter/rusto_flutter.dart';

// Option A: Zero-config initialization (auto-downloads ppocrv6-tiny on first run)
final engine = RustO.initialize();

// Option B: Explicit JSON configuration (e.g. extracted Flutter rootBundle paths)
final customEngine = RustO.initialize('''
{
  "template": "indra",
  "detection": { "modelPath": "/path/to/indra_det.rten" },
  "recognition": {
    "modelPath": "/path/to/indra_rec.rten",
    "dictPath": "/path/to/indra_meta.json"
  }
}
''');
```

## 2. Text Recognition via Fluent Builder

Chain pipeline toggles, 6-phase options, and output granularity (`.asLines()`, `.asWords()`, `.asSpatial()`) ending in `.run()`, which returns a sealed `DetectTextResult` (`DetectTextResultStructured` or `DetectTextResultSpatial`):

### Structured Recognition (`.asLines().run()`)

```dart
final result = engine
    .detectText('receipt.jpg')
    .withAutoUnwarp()
    .withLayoutReading()
    .withPostRecognition(scoreThreshold: 0.5)
    .asLines()
    .run();

if (result is DetectTextResultStructured) {
  for (final line in result.results) {
    print('[${line.score.toStringAsFixed(2)}] ${line.text}');
    print(
      '  Frame: left=${line.frame.left}, top=${line.frame.top}, '
      'w=${line.frame.width}, h=${line.frame.height}',
    );
  }
}

engine.close();
```

### From `Uint8List` Bytes or Decoded RGB8 Pixels

```dart
import 'dart:io';
import 'dart:typed_data';

// 1. Encoded PNG/JPEG bytes
final Uint8List bytes = File('document.png').readAsBytesSync();
final res = engine.detectText(bytes).asLines().run();

// 2. Decoded interleaved RGB8 pixel buffer
final rgbRes = engine
    .detectText()
    .rgb(rgbPixels, width, height, stride: width * 3)
    .asLines()
    .run();
```

## 3. Spatial Layout Reconstruction (`.asSpatial().run()`)

```dart
final spatialResult = engine
    .detectText('invoice.png')
    .withPreRecognition(lineYThreshold: 0.5, wordXThreshold: 0.4)
    .asSpatial()
    .run();

if (spatialResult is DetectTextResultSpatial) {
  print('--- Spatial Document Layout ---');
  print(spatialResult.text);
}
```

## 4. Running on a Background Isolate in Flutter

Because Dart FFI calls execute synchronously on the calling isolate, wrap OCR inference inside `Isolate.run` in Flutter mobile/desktop apps to keep UI animations at 60/120 FPS:

```dart
import 'dart:isolate';
import 'dart:typed_data';
import 'package:rusto_flutter/rusto_flutter.dart';

Future<List<TextResult>> scanInBackground(Uint8List imageBytes, String cacheDir) {
  return Isolate.run(() {
    final engine = RustO.initialize('{"cacheDir": "$cacheDir"}');
    try {
      final res = engine
          .detectText(imageBytes)
          .withAutoUnwarp()
          .asLines()
          .run();
      return res is DetectTextResultStructured ? res.results : const <TextResult>[];
    } finally {
      engine.close();
    }
  });
}
```

## 5. Best Practices in Flutter Widget Tests

When writing `testWidgets` that interact with native FFI calls, load fixture files using synchronous file operations (`File(path).readAsBytesSync()`) rather than `await File(path).readAsBytes()` to avoid event-loop stalls inside Flutter's `FakeAsync` test zone.
