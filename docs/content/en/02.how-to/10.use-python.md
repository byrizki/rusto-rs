The `rusto` Python package provides native bindings powered by [UniFFI](https://mozilla.github.io/uniffi-rs/), allowing Python applications to run pure-Rust OCR with native speed, context-manager lifecycle safety, and zero GIL contention during inference.

## Installation

```bash
pip install rusto
```

---

## 1. Engine Initialization

Call `RustO.initialize()` with zero arguments to automatically download and cache the default **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) models on first run, or configure presets with `InitializeConfig`:

```python
from rusto import InitializeConfig, RustO

# Option A: Zero-config initialization (auto-downloads ppocrv6-tiny on first run)
engine = RustO.initialize()

# Option B: Explicit Indra OCR or PP-OCRv6 presets
indra_cfg = InitializeConfig.indra()
ppv6_cfg = InitializeConfig.ppv6(
    det_model_path="models/det.rten",
    rec_model_path="models/rec.rten",
    dict_path="models/dict.txt",
)
custom_engine = RustO.initialize(ppv6_cfg)
```

`RustO` also supports Python `with` statements so `engine.close()` is called automatically:

```python
with RustO.initialize() as engine:
    result = engine.detect_text("receipt.jpg").as_lines().run()
```

## 2. Text Recognition via Fluent Builder

Chain pipeline toggles, 6-phase options, and output granularity (`.as_lines()`, `.as_words()`, `.as_spatial()`) before calling `.run()`:

### Structured Output (`as_lines` / `as_words`)

```python
from rusto import PostRecognitionOptions, RustO

with RustO.initialize() as engine:
    result = (
        engine.detect_text("receipt.jpg")
        .with_auto_unwarp()
        .with_layout_reading()
        .with_post_recognition(PostRecognitionOptions(score_threshold=0.6))
        .as_lines()
        .run()
    )

    if result.is_STRUCTURED():
        for item in result.results:
            print(f"[{item.score:.2f}] {item.text}")
            print(
                f"  Frame: left={item.frame.left}, top={item.frame.top}, "
                f"w={item.frame.width}, h={item.frame.height}"
            )
```

### From In-Memory Bytes or Decoded RGB8 Pixels

```python
# 1. Encoded PNG/JPEG bytes
with open("invoice.png", "rb") as f:
    image_bytes = f.read()

result = engine.detect_text(image_bytes).as_lines().run()

# 2. Decoded interleaved RGB8 pixel buffer (e.g. from NumPy / Pillow)
rgb_result = (
    engine.detect_text()
    .rgb(rgb_bytes, width, height, width * 3)
    .as_lines()
    .run()
)
```

## 3. Spatial Layout Reconstruction

Preserve tabular layouts, receipts, and multi-column documents using `.as_spatial().run()`:

```python
from rusto import PreRecognitionOptions, RustO

with RustO.initialize() as engine:
    result = (
        engine.detect_text("invoice.png")
        .with_pre_recognition(PreRecognitionOptions(line_y_threshold=0.5, word_x_threshold=0.4))
        .as_spatial()
        .run()
    )

    if result.is_SPATIAL():
        print("--- Reconstructed Spatial Document ---")
        print(result.text)
```
