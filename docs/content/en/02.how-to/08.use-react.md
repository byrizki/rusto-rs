# Use React

The `@rustors/react` package provides declarative React primitives on top of `@rustors/web`: `<RustoProvider />`, `useOcr()`, `useRusto()`, `<OcrOverlay />`, and `<OcrDropzone />`.

## Installation

```bash
npm install @rustors/react @rustors/web
# or
yarn add @rustors/react @rustors/web
# or
pnpm add @rustors/react @rustors/web
```

## Setup Provider

Wrap your application in `<RustoProvider />` to manage WASM Web Worker lifecycle and model initialization (`'ppv6'` default, plus `'indra'`, `'ppv5'`, `'ppv4'`, `'ppv3'`):

```tsx
import React from 'react';
import { RustoProvider } from '@rustors/react';

// Option A: Local assets hosted in public/ folder
const localModels = {
  detection: '/models/ppocrv6-tiny/det.rten',
  recognition: '/models/ppocrv6-tiny/rec.rten',
  dictionary: '/models/ppocrv6-tiny/dict.txt',
};

// Option B: Hosted via Hugging Face Hub (native CORS enabled)
const HF_BASE = 'https://huggingface.co/byrizki/rusto-models/resolve/main';
const remoteModels = {
  detection: `${HF_BASE}/ppocrv6-tiny/det.rten`,
  recognition: `${HF_BASE}/ppocrv6-tiny/rec.rten`,
  dictionary: `${HF_BASE}/ppocrv6-tiny/dict.txt`,
  unwarp: `${HF_BASE}/modules/uvdoc.rten`,
  layout: `${HF_BASE}/modules/layout_cdla.rten`,
  order: `${HF_BASE}/indraocr/order.rten`,
};

export function App() {
  return (
    <RustoProvider
      config={{
        preset: 'ppv6',
        enableReadingOrder: true,
        layoutModel: 'cdla',
        wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
        models: remoteModels,
      }}
    >
      <OcrScanner />
    </RustoProvider>
  );
}
```

## Scanning with `useOcr`, `<OcrDropzone />`, and `<OcrOverlay />`

```tsx
import React, { useState } from 'react';
import { OcrDropzone, OcrOverlay, useOcr } from '@rustors/react';

export function OcrScanner() {
  const [imageSrc, setImageSrc] = useState<string | null>(null);
  const { detect, results, isProcessing } = useOcr();

  const handleFileSelect = async (file: File) => {
    setImageSrc(URL.createObjectURL(file));
    await detect(file, {
      autoUnwarp: true,
      layoutReading: true,
      postRecognition: { scoreThreshold: 0.5 },
    });
  };

  return (
    <div>
      <OcrDropzone onFileSelect={handleFileSelect} />

      {isProcessing && <p>Scanning document...</p>}

      {imageSrc && results.length > 0 && (
        <OcrOverlay
          imageSrc={imageSrc}
          results={results}
          onItemClick={(item) => console.log('Clicked box:', item.text)}
        />
      )}
    </div>
  );
}
```

## Direct Fluent Builder Chaining with `useRusto()`

When you want fluent builder chaining (`.asLines()`, `.asWords()`, `.asSpatial()`) directly inside a component, access `service.getEngine()` via `useRusto()`:

```tsx
import React, { useState } from 'react';
import { useRusto } from '@rustors/react';

export function SpatialReceiptViewer({ file }: { file: File }) {
  const { service, isInitialized } = useRusto();
  const [spatial, setSpatial] = useState('');

  const scanSpatial = async () => {
    if (!isInitialized) return;
    const text = await service.getEngine().detectText(file).withAutoUnwarp().asSpatial().run();
    setSpatial(text);
  };

  return (
    <div>
      <button onClick={scanSpatial} disabled={!isInitialized}>
        Reconstruct Spatial Layout
      </button>
      {spatial && <pre>{spatial}</pre>}
    </div>
  );
}
```

## Content Security Policy (CSP) Troubleshooting

When building React or Next.js applications in environments with strict CSP headers, add these directives:

```http
Content-Security-Policy:
  script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net;
  connect-src 'self' https://cdn.jsdelivr.net https://huggingface.co blob:;
  worker-src 'self' blob:;
  img-src 'self' data: blob:;
```

- If you see `EvalError: Refused to compile or instantiate WebAssembly module`, add `'wasm-unsafe-eval'` to `script-src`.
- If model assets fail to download from jsDelivr or Hugging Face Hub, add `https://cdn.jsdelivr.net` and `https://huggingface.co` to `connect-src`.
- If worker instantiation throws a `SecurityError`, add `worker-src 'self' blob:`.
