The `@rustors/node` package provides high-performance native N-API bindings for Node.js, linking directly against the pure-Rust RustO! engine with zero IPC or child-process overhead.

## Installation

```bash
npm install @rustors/node
```

Pre-built N-API binaries are automatically resolved for Linux (`x64`, `arm64`), macOS (Apple Silicon & Intel), and Windows (`x64`).

---

## 1. Engine Initialization & Cleanup

Call `RustO.initialize()` with zero arguments to automatically download and cache the flagship **Indra OCR** (`indraocr`) pipeline on first run, or pass an `InitializeConfig` object:

```javascript
const { RustO } = require('@rustors/node');

// Option A: Zero-config initialization (auto-downloads indraocr on first run)
const engine = RustO.initialize();

// Option B: Initialize with auxiliary unwarping, layout & reading order
const docEngine = RustO.initialize({
  model: 'indraocr',
  enableReadingOrder: true,
  layoutVariant: 'cdla',
  unwarp: { enabled: true },
  layout: { enabled: true },
});

// Option C: Explicit local model paths
const customEngine = RustO.initialize({
  template: 'ppv6',
  detection: { modelPath: 'models/det.rten' },
  recognition: { modelPath: 'models/rec.rten', dictPath: 'models/dict.txt' },
});
```

## 2. Text Recognition via Fluent Builder

Chain runtime toggles, 6-phase options, and output granularity (`.asLines()`, `.asWords()`, `.asSpatial()`) before calling `.run()`:

### From Filesystem Path

```javascript
const results = engine
  .detectText('receipt.jpg')
  .withAutoUnwarp()
  .withLayoutReading()
  .asLines()
  .run();

results.forEach((item, index) => {
  console.log(`[Line ${index + 1}] ${item.text} (${(item.score * 100).toFixed(1)}%)`);
  console.log(`  Bounding Box: ${JSON.stringify(item.box_points)}`);
  console.log(
    `  Frame: left=${item.frame.left}, top=${item.frame.top}, w=${item.frame.width}, h=${item.frame.height}`
  );
  if (item.region_id != null) {
    console.log(`  Layout Region #${item.region_id}: ${item.layout_type}`);
  }
});
```

### From Encoded Buffer or Decoded RGB8 Pixels

```javascript
const fs = require('fs');

// 1. Encoded PNG/JPEG Buffer in memory
const imageBuffer = fs.readFileSync('document.png');
const results = engine.detectText(imageBuffer).asLines().run();

// 2. Decoded interleaved RGB8 pixel buffer (skips image decoding)
const rgbResults = engine
  .detectText()
  .rgb(rgbBuffer, width, height, width * 3)
  .asLines()
  .run();
```

## 3. Spatial Layout Reconstruction

To preserve two-dimensional formatting, columns, tables, and receipts as a formatted `string`:

```javascript
const spatialText = engine
  .detectText('invoice.png')
  .withPreRecognition({ lineYThreshold: 0.5, wordXThreshold: 0.4 })
  .asSpatial()
  .run();

console.log('--- Reconstructed Spatial Document ---');
console.log(spatialText);
```

## 4. TypeScript & Model Pre-Downloading

`@rustors/node` ships complete TypeScript declarations and offline download helpers:

```typescript
import { RustO, TextResult } from '@rustors/node';

// Pre-download models in Docker build steps or CI
RustO.downloadModel('indraocr', 'latin');

const engine: RustO = RustO.initialize();
const lines: TextResult[] = engine
  .detectText('invoice.png')
  .withAutoUnwarp()
  .withLayoutReading()
  .withPostRecognition({ scoreThreshold: 0.6 })
  .asLines()
  .run();

engine.close();
```
