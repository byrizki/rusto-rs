The `github.com/byrizki/rusto-rs/packages/go` module (`package rusto`) provides native Go bindings via Cgo. It embeds dynamic linker runtime search paths (`-Wl,-rpath`), allowing Go binaries and unit tests to locate `librusto` without manual `LD_LIBRARY_PATH` configuration.

## Installation

```bash
go get github.com/byrizki/rusto-rs/packages/go
```

Ensure `librusto.so` (Linux), `librusto.dylib` (macOS), or `rusto.dll` (Windows) is built and located in your library search path.

---

## 1. Engine Initialization

Call `rusto.Initialize()` (or `rusto.New()`) with zero arguments to automatically download and cache the default **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) pipeline on first run, or pass an optional JSON configuration string:

```go
package main

import (
	"log"

	"github.com/byrizki/rusto-rs/packages/go"
)

func main() {
	// Option A: Zero-config initialization (auto-downloads ppocrv6-tiny on first run)
	engine, err := rusto.Initialize()
	if err != nil {
		log.Fatalf("Failed to initialize RustO: %v", err)
	}
	defer engine.Close()

	// Option B: Explicit JSON configuration
	customEngine, err := rusto.Initialize(`{
		"model": "ppocrv6-tiny",
		"unwarp": {"enabled": true},
		"layout": {"enabled": true},
		"enableReadingOrder": true
	}`)
	if err != nil {
		log.Fatalf("Failed to initialize custom engine: %v", err)
	}
	defer customEngine.Close()
}
```

## 2. Text Recognition via Fluent Builder

Chain runtime toggles, 6-phase options, and output granularity (`.AsLines()`, `.AsWords()`, `.AsSpatial()`) ending in `.Run()`, which returns `(*DetectTextResult, error)`:

### From Filesystem Path

```go
res, err := engine.DetectText("receipt.jpg").
	WithAutoUnwarp(true).
	WithLayoutReading(true).
	WithPostRecognition(rusto.PostRecognitionOptions{ScoreThreshold: 0.6}).
	AsLines().
	Run()
if err != nil {
	log.Fatalf("Detection failed: %v", err)
}

for i, line := range res.Results {
	fmt.Printf("[%d] (Score: %0.2f) %s\n", i+1, line.Score, line.Text)
	fmt.Printf("    Frame: left=%0.1f, top=%0.1f, w=%0.1f, h=%0.1f\n",
		line.Frame.Left, line.Frame.Top, line.Frame.Width, line.Frame.Height)
	if line.RegionID >= 0 {
		fmt.Printf("    Layout Region #%d (type=%d)\n", line.RegionID, line.LayoutType)
	}
}
```

### From Encoded Bytes or Decoded RGB8 Pixels

```go
import "os"

// 1. Encoded PNG/JPEG bytes in memory
imageBytes, err := os.ReadFile("document.png")
if err != nil {
	log.Fatal(err)
}

res, err := engine.DetectText().
	Data(imageBytes).
	AsLines().
	Run()
if err != nil {
	log.Fatal(err)
}
fmt.Printf("Detected %d text segments\n", len(res.Results))

// 2. Decoded interleaved RGB8 pixel buffer
rgbRes, err := engine.DetectText().
	RGB(rgbPixels, width, height, int(width)*3).
	AsLines().
	Run()
```

## 3. Spatial Layout Reconstruction

Use `.AsSpatial().Run()` to reconstruct formatted 2D text layouts (`res.IsSpatial == true` and `res.Text` holds the aligned text):

```go
spatialRes, err := engine.DetectText("invoice.png").
	WithPreRecognition(rusto.PreRecognitionOptions{
		LineYThreshold: 0.5,
		WordXThreshold: 0.4,
	}).
	AsSpatial().
	Run()
if err != nil {
	log.Fatal(err)
}

fmt.Println("--- Spatial Output ---")
fmt.Println(spatialRes.Text)
```
