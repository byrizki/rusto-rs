RustO! comes with a high-performance command line interface (CLI) binary for desktop OCR, terminal workflows, model management, and automated CI pipelines.

## Installation & Building

Build the CLI directly from source with Release optimizations:

```bash
cargo build --release
```

The compiled binary will be located at `target/release/rusto`. You can optionally install it into your `$PATH`:

```bash
cargo install --path .
```

---

## 1. Quick Invocations

### Auto-Download & Default Inference

With RustO!, you do not need to specify manual model paths if you want to use the canonical models. RustO! automatically downloads required models to `~/.cache/rusto/models` on first run:

```bash
# Uses default canonical model (ppocrv6-tiny)
rusto ocr receipt.jpg

# Or run with Indonesian ID / receipt specialist model
rusto ocr receipt.jpg --model indraocr

# Or with spatial reconstructed layout output
rusto ocr invoice.png --format text-ordered
```

---

## 2. Dedicated Model Downloader (`rusto download`)

Download model assets ahead of time for offline systems, Docker containers, or CI environments:

```bash
# Download default model (ppocrv6-tiny) to ~/.cache/rusto/models
rusto download

# Download a specific canonical model
rusto download --model indraocr
rusto download --model ppocrv6-small

# Download a regional language pack
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang japan

# Download all available canonical models
rusto download --all

# Specify a custom cache directory
rusto download --model indraocr --cache-dir /opt/models
```

## 3. CLI Command & Options Reference

### Subcommands

| Subcommand                    | Description                                                                     |
| :---------------------------- | :------------------------------------------------------------------------------ |
| `rusto ocr [IMAGE] [OPTIONS]` | Run OCR text detection and recognition on an image (default if image provided). |
| `rusto download [OPTIONS]`    | Download pre-trained `.rten` model weights to local cache.                      |

### `rusto ocr` Options

| Option                | Flag               | Type     | Default                 | Description                                                                                          |
| :-------------------- | :----------------- | :------- | :---------------------- | :--------------------------------------------------------------------------------------------------- |
| **Model**             | `--model`          | `String` | `ppocrv6-tiny`          | Canonical model name (`ppocrv6-tiny`, `ppocrv6-small`, `indraocr`, `ppocrv5`, `ppocrv4`, `ppocrv3`). |
| **Model Directory**   | `--model-path`     | `Path`   | None                    | Base directory containing `det.rten`, `rec.rten`, and `dict.txt`.                                    |
| **Detection Model**   | `--det-model`      | `Path`   | None                    | Component path override for detection model file.                                                    |
| **Recognition Model** | `--rec-model`      | `Path`   | None                    | Component path override for recognition model file.                                                  |
| **Dictionary**        | `--dict`           | `Path`   | None                    | Component path override for character dictionary file.                                               |
| **Language**          | `--lang`           | `String` | None                    | Language pack code (e.g. `latin`, `cyrillic`, `ar`, `ja`, `ko`, `devanagari`).                       |
| **Cache Directory**   | `--cache-dir`      | `Path`   | `~/.cache/rusto/models` | Custom cache directory for downloaded models.                                                        |
| **Output Format**     | `-f`, `--format`   | `Enum`   | `json`                  | Output mode (`json`, `text`, `tsv`, `markdown`, `text-ordered`).                                     |
| **Text Score**        | `--text-score`     | `Float`  | `0.5`                   | Minimum recognition confidence score threshold [0.0 - 1.0].                                          |
| **Batch Size**        | `--batch-num`      | `Int`    | `6`                     | Recognition batch size for simultaneous text-line inference.                                         |
| **Orientation**       | `--enable-orient`  | `Flag`   | `false`                 | Enable whole-document 0°/90°/180°/270° orientation detection.                                        |
| **Orient Model**      | `--orient-model`   | `Path`   | None                    | Path to orientation classifier model file.                                                           |
| **CLS Model**         | `--cls-model`      | `Path`   | None                    | Path to text line 180° rotation classifier model.                                                    |
| **Unwarp Model**      | `--unwarp-model`   | `Path`   | None                    | Path to document dewarping model file.                                                               |
| **Layout Model**      | `--layout-model`   | `Path`   | None                    | Path to document layout analysis model file.                                                         |
| **Layout Variant**    | `--layout-variant` | `String` | `cdla`                  | Layout variant: `cdla` (10 classes) or `publaynet` (5 classes).                                      |
| **Reading Order**     | `--reading-order`  | `Flag`   | `false`                 | Enable neural reading order recovery transformer.                                                    |

## 4. Output Formats with Real Examples

Outputs structured JSON with bounding polygon quads and axis-aligned bounding frames:

```bash
rusto ocr receipt.jpg --format json
```

```json

    "text": "COFFEE SHOP",
    "score": 0.992,
```

### 2. Formatted Spatial Layout (`--format text-ordered`)

Preserves tabular columns, receipt rows, and document indentations:

```bash
rusto ocr invoice.jpg --format text-ordered
```


### 3. Tab-Separated Values (`--format tsv`)

Ideal for shell scripting and piping into `awk`, `cut`, or spreadsheets:

```bash
rusto ocr receipt.jpg --format tsv
```

## 5. Shell Integration & Batch Processing

### Piping into `jq` for JSON Processing

Extract high-confidence text lines:

```bash
rusto ocr receipt.jpg --format json | \
  jq -r '.[] | select(.score > 0.95) | "\(.text) (\(.score * 100 | round)%)"'
```

### Batch Scanning an Entire Directory

Scan all `.jpg` and `.png` images in parallel using `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto ocr {} --format text-ordered
```
