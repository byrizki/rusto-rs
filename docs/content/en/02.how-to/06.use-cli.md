RustO! ships with the standalone `rusto` command-line binary for desktop OCR, shell pipelines, model caching, and automated CI workflows.

## Installation & Building

Install `rusto` from `crates.io`:

```bash
cargo install rusto-rs
rusto --version
```

Or build directly from source with Release optimizations:

```bash
cargo build --release
# Compiled binary: target/release/rusto
```

---

## 1. Quick Invocations

Both `rusto <IMAGE>` and `rusto ocr <IMAGE>` execute the OCR pipeline. On first run, `rusto` automatically downloads missing `.rten` model files into `~/.cache/rusto/models`:

```bash
# Default invocation using flagship Indra OCR (outputs JSON)
rusto receipt.jpg

# Explicit ocr subcommand (equivalent)
rusto ocr receipt.jpg

# Run with PP-OCRv6 Tiny model
rusto receipt.jpg --model ppocrv6-tiny

# Reconstruct 2D spatial columns and tables
rusto invoice.png --format spatial

# Enable full document understanding (unwarp + layout + neural reading order)
rusto scan.jpg --enable-unwarp --enable-layout --reading-order --format text
```

---

## 2. Dedicated Model Downloader (`rusto download`)

Pre-download model assets ahead of time for air-gapped servers, Docker images, or CI runners:

```bash
# Download default flagship model (indraocr) to ~/.cache/rusto/models
rusto download --model indraocr

# Download Indra OCR plus auxiliary unwarp, orientation, layout, and reading-order models
rusto download --model indraocr --orient --unwarp --layout --reading-order

# Download PP-OCRv6 Tiny or regional language packs
rusto download --model ppocrv6-tiny
rusto download --model ppocrv5 --lang latin
rusto download --model ppocrv4 --lang ja

# Download every available pre-trained model asset
rusto download --all

# Specify a custom cache directory (or use --download-only on an OCR command)
rusto download --model indraocr --cache-dir /opt/models
rusto --model indraocr --download-only --cache-dir /opt/models
```

## 3. CLI Command & Options Reference

### Commands

| Command                       | Description                                                              |
| :---------------------------- | :----------------------------------------------------------------------- |
| `rusto <IMAGE> [OPTIONS]`     | Run OCR detection and recognition on `<IMAGE>`.                          |
| `rusto ocr <IMAGE> [OPTIONS]` | Explicit subcommand alias for `rusto <IMAGE> [OPTIONS]`.                 |
| `rusto download [OPTIONS]`    | Pre-download `.rten` model weights into the cache directory without OCR. |

### `rusto` / `rusto ocr` Flags

| Flag                         | Type     | Default                 | Description                                                                                         |
| :--------------------------- | :------- | :---------------------- | :-------------------------------------------------------------------------------------------------- |
| `-m`, `--model <MODEL>`      | `String` | `indraocr`              | Model pipeline (`indraocr`, `ppocrv6-tiny`, `ppocrv6-small`, `ppocrv5`, `ppocrv4`, `ppocrv3`).      |
| `-l`, `--lang <LANG>`        | `String` | None                    | Language code (`latin`, `rtl`, `world`, `ja`, `ko`, `ar`, `cyrillic`, `devanagari`, `chinese-cht`). |
| `--model-path <PATH>`        | `Path`   | None                    | Base directory containing `det`, `rec`, and `dict` files.                                           |
| `--det-model <PATH>`         | `Path`   | None                    | Explicit path override for the text detection `.rten` model.                                        |
| `--rec-model <PATH>`         | `Path`   | None                    | Explicit path override for the text recognition `.rten` model.                                      |
| `--dict <PATH>`              | `Path`   | None                    | Explicit path override for the dictionary (`.txt`) or metadata (`.json`) file.                      |
| `--cache-dir <PATH>`         | `Path`   | `~/.cache/rusto/models` | Custom directory for cached/downloaded model weights.                                               |
| `--download-only`            | `Flag`   | `false`                 | Download required models for the selected flags and exit without running inference.                 |
| `-f`, `--format <FORMAT>`    | `Enum`   | `json`                  | Output format: `json`, `text`, `text-ordered`, `spatial`, `tsv`, `markdown`.                        |
| `--enable-cls`               | `Flag`   | `false`                 | Enable `180°` text-line orientation classification (`ppocr_cls.rten`).                              |
| `--cls-model <PATH>`         | `Path`   | None                    | Explicit path override for the text-line classifier model.                                          |
| `--enable-orient`            | `Flag`   | `false`                 | Enable whole-page `0°/90°/180°/270°` orientation classification.                                    |
| `--orient-model <PATH>`      | `Path`   | None                    | Explicit path override for the document orientation model.                                          |
| `--enable-unwarp`            | `Flag`   | `false`                 | Enable UVDoc 3D geometric document dewarping (`uvdoc.rten`).                                        |
| `--unwarp-model <PATH>`      | `Path`   | None                    | Explicit path override for the document unwarping model.                                            |
| `--enable-layout`            | `Flag`   | `false`                 | Enable PicoDet document layout region detection.                                                    |
| `--layout-variant <VARIANT>` | `String` | `cdla`                  | Layout model variant: `cdla` (10-class) or `publaynet` (5-class).                                   |
| `--layout-model <PATH>`      | `Path`   | None                    | Explicit path override for the document layout model.                                               |
| `--reading-order`            | `Flag`   | `false`                 | Enable neural graph reading order recovery (`indra_order.rten`).                                    |
| `--det-limit <PX>`           | `Int`    | Preset default          | Detection resize dimension limit (`limit_side_len`).                                                |
| `--max-side-len <PX>`        | `Float`  | None                    | Maximum image side length during pre-detection downscaling.                                         |
| `--rec-batch-num <N>`        | `Int`    | `1` (Indra) / `6` (PP)  | Recognition mini-batch size for simultaneous line inference.                                        |
| `--score-threshold <SCORE>`  | `Float`  | `0.5`                   | Minimum recognition confidence score threshold `[0.0 - 1.0]`.                                       |

## 4. Output Formats with Real Examples

### 1. JSON (`--format json`)

Outputs structured JSON with polygon quads, axis-aligned bounding frames, and optional layout metadata (plus `layout_regions` when `--enable-layout` is active):

```bash
rusto receipt.jpg --format json
```

```json
[
  {
    "text": "COFFEE SHOP",
    "score": 0.992,
    "box_points": [
      [95.0, 30.0],
      [275.0, 30.0],
      [275.0, 55.0],
      [95.0, 55.0]
    ],
    "frame": {
      "left": 95.0,
      "top": 30.0,
      "width": 180.0,
      "height": 25.0
    }
  },
  {
    "text": "Total $16.50",
    "score": 0.988,
    "box_points": [
      [40.0, 245.0],
      [320.0, 245.0],
      [320.0, 265.0],
      [40.0, 265.0]
    ],
    "frame": {
      "left": 40.0,
      "top": 245.0,
      "width": 280.0,
      "height": 20.0
    }
  }
]
```

### 2. 2D Spatial Layout Reconstruction (`--format spatial`)

Reconstructs tabular columns, receipt rows, and horizontal spacing into visually aligned text (`--format text-ordered` sorts plain lines top-to-bottom / left-to-right without column padding):

```bash
rusto invoice.jpg --format spatial
```

```text
Item Description           Qty       Price       Total
Mechanical Keyboard          1     $120.00     $120.00
Wireless Mouse               2      $45.00      $90.00
USB-C Hub                    1      $35.00      $35.00
──────────────────────────────────────────────────────
Total Amount:                                  $245.00
```

---

### 3. Plain & Top-Down Ordered Text (`--format text` / `--format text-ordered`)

```bash
# Emit lines in pipeline / neural reading order
rusto article.jpg --reading-order --format text

# Emit lines sorted top-to-bottom, left-to-right by frame coordinates
rusto receipt.jpg --format text-ordered
```

---

### 4. Tab-Separated Values (`--format tsv`)

Ideal for shell scripting and piping into `awk`, `cut`, or spreadsheets:

```bash
rusto receipt.jpg --format tsv
```

```text
COFFEE SHOP	0.992	95.0,30.0,275.0,30.0,275.0,55.0,95.0,55.0
2026-08-20	0.981	40.0,70.0,140.0,70.0,140.0,90.0,40.0,90.0
Total $16.50	0.988	40.0,245.0,320.0,245.0,320.0,265.0,40.0,265.0
```

## 5. Shell Integration & Batch Processing

### Piping into `jq` for JSON Filtering

```bash
rusto receipt.jpg --score-threshold 0.95 --format json | \
  jq -r '.[] | "\(.text) (\(.score * 100 | round)%)"'
```

### Batch Scanning an Entire Directory

Scan all `.jpg` and `.png` images in parallel using `xargs`:

```bash
find ./scans -type f \( -name "*.jpg" -o -name "*.png" \) | \
  xargs -I {} -P 4 rusto {} --format spatial
```
