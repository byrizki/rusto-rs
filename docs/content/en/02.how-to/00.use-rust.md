The `rusto-rs` crate is the core pure Rust engine powering all RustO! platform bindings. It provides zero-cost abstractions, memory safety, and SIMD-accelerated image preprocessing.

## Installation

Add `rusto-rs` to your `Cargo.toml`:

```toml
[dependencies]
rusto-rs = "0.2.4"
```

---

## 1. Engine Initialization (`InitializeConfig`)

Initialize the OCR engine once per application lifecycle or thread. RustO! provides presets matching different PaddleOCR model generations:

```rust
use rusto::{InitializeConfig, RustO};

// Initialize with the standard PP-OCRv6 preset
let config = InitializeConfig::ppv6("models/det.mnn", "models/rec.mnn", "models/dict.txt")
    .with_det_thresh(0.3)
    .with_det_box_thresh(0.6)
    .with_limit_side_len(736)
    .with_limit_type("min")
    .with_unclip_ratio(2.0)
    .with_use_dilation(true)
    .with_text_score(0.5)
    .with_rec_batch_num(6);

let mut ocr = RustO::initialize(config)?;
```

### Auxiliary Models (Orientation & CLS)

For rotated scans or inverted text lines, attach orientation classification models:

```rust
// PP-OCRv5 with 180° line classifier (CLS) and whole-page rotator
let config = InitializeConfig::ppv5("models/det.mnn", "models/rec.mnn", "models/dict.txt")
    .with_cls_threshold("models/cls.mnn", 0.9)
    .with_orientation_threshold("models/orient.mnn", 0.85);

let mut ocr = RustO::initialize(config)?;
```

## 2. Request-Local Options (`OcrRunOptions`)

Image bounds, detector resizing, dilation, unclip ratios, and output modes can be modified per detection call via `OcrRunOptions` without altering the initialized model sessions:

```rust
use rusto::{
    DetectionRunOptions, ImageSource, OcrRunOptions, OutputGranularity,
    PostprocessRunOptions,
};

let options = OcrRunOptions {
    output: OutputGranularity::Lines, // OutputGranularity::Words or OutputGranularity::Spatial
    line_y_threshold: Some(0.5),      // Dynamic row clustering tolerance
    word_x_threshold: Some(0.4),      // Word/column spacing tolerance
    text_score: Some(0.55),           // Minimum recognition score cutoff
    classification: Some(true),       // Evaluate CLS if configured
    max_side_len: Some(1600.0),       // Max image side length bound
    min_height: Some(32.0),           // Minimum text box height
    detection: Some(DetectionRunOptions {
        limit_side_len: Some(960),
        limit_type: Some("max".into()),
        ..Default::default()
    }),
    postprocess: Some(PostprocessRunOptions {
        use_dilation: Some(true),     // Morphological dilation for faint receipts
        unclip_ratio: Some(2.0),
        threshold: Some(0.3),
        box_threshold: Some(0.6),
        ..Default::default()
    }),
    ..Default::default()
};
```

## 3. Supported Image Sources

`ImageSource` accepts filesystem paths or in-memory byte buffers:

```rust
use rusto::ImageSource;
use std::path::PathBuf;

// 1. Filesystem path (loads and decodes efficiently)
let source_path = ImageSource::Path(PathBuf::from("data/invoice.jpg"));

// 2. In-memory encoded bytes (PNG, JPEG, WebP, BMP)
let raw_bytes: Vec<u8> = std::fs::read("data/invoice.jpg")?;
let source_bytes = ImageSource::Bytes(raw_bytes);
```

## 4. Practical Recipes & Output Handling

### Recipe A: Extracting Structured Line Blocks

```rust
use rusto::{DetectTextResult, ImageSource, OcrRunOptions, OutputGranularity, RustO};

let mut options = OcrRunOptions::default();
options.output = OutputGranularity::Lines;

let result = ocr.detect_text(&ImageSource::Path("invoice.png".into()), &options)?;

if let DetectTextResult::Structured(items) = result {
    for item in items {
        println!("Text: {}", item.text);
        println!("Score: {:.3}", item.score);
        println!("Polygon Points [TL, TR, BR, BL]: {:?}", item.box_points);
        println!(
            "Axis-Aligned Frame: Left={}, Top={}, Width={}, Height={}",
            item.frame.left, item.frame.top, item.frame.width, item.frame.height
        );
    }
}
```

### Recipe B: Reconstructing Document Spatial Layout

Preserve multi-column table alignment, invoice columns, and form fields into formatted text:

```rust
use rusto::{DetectTextResult, ImageSource, OcrRunOptions, OutputGranularity};

let mut options = OcrRunOptions::default();
options.output = OutputGranularity::Spatial;
options.line_y_threshold = Some(0.5);
options.word_x_threshold = Some(0.4);

if let DetectTextResult::Spatial(layout_text) = ocr.detect_text(
    &ImageSource::Path("table.png".into()),
    &options,
)? {
    println!("{layout_text}");
}
```

#### Example Output:

### Recipe C: Multi-Threaded Batch Processing with Rayon

Because `RustO` instances hold inference session state, use thread-local instances or worker thread pools for concurrent high-throughput workloads:

```rust
use rayon::prelude::*;
use rusto::{DetectTextResult, ImageSource, InitializeConfig, OcrRunOptions, RustO};
use std::path::PathBuf;

let image_paths: Vec<PathBuf> = vec![
    "doc1.jpg".into(),
    "doc2.jpg".into(),
    "doc3.jpg".into(),
    "doc4.jpg".into(),
];

// Process concurrently across CPU cores
image_paths.par_iter().for_each(|path| {
    // Each thread initializes its own lightweight session
    let config = InitializeConfig::ppv6("models/det.mnn", "models/rec.mnn", "models/dict.txt");
    let mut thread_ocr = RustO::initialize(config).expect("Failed to init thread OCR");

    let result = thread_ocr.detect_text(
        &ImageSource::Path(path.clone()),
        &OcrRunOptions::default(),
    ).expect("OCR error");

    if let DetectTextResult::Structured(lines) = result {
        println!("Processed {:?}: {} lines found", path, lines.len());
    }
});
```
