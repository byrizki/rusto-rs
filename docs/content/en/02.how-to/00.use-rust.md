The `rusto-rs` crate (`use rusto::...`) is the core pure-Rust engine powering all RustO! platform SDKs. It provides zero-cost abstractions, memory safety, SIMD-accelerated image preprocessing, and pluggable neural inference backends.

## Installation & Cargo Features

Add `rusto-rs` to your `Cargo.toml`:

```toml
[dependencies]
rusto-rs = "0.4.0"
```

By default, `rusto-rs` includes the pure-Rust MNN runtime (`rusto-nn`) out of the box and enables `default = ["ffi", "rten"]`:

| Feature   | Default | Description                                                                         |
| :-------- | :-----: | :---------------------------------------------------------------------------------- |
| `rten`    | **Yes** | Pure-Rust RTen neural network backend (`rusto-rten`) for `.rten` models.            |
| `ffi`     | **Yes** | C FFI (`rocr_*`) and UniFFI exports for embedding `librusto` into foreign runtimes. |
| `webgpu`  |   No    | Cross-platform GPU compute acceleration via WebGPU (`rusto-nn-webgpu`).             |
| `cuda`    |   No    | NVIDIA GPU compute acceleration via `rusto-nn-cuda`.                                |
| `mnn-cpp` |   No    | Optional Alibaba MNN C++ runtime bridge (`rusto-mnn`) for hardware execution.       |

## 1. Engine Initialization (`InitializeConfig`)

Initialize the OCR engine once per worker or thread. You can auto-download the default **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`) pipeline with zero manual paths, or configure explicit presets (`ppv6`, `indra`, `ppv5`, `ppv4`, `ppv3`):

```rust
use rusto::download::parse_config_with_auto_download;
use rusto::{InitializeConfig, RustO};

// Register session loaders
rusto::init();

// Option A: Zero-config initialization (auto-downloads ppocrv6-tiny to ~/.cache/rusto/models)
let auto_cfg = parse_config_with_auto_download("{}")?;
let mut ocr = RustO::initialize(auto_cfg)?;

// Option B: Explicit Indra OCR local model paths (.mnn or .rten)
let indra_cfg = InitializeConfig::indra(
    "models/indra_det.mnn",
    "models/indra_rec_latin.mnn",
    "models/indra_rec_latin_meta.json",
);
let mut indra_ocr = RustO::initialize(indra_cfg)?;

// Option C: PP-OCRv6 preset with custom hyperparameters
let ppv6_cfg = InitializeConfig::ppv6("models/det.mnn", "models/rec.mnn", "models/dict.txt")
    .with_det_thresh(0.3)
    .with_det_box_thresh(0.6)
    .with_limit_side_len(736)
    .with_limit_type("min")
    .with_unclip_ratio(2.0)
    .with_use_dilation(true)
    .with_text_score(0.5)
    .with_rec_batch_num(6);
let mut ppv6_ocr = RustO::initialize(ppv6_cfg)?;
```

### Auxiliary Models (Unwarping, Layout, Orientation & CLS)

Attach optional geometric dewarping (`uvdoc.mnn` / `uvdoc.rten`), PicoDet layout detection (`layout_cdla.mnn` / `layout_cdla.rten`), whole-page orientation (`0°/90°/180°/270°`), or `180°` line classification:

```rust
use rusto::download::parse_config_with_auto_download;
use rusto::RustO;

rusto::init();
let config = parse_config_with_auto_download(
    r#"{
        "model": "ppocrv6-tiny",
        "unwarp": { "enabled": true },
        "orientation": { "enabled": true },
        "layout": { "enabled": true },
        "layoutVariant": "cdla",
        "enableReadingOrder": true
    }"#,
)?;
let mut ocr = RustO::initialize(config)?;
```

### Generic & Pluggable Engine Composition

RustO! provides the `InferenceSession` trait and `EngineSession` enum to plug in custom inference sessions without altering downstream OCR postprocessing:

```rust
use rusto::{InitializeConfig, RustO, TextDetector, TextRecognizer};

let config = InitializeConfig::indra("models/det.mnn", "models/rec.mnn", "models/meta.json");

// Option 1: Supply custom InferenceSession implementations
let ocr = RustO::with_custom_engines(config.clone(), my_det_session, my_rec_session)?;

// Option 2: Compose pre-configured TextDetector and TextRecognizer
let det = TextDetector::new(config.det.clone())?;
let rec = TextRecognizer::new(config.rec.clone())?;
let ocr = RustO::with_components(config.global, det, rec)?;
```

## 2. Request-Local Options & Fluent Builder

Chain runtime options per call with `detect_text_builder` (4 pipeline toggles + 6 structured phases) and select output granularity with `.as_lines()`, `.as_words()`, or `.as_spatial()` before calling `.run()`:

```rust
use rusto::{
    DetectTextBuilderExt, ImageSource, PostDetectionOptions, PostRecognitionOptions,
    PreRecognitionOptions,
};

let result = ocr
    .detect_text_builder(ImageSource::Path("data/invoice.jpg".into()))
    .with_auto_unwarp(true)
    .with_layout_reading(true)
    .with_post_detection(PostDetectionOptions {
        use_dilation: Some(true),
        unclip_ratio: Some(2.0),
        threshold: Some(0.3),
        box_threshold: Some(0.6),
        ..Default::default()
    })
    .with_pre_recognition(PreRecognitionOptions {
        line_y_threshold: Some(0.5),
        word_x_threshold: Some(0.4),
    })
    .with_post_recognition(PostRecognitionOptions {
        score_threshold: Some(0.6),
    })
    .as_lines()
    .run()?;
```

## 3. Supported Image Sources

Pass filesystem paths, encoded in-memory bytes, or zero-decode interleaved RGB8 pixel buffers:

```rust
use rusto::{DetectTextBuilderExt, ImageSource};
use std::path::PathBuf;

// 1. Filesystem path
let source_path = ImageSource::Path(PathBuf::from("data/invoice.jpg"));

// 2. Encoded image bytes (PNG, JPEG, WebP, BMP)
let raw_bytes: Vec<u8> = std::fs::read("data/invoice.jpg")?;
let source_bytes = ImageSource::Bytes(raw_bytes);

// 3. Decoded interleaved RGB8 pixels (skips image codec decoding)
let rgb_result = ocr
    .detect_text_rgb_builder(&rgb_pixels, width, height, width as usize * 3)
    .as_lines()
    .run()?;
```

## 4. Practical Recipes & Output Handling

### Recipe A: Extracting Structured Line Blocks & Layout Metadata

```rust
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource};

let result = ocr
    .detect_text_builder(ImageSource::Path("invoice.png".into()))
    .with_layout_reading(true)
    .as_lines()
    .run()?;

if let DetectTextResult::Structured(items) = result {
    for item in items {
        println!("Text: {}", item.text);
        println!("Score: {:.3}", item.score);
        println!("Polygon Points [TL, TR, BR, BL]: {:?}", item.box_points);
        println!(
            "Frame: Left={}, Top={}, Width={}, Height={}",
            item.frame.left, item.frame.top, item.frame.width, item.frame.height
        );
        if let (Some(region_id), Some(layout_type)) = (item.region_id, item.layout_type) {
            println!("Layout Region #{region_id}: {layout_type:?}");
        }
    }
}
```

### Recipe B: Reconstructing Document Spatial Layout

Preserve multi-column table alignment, invoice columns, and form fields into formatted plain text:

```rust
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource, PreRecognitionOptions};

if let DetectTextResult::Spatial(layout_text) = ocr
    .detect_text_builder(ImageSource::Path("table.png".into()))
    .with_pre_recognition(PreRecognitionOptions {
        line_y_threshold: Some(0.5),
        word_x_threshold: Some(0.4),
    })
    .as_spatial()
    .run()?
{
    println!("{layout_text}");
}
```

### Recipe C: Multi-Threaded Batch Processing with Rayon

Because `RustO` instances hold mutable session state, create one instance per worker thread for parallel batch processing:

```rust
use rayon::prelude::*;
use rusto::download::parse_config_with_auto_download;
use rusto::{DetectTextBuilderExt, DetectTextResult, ImageSource, RustO};
use std::path::PathBuf;

rusto::init();
let base_config = parse_config_with_auto_download("{}")?;

let image_paths: Vec<PathBuf> = vec![
    "doc1.jpg".into(),
    "doc2.jpg".into(),
    "doc3.jpg".into(),
    "doc4.jpg".into(),
];

image_paths.par_iter().for_each(|path| {
    let mut thread_ocr = RustO::initialize(base_config.clone()).expect("Failed to init thread OCR");

    let result = thread_ocr
        .detect_text_builder(ImageSource::Path(path.clone()))
        .as_lines()
        .run()
        .expect("OCR error");

    if let DetectTextResult::Structured(lines) = result {
        println!("Processed {:?}: {} lines found", path, lines.len());
    }
});
```

> [!TIP]
> **Concurrency & Embedded Sizing**: Configure per-engine recognition worker bounds with `InitializeConfig::with_rec_workers(n)` / `.with_max_rec_workers(n)` (or per-image with `DetectTextBuilder::with_rec_workers(n)`). Set `rec_workers = 1` on memory-constrained embedded/IoT devices for deterministic single-threaded execution, and for HTTP server workloads use an engine pool (e.g. 4–8 `RustO` instances) instead of wrapping one instance in `Arc<Mutex<RustO>>`.
