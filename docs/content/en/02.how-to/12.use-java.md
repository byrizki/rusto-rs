The `rusto-java` package provides high-performance JVM bindings using Java Native Access (JNA). `RustO` implements `AutoCloseable` for deterministic native memory cleanup in `try-with-resources` blocks.

## Installation

### Gradle (Kotlin DSL)

```kotlin
repositories {
    mavenCentral()
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.byrizki.rusto-rs:rusto-java:0.4.0")
}
```

### Maven (`pom.xml`)

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.byrizki.rusto-rs</groupId>
    <artifactId>rusto-java</artifactId>
    <version>0.4.0</version>
</dependency>
```

Ensure `librusto` (`librusto.so`, `librusto.dylib`, or `rusto.dll`) is available in `jna.library.path` or `java.library.path`.

## 1. Engine Initialization

Call `RustO.initialize()` with zero arguments to automatically download and cache the default **PP-OCRv6 Tiny FP32** (`ppocrv6-tiny`, Apache 2.0) pipeline on first run, or supply a custom JSON configuration string:

```java
import com.byrizki.rusto.RustO;

public class Main {
    public static void main(String[] args) {
        // Option A: Zero-config initialization (auto-downloads ppocrv6-tiny on first run)
        try (RustO engine = RustO.initialize()) {
            // Engine is ready for recognition
        }

        // Option B: Explicit JSON configuration
        String config = """
            {
                "model": "ppocrv6-tiny",
                "unwarp": { "enabled": true },
                "layout": { "enabled": true },
                "enableReadingOrder": true
            }
            """;
        try (RustO customEngine = RustO.initialize(config)) {
            // Ready with unwarping, layout analysis, and neural reading order
        }
    }
}
```

## 2. Text Recognition via Fluent Builder

Chain runtime toggles, 6-phase options, and output granularity (`.asLines()`, `.asWords()`, `.asSpatial()`) ending in `.run()`, which returns `RustO.DetectTextResult`:

### Structured Line Results (`.asLines().run()`)

```java
import com.byrizki.rusto.RustO;
import com.byrizki.rusto.TextResult;

try (RustO engine = RustO.initialize()) {
    RustO.DetectTextResult res = engine.detectText("receipt.jpg")
        .withAutoUnwarp()
        .withLayoutReading()
        .asLines()
        .run();

    for (TextResult r : res.results()) {
        System.out.printf("[%0.2f] %s%n", r.score(), r.text());
        System.out.printf("  Frame: left=%0.1f, top=%0.1f, width=%0.1f, height=%0.1f%n",
            r.frame().left(), r.frame().top(), r.frame().width(), r.frame().height());
        if (r.regionId() >= 0) {
            System.out.printf("  Layout Region #%d (type=%d)%n", r.regionId(), r.layoutType());
        }
    }
}
```

### From In-Memory Bytes or Decoded RGB8 Pixels

```java
// 1. Encoded PNG/JPEG bytes
byte[] imageBytes = java.nio.file.Files.readAllBytes(java.nio.file.Path.of("invoice.png"));
RustO.DetectTextResult res = engine.detectText(imageBytes)
    .asLines()
    .run();

// 2. Decoded interleaved RGB8 pixel buffer
RustO.DetectTextResult rgbRes = engine.detectText()
    .rgb(rgbPixels, width, height, width * 3L)
    .asLines()
    .run();
```

## 3. Spatial Layout Reconstruction (`.asSpatial().run()`)

```java
RustO.DetectTextResult spatial = engine.detectText("invoice.png")
    .asSpatial()
    .run();

if (spatial.isSpatial()) {
    System.out.println("--- Reconstructed Spatial Document ---");
    System.out.println(spatial.text());
}
```
