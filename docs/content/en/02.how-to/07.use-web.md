# Use Web

The `@rustors/web` package brings pure-Rust WebAssembly OCR directly to modern browsers and Web Workers with full TypeScript support, SIMD acceleration, and zero server uploads.

## Installation

```bash
npm install @rustors/web
# or
yarn add @rustors/web
# or
pnpm add @rustors/web
```

## Quick Start

Initialize the WASM engine with **Indra OCR** (`'indra'`, default) or PaddleOCR presets (`'ppv6'`, `'ppv5'`, `'ppv4'`, `'ppv3'`), then chain `.asLines()`, `.asWords()`, or `.asSpatial()` followed by `.run()`:

```ts
import { close, detectText, initialize } from '@rustors/web';

// 1. Initialize engine with local or remote model URLs
await initialize({
  preset: 'indra',
  enableReadingOrder: true,
  layoutModel: 'cdla',
  models: {
    detection: '/models/indraocr/det.rten',
    recognition: '/models/indraocr/rec.rten',
    dictionary: '/models/indraocr/meta.json',
    unwarp: '/models/modules/uvdoc.rten',
    orientation: '/models/indraocr/orient.rten',
    layout: '/models/modules/layout_cdla.rten',
    order: '/models/indraocr/order.rten',
  },
});

// 2. Perform OCR with fluent builder chaining (always finish with .run())
const results = await detectText(document.getElementById('my-image') as HTMLImageElement)
  .withAutoUnwarp()
  .withLayoutReading()
  .asLines()
  .run();

for (const item of results) {
  console.log(`${item.text} (${(item.score * 100).toFixed(1)}%)`);
}

// 3. Release worker resources when shutting down
close();
```

> [!IMPORTANT]
> Calling `detectText(source)` with a single argument returns a `DetectTextBuilder` (not a `Promise`). Always invoke `.run()` at the end of the builder chain!

## CDN & Remote Assets Usage

Load the WebAssembly runtime from jsDelivr and `.rten` models directly from Hugging Face Hub (with native CORS) without bundling model files into your frontend build:

### In Bundlers (Vite, Next.js, Nuxt)

```ts
import { detectText, initialize } from '@rustors/web';

const HF_BASE = 'https://huggingface.co/byrizki/rten-models/resolve/main';

await initialize({
  preset: 'indra',
  wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
  models: {
    detection: `${HF_BASE}/indraocr/det.rten`,
    recognition: `${HF_BASE}/indraocr/rec.rten`,
    dictionary: `${HF_BASE}/indraocr/meta.json`,
  },
});

const results = await detectText(imageFile).asLines().run();
```

### Vanilla HTML / Browser ES Modules

No build step or bundler required:

```html
<script type="module">
  import { detectText, initialize } from 'https://cdn.jsdelivr.net/npm/@rustors/web/+esm';

  const HF_BASE = 'https://huggingface.co/byrizki/rten-models/resolve/main';

  await initialize({
    preset: 'indra',
    wasmUrl: 'https://cdn.jsdelivr.net/npm/@rustors/web/dist/wasm/rusto_nn_bg.wasm',
    models: {
      detection: `${HF_BASE}/indraocr/det.rten`,
      recognition: `${HF_BASE}/indraocr/rec.rten`,
      dictionary: `${HF_BASE}/indraocr/meta.json`,
    },
  });

  const results = await detectText('https://example.com/sample-receipt.jpg').asLines().run();
  console.log('Detected items:', results);
</script>
```

## Supported Image Sources

`@rustors/web` accepts:

- Image URLs (`'https://example.com/receipt.jpg'` or `'/samples/doc.png'`)
- Base64 data URLs (`'data:image/jpeg;base64,...'`)
- DOM Elements: `HTMLImageElement`, `HTMLCanvasElement`, `ImageData`, `ImageBitmap`
- User files: `File`, `Blob`
- In-memory bytes: `Uint8Array`, `ArrayBuffer`, `{ bytes: Uint8Array }`

## Output Granularity via Fluent Builder

```ts
// Lines (default): row-grouped candidates -> Promise<TextResult[]>
const lines = await detectText(imageFile).asLines().run();

// Words: individual word-level tokens -> Promise<TextResult[]>
const words = await detectText(imageFile).asWords().run();

// Spatial: formatted 2D text with column spacing & newlines -> Promise<string>
const spatialText = await detectText(imageFile).asSpatial().run();
console.log(spatialText);
```

## Content Security Policy (CSP)

If your web application deploys strict HTTP Content Security Policy headers, configure these directives:

```http
Content-Security-Policy:
  default-src 'self';
  script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net;
  connect-src 'self' https://cdn.jsdelivr.net https://huggingface.co blob:;
  worker-src 'self' blob:;
  img-src 'self' data: blob:;
```

- **`script-src 'wasm-unsafe-eval'`**: Enables browser runtime compilation of WebAssembly binaries.
- **`connect-src https://cdn.jsdelivr.net https://huggingface.co blob:`**: Permits downloading `.wasm` and `.rten` model files from CDNs or local blob stores.
- **`worker-src 'self' blob:`**: Required because `@rustors/web` executes inference inside non-blocking Web Workers by default.
- **`img-src 'self' data: blob:`**: Allows reading images from local file previews or Base64 streams.
