# Use RustO in Web & Browser Apps

The `rusto-web` package brings client-side OCR capabilities to modern browsers, Web Workers, and client frameworks with full TypeScript support.

## Installation

```bash
npm install rusto-web rusto-models-ppocrv6-tiny
# or
yarn add rusto-web rusto-models-ppocrv6-tiny
# or
pnpm add rusto-web rusto-models-ppocrv6-tiny
```

## Quick Start

```ts
import { initialize, detectText } from 'rusto-web';
import { getModelUrls } from 'rusto-models-ppocrv6-tiny';

// 1. Initialize engine with pre-trained models
const urls = getModelUrls('/models/ppocrv6-tiny');

await initialize({
  preset: 'ppv6',
  models: {
    detection: urls.detection,
    recognition: urls.recognition,
    dictionary: urls.dictionary,
  },
});

// 2. Perform OCR on any ImageSource (Image, Canvas, File, Blob, or URL)
const results = await detectText(document.getElementById('my-image') as HTMLImageElement);

for (const item of results) {
  console.log(`${item.text} (${(item.score * 100).toFixed(1)}%)`);
}
```

## Supported Image Sources

`rusto-web` seamlessly accepts:

- Image URLs (e.g. `'https://example.com/receipt.jpg'` or `'/samples/doc.png'`)
- Base64 data strings (`'data:image/jpeg;base64,...'`)
- DOM Elements: `HTMLImageElement`, `HTMLCanvasElement`, `ImageData`, `ImageBitmap`
- User files: `File`, `Blob`
- In-memory bytes: `Uint8Array`, `ArrayBuffer`, `{ bytes: Uint8Array }`

## Output Granularity

```ts
// Lines (default): row-grouped candidates
const lines = await detectText(imageFile, { output: 'lines' });

// Words: individual word-level tokens
const words = await detectText(imageFile, { output: 'words' });

// Spatial: formatted text with layout spacing and newlines preserved
const spatialText = await detectText(imageFile, { output: 'spatial' });
console.log(spatialText);
```
