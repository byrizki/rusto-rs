The `@rustors/react-native` package provides native bridges and TypeScript typings for React Native iOS and Android applications. Written natively in **Objective-C++** on iOS and **Kotlin/JNI** on Android, it delivers low-overhead native bridging across both Legacy and New Architecture (TurboModules).

---

## Installation

```bash
npm install @rustors/react-native
# or yarn add @rustors/react-native / pnpm add @rustors/react-native
```

---

## iOS Configuration Deep Dive

### 1. Zero-Friction Native Implementation

The iOS native module is authored in **Objective-C++ (`.mm`)**. This eliminates toolchain-dependent Swift linker issues (such as Swift runtime library embedding or requiring host applications to include dummy `.swift` bridging stubs) and links cleanly into both Objective-C and Swift host apps.

### 2. Dual Architecture Support (New Architecture & Paper)

`@rustors/react-native` automatically adapts to your project's architecture:

- **New Architecture (TurboModule)**: When `RCT_NEW_ARCH_ENABLED=1` is set, the module compiles against React Native's C++ TurboModule interface.
- **Legacy Architecture (Paper)**: Uses standard asynchronous `RCTBridgeModule` promises with zero deprecation warnings.

### 3. CocoaPods Setup (`ios/Podfile`)

Ensure static linkage is enabled if using `use_frameworks!`:

```ruby
target 'YourApp' do
  use_frameworks! :linkage => :static
end
```

RustO! automatically downloads required models (`ppocrv6-tiny` by default) on demand from Hugging Face Hub into the app's cache directory when unbundled, or loads bundled `.mnn` / `.rten` assets directly from your app bundle.

Install CocoaPods dependencies:

```bash
cd ios && pod install
```

### 4. Camera & Photo Permissions (`ios/YourApp/Info.plist`)

When integrating camera feeds or gallery image pickers (`react-native-image-picker` or `react-native-vision-camera`), declare the required permissions:

```xml
<key>NSCameraUsageDescription</key>
<string>This app requires camera access to scan physical documents with RustO! OCR.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>This app requires photo library access to import images for text recognition.</string>
```

### 5. Expo Configuration (Development Builds)

Because RustO! executes native compiled binaries, standard **Expo Go** cannot load it. Use **Expo Prebuild** / custom development builds:

```bash
npx expo run:ios
```

In `app.json`:

```json
{
  "expo": {
    "plugins": [
      [
        "expo-image-picker",
        {
          "photosPermission": "The app accesses your photos to scan receipts with RustO!."
        }
      ]
    ]
  }
}
```

## Android Configuration

In your root `android/settings.gradle`, ensure the JitPack Maven repository is enabled:

```groovy
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
    }
}
```

Models are downloaded automatically on first run when unbundled, or can be placed into `android/app/src/main/assets/` for offline bundling.

## 1. Engine Initialization & Cleanup

Call `initialize()` once during application boot (and `close()` when releasing native resources):

```typescript
import { close, initialize } from '@rustors/react-native';

// 1. Zero-config initialization (auto-downloads PP-OCRv6 Tiny FP32 when unbundled)
await initialize();

// 2. Or initialize with explicit Indra / PP-OCRv6 preset & auxiliary models:
await initialize({
  preset: 'indra',
  enableReadingOrder: true,
  layoutVariant: 'cdla',
  models: {
    detection: 'indra_det.mnn',
    recognition: 'indra_rec_latin.mnn',
    dictionary: 'indra_rec_latin_meta.json',
    unwarp: 'uvdoc.mnn',
    orientation: 'indra_orient.mnn',
    layout: 'layout_cdla.mnn',
  },
});

// Release native engine handle when no longer needed
await close();
```

## 2. Input Sources on iOS & Android

`detectText(source)` returns a fluent `DetectTextBuilder` — always finish the chain with `.run()`:

```typescript
import { detectText } from '@rustors/react-native';

// 1. File URI (file://, or Android content://)
const r1 = await detectText({ uri: 'file:///var/mobile/Containers/Data/.../receipt.jpg' })
  .asLines()
  .run();

// 2. Base64 Encoded Image Data
const r2 = await detectText({ base64: base64DataString }).asLines().run();

// 3. Raw Bytes (Uint8Array)
const r3 = await detectText({ bytes: rawUint8Array }).asLines().run();
```

> [!TIP]
> Passing local `file://` or `content://` URIs obtained directly from image pickers or camera caches avoids copying large Base64 strings across the JS bridge.

## 3. Output Modes & Fluent Builder

Select output granularity using `.asLines()`, `.asWords()`, or `.asSpatial()` before calling `.run()`:

```typescript
import { detectText, TextResult } from '@rustors/react-native';

// Mode 1: Line detection (default) -> Promise<TextResult[]>
const lines: TextResult[] = await detectText({ uri: imageUri })
  .withAutoUnwarp()
  .withLayoutReading()
  .asLines()
  .run();

// Mode 2: Word-level detection -> Promise<TextResult[]>
const words: TextResult[] = await detectText({ uri: imageUri }).asWords().run();

// Mode 3: Spatial layout reconstruction -> Promise<string>
const spatialText: string = await detectText({ uri: imageUri })
  .withPreRecognition({ lineYThreshold: 0.5, wordXThreshold: 0.4 })
  .asSpatial()
  .run();
```

## 4. Complete React Native Scanner Component

```tsx
import React, { useEffect, useState } from 'react';
import {
  ActivityIndicator,
  Image,
  SafeAreaView,
  ScrollView,
  StyleSheet,
  Text,
  TouchableOpacity,
  View,
} from 'react-native';
import { launchImageLibrary } from 'react-native-image-picker';
import { close, detectText, initialize, TextResult } from '@rustors/react-native';

export default function DocumentScannerScreen() {
  const [imageUri, setImageUri] = useState<string | null>(null);
  const [lines, setLines] = useState<TextResult[]>([]);
  const [spatialText, setSpatialText] = useState<string>('');
  const [loading, setLoading] = useState<boolean>(false);
  const [mode, setMode] = useState<'lines' | 'spatial'>('lines');

  useEffect(() => {
    initialize().catch((err) => console.error('RustO Initialization Failed:', err));
    return () => {
      close();
    };
  }, []);

  const handlePickImage = async () => {
    const result = await launchImageLibrary({ mediaType: 'photo', quality: 0.9 });
    if (result.assets && result.assets[0]?.uri) {
      const uri = result.assets[0].uri;
      setImageUri(uri);
      processOcr(uri, mode);
    }
  };

  const processOcr = async (uri: string, targetMode: 'lines' | 'spatial') => {
    setLoading(true);
    try {
      if (targetMode === 'lines') {
        const results = await detectText({ uri })
          .withAutoUnwarp()
          .withLayoutReading()
          .withPostDetection({ useDilation: true })
          .asLines()
          .run();
        setLines(results);
        setSpatialText('');
      } else {
        const formatted = await detectText({ uri })
          .withAutoUnwarp()
          .withPreRecognition({ lineYThreshold: 0.5, wordXThreshold: 0.4 })
          .asSpatial()
          .run();
        setSpatialText(formatted);
        setLines([]);
      }
    } catch (error) {
      console.error('OCR Error:', error);
    } finally {
      setLoading(false);
    }
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.header}>
        <TouchableOpacity style={styles.btn} onPress={handlePickImage}>
          <Text style={styles.btnText}>Pick Document</Text>
        </TouchableOpacity>

        <TouchableOpacity
          style={[styles.btn, styles.toggleBtn]}
          onPress={() => {
            const nextMode = mode === 'lines' ? 'spatial' : 'lines';
            setMode(nextMode);
            if (imageUri) processOcr(imageUri, nextMode);
          }}
        >
          <Text style={styles.btnText}>Mode: {mode.toUpperCase()}</Text>
        </TouchableOpacity>
      </View>

      {loading && <ActivityIndicator size="large" color="#f97316" style={{ marginVertical: 12 }} />}

      <ScrollView style={styles.content}>
        {imageUri && (
          <View style={styles.imageWrapper}>
            <Image source={{ uri: imageUri }} style={styles.previewImage} resizeMode="contain" />
          </View>
        )}

        <View style={styles.resultContainer}>
          {mode === 'spatial' ? (
            <Text style={styles.spatialCode}>
              {spatialText || 'No spatial text reconstructed.'}
            </Text>
          ) : (
            lines.map((item, idx) => (
              <View key={idx} style={styles.lineItem}>
                <Text style={styles.lineText}>{item.text}</Text>
                <Text style={styles.lineScore}>({(item.score * 100).toFixed(0)}%)</Text>
              </View>
            ))
          )}
        </View>
      </ScrollView>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#09090b' },
  header: { flexDirection: 'row', padding: 12, gap: 8 },
  btn: { flex: 1, backgroundColor: '#f97316', padding: 12, borderRadius: 8, alignItems: 'center' },
  toggleBtn: { backgroundColor: '#27272a' },
  btnText: { color: '#ffffff', fontWeight: 'bold' },
  content: { flex: 1, padding: 12 },
  imageWrapper: {
    width: '100%',
    height: 240,
    backgroundColor: '#18181b',
    borderRadius: 8,
    marginBottom: 12,
  },
  previewImage: { width: '100%', height: '100%' },
  resultContainer: { padding: 12, backgroundColor: '#18181b', borderRadius: 8 },
  lineItem: {
    flexDirection: 'row',
    justifyContent: 'space-between',
    paddingVertical: 4,
    borderBottomWidth: 1,
    borderBottomColor: '#27272a',
  },
  lineText: { color: '#fafafa', fontSize: 14, flex: 1 },
  lineScore: { color: '#a1a1aa', fontSize: 12, marginLeft: 8 },
  spatialCode: { color: '#38bdf8', fontFamily: 'monospace', fontSize: 13, lineHeight: 18 },
});
```
